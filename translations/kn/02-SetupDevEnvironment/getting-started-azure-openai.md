# Azure AI Foundry ನ ಅಭಿವೃದ್ಧಿ ಪರಿಸರವನ್ನು ಸೆಟ್‌ಅಪ್ ಮಾಡುವುದು

> ಈ ಮಾರ್ಗದರ್ಶಿ ಈ ಕೋರ್ಸ್‌ನ ಜावा AI ಆ್ಯಪ್‌ಗಳಿಗಾಗಿ **Azure AI Foundry** ಮಾದರಿಗಳನ್ನು **ಕೀಲೆಸ್** प्रमाणೀಕರಣ (Microsoft Entra ID) ಬಳಸಿ ಸೆಟ್‌ಅಪ್ ಮಾಡುತ್ತದೆ — ನಿರ್ವಹಿಸಲು API ಕೀಸ್ ಏನೂ ಇಲ್ಲ. ಟೂಲ್‌ಗಳಿಗೆ ಹೊಸದಾ? [ಅಭಿವೃದ್ಧಿ ಪರಿಸರ ಮಾರ್ಗದರ್ಶಿ](./README.md)ನಿಂದ ಪ್ರಾರಂಭಿಸಿ.

ಈ ಮಾರ್ಗದರ್ಶಿ ಈ ಕೋರ್ಸ್‌ನ ಜಾವಾ AI ಆ್ಯಪ್‌ಗಳಿಗಾಗಿ **Azure AI Foundry** ಮಾದರಿಗಳನ್ನು ಸೆಟ್‌ಅಪ್ ಮಾಡುತ್ತದೆ. ನಿಮ್ಮ ಬಳಿ ಎರಡು ಮಾರ್ಗಗಳಿವೆ:

- **ಆಪ್ಷನ್ A — `azd` + Bicep ಬಳಸಿ ಪ್ರೊವಿಷನ್ (ಶಿಫಾರಸು ಮಾಡಲಾಗಿದೆ):** ಒಂದು ಕಮಾಂಡ್ Foundry ಖಾತೆ ಮತ್ತು ಮಾದರಿಗಳನ್ನು ಕೋಡ್ ಎಂದು ನಿಯೋಜಿಸುತ್ತದೆ. ಯಾವುದೇ ಪೋರ್ಟಲ್ ಕ್ಲಿಕ್ಕಿಸುವಿಕೆ ಇಲ್ಲ.
- **ಆಪ್ಷನ್ B — ಸಂಪನ್ಮೂಲಗಳನ್ನು ಕೈಯಿಂದ ರಚಿಸಿ** Azure AI Foundry ಪೋರ್ಟಲ್‌ನಲ್ಲಿ.

ಎರಡೂ ಮಾರ್ಗಗಳು **ಕೀಲೆಸ್ ಪ್ರಮಾಣೀಕರಣ** (Microsoft Entra ID) ಬಳಸುತ್ತವೆ — ನಕಲಿಸಲು ಅಥವಾ ಹಠಾತ್ತಾಗಿ ಹೊರಬಿಟ್ಟಲು API ಕೀಸ್ ಇಲ್ಲ.

## ಏನು ರಚಿಸಲಾಗುತ್ತದೆ

[`infra/`](../../../02-SetupDevEnvironment/infra)ನಲ್ಲಿರುವ Bicep ಟೆಂಪ್ಲೇಟ್ಗಳು ಪ್ರೊವಿಷನ್ ಮಾಡುತ್ತವೆ:

- ಒಬ್ಬ **Azure AI Foundry** ಖಾತೆ (`Microsoft.CognitiveServices/accounts`, ಪ್ರಕಾರ `AIServices`) ಪ್ರಾಜೆಕ್ಟ್ ಜೊತೆಗೆ
- ಒಂದು **ಚಾಟ್** ನಿಯೋಜನೆ - GPT-5.6 Luna (`gpt-5.6-luna`), ಆವೃತ್ತಿ `2026-07-09`, **GlobalStandard** ಸಾಮರ್ಥ್ಯ `10` (10 ವಿನಂತಿಗಳು/ನಿಮಿಷ ಮತ್ತು 10,000 ಟೋಕನ್‌ಗಳು/ನಿಮಿಷ ಈ ಮಾದರಿ ಗಾಗಿ)
- ಒಂದು **ಎಂಬೆಡಿಂಗ್** ನಿಯೋಜನೆ - `text-embedding-3-small`, ಆವೃತ್ತಿ `1` (ನಂತರ ಅಧ್ಯಾಯಗಳಲ್ಲಿ ಬಳಸಲಾಗುತ್ತದೆ)
- ಒಂದು **ಕೀಲೆಸ್ ಪಾತ್ರ ನಿಯೋಜನೆ** (`Cognitive Services OpenAI User`) ಆದ್ದರಿಂದ ನೀವು `az login` ಮೂಲಕ ಸೈನ್ ಇನ್ ಆಗಬಹುದು, ಕೀಗಳನ್ನು ನಿರ್ವಹಿಸುವ ಅಗತ್ಯವಿಲ್ಲ

## ಆಪ್ಷನ್ A: azd + Bicep ಬಳಸಿ ಪ್ರೊವಿಷನ್ (ಶಿಫಾರಸು)

`02-SetupDevEnvironment` ಫೋಲ್ಡರ್‌ನಿಂದ:

```bash
cd 02-SetupDevEnvironment

# ಸೈನ್ ಇನ್ (ಎರಡೂ ಉಪಕರಣಗಳು)
azd auth login
az login

# ಫೌಂಡ್ರಿ ಖಾತೆ + ಮಾದರಿ ನಿಯೋಜನೆಗಳನ್ನು ಒದಗಿಸಿ
azd up
```

`azd` ನಿಮಗೆ **ಪರಿಸರ ಹೆಸರು** (ಉದಾ: `genai-java`), **ಚಂದಾದಾರಿಕೆ**, ಮತ್ತು **ಪ್ರದೇಶ**ಗಾಗಿ ಕೇಳುತ್ತದೆ. ನಿಮ್ಮದೇ ಚಂದಾದಾರಿಕೆಯನ್ನು ಮತ್ತು `gpt-5.6-luna` ಮತ್ತು `text-embedding-3-small` ಲಭ್ಯವಿರುವ ಯಾವುದೇ ಪ್ರದೇಶವನ್ನು ಆಯ್ಕೆಮಾಡಿ, ಉದಾ: `eastus2`. ಆ ಪ್ರದೇಶದಲ್ಲಿ ಮಾದರಿ ಮತ್ತು ನಿಯೋಜನೆ ಪ್ರಕಾರಕ್ಕೆ ಸಾಧ್ಯತೆಯೂ ಮತ್ತು ಕ್ವೋಟಾವುಳ್ಳದ ದೃಢ ಪಡಿಸಿ; ಚಂದಾದಾರಿಕೆಯ ಆಧಾರದ ಮೇಲೆ ಲಭ್ಯತೆ ಮತ್ತು ಕ್ವೋಟಾ ಬದಲಾಗಬಹುದು.

ಪ್ರೊವಿಷನಿಂಗ್ ಮುಗಿದ ನಂತರ, azd:

1. [`infra/main.bicep`](../../../02-SetupDevEnvironment/infra/main.bicep) ನಲ್ಲಿ ವ್ಯಾಖ್ಯಾನಿಸಲಾದ ಎಲ್ಲವನ್ನೂ ನಿಯೋಜಿಸುತ್ತದೆ.
2. ಒಂದು ಪೋಸ್ಟ್‌ಪ್ರೊವಿಷನ್ ಹುಕ್ ಅನ್ನು ಚಲಿಸುತ್ತದೆ, ಅದು [`examples/basic-chat-azure/.env`](../../../02-SetupDevEnvironment/examples/basic-chat-azure) ನಲ್ಲಿ ನಿಮ್ಮ ಎಂಡ್‌ಪಾಯಿಂಟ್ ಮತ್ತು ನಿಯೋಜನೆಯ ಹೆಸರುಗಳನ್ನು (ರಹಸ್ಯವಿಲ್ಲದೇ) ಬರೆಯುತ್ತದೆ.

> **ಸೂಚನೆ:** ಬದಲಾವಣೆಗಳನ್ನು ಅನ್ವಯಿಸಲು ಯಾವುದೇ ಸಮಯದಲ್ಲಿ `azd up` ಅನ್ನು ಪುನರುಚಿತ್ತಪಡಿಸಿ. ಎಲ್ಲಾ ಸ್ವಯಂವಿಲ್ಲಾ ಮಾಡುವುದಕ್ಕೆ `azd down` ಅನ್ನು ಚಲಾಯಿಸಿ ಮತ್ತು ವೆಚ್ಚವನ್ನು ನಿಲ್ಲಿಸಿ.

ಸೃಷ್ಟಿಕರಿಸಿದ ಸೆಟ್ಟಿಂಗ್ಸ್ ನೋಡಲು:

```bash
azd env get-values
```

ಈಗ [ನಿಮ್ಮ ಸೆಟಪ್ ಪರೀಕ್ಷಿಸಿ](#ನಿಮ್ಮ-ಸೆಟಪ್-ಪರೀಕ್ಷಿಸಿ)ಗೆ ಹೋಗಿ.

## ಆಪ್ಷನ್ B: ಸಂಪನ್ಮೂಲಗಳನ್ನು ಕೈಯಿಂದ ರಚಿಸಿ

ಪೋರ್ಟಲ್ ಇಷ್ಟವಿದೆಯೇ? ಸಂಪನ್ಮೂಲಗಳನ್ನು ಕೈಯಿಂದ ರಚಿಸಿ:

1. [Azure AI Foundry ಪೋರ್ಟಲ್](https://ai.azure.com/)ಗೆ ಹೋಗಿ ಮತ್ತು ಸೈನ್ ಇನ್ ಮಾಡಿರಿ.
2. **ಪ್ರಾಜೆಕ್ಟ್ ರಚಿಸಿ** (ಇದು AI Foundry ಸಂಪನ್ಮೂಲವನ್ನೂ ಸೃಷ್ಟಿಸುತ್ತದೆ). ಅದಕ್ಕೆ `GenAIJava` ಎಂದು ಹೆಸರು ಕೊಡಿರಿ.
3. ನಿಮ್ಮ ಪ್ರಾಜೆಕ್ಟ್‌ನಲ್ಲಿ, **ಮಾದರಿಗಳು + ಎಂಡ್‌ಪಾಯಿಂಟ್‌ಗಳು** → **ಮಾದರಿ ನಿಯೋಜಿಸಿ** → **ಬೇಸ್ ಮಾದರಿ ನಿಯೋಜಿಸಿ** ತೆರೆಯಿರಿ.
4. **GPT-5.6 Luna** (ಮಾದರಿ ಮತ್ತು ನಿಯೋಜನೆ ಹೆಸರನ್ನು `gpt-5.6-luna`, ಆವೃತ್ತಿ `2026-07-09`)ನೊಂದಿಗೆ **Global Standard** ಸಾಮರ್ಥ್ಯ `10` ನಿಯೋಜಿಸಿ. ನೀವುemba ಪ್ರತಿಮಾ ಉದಾಹರಣೆಗಳಿಗಾಗಿ **text-embedding-3-small**, ಆವೃತ್ತಿ `1` ಅನ್ನು ಪುನರಾವರ್ತಿಸಿ.
5. **ಒವರ್ವ್ಯೂ**ನಿಂದ, **ಎಂಡ್‌ಪಾಯಿಂಟ್** ನಕಲು ಮಾಡಿ (ಉದಾ: `https://<resource>.openai.azure.com/`).
6. ನಿಮಗೆ ಕೀಲೆಸ್ ಪ್ರವೇಶ ನೀಡಿ: ಸಂಪನ್ಮೂಲದಲ್ಲಿ **ಪ್ರವೇಶ ನಿಯಂತ್ರಣ (IAM)** → **ಪಾತ್ರ ನಿಯೋಜಿಸು** → ನಿಮ್ಮ ಖಾತೆಗೆ **Cognitive Services OpenAI User** ಅನ್ನು ನೀಡಿರಿ.

> **ಇನ್ನೂ ಸಮಸ್ಯೆ ಇದೆಯೇ?** [Azure AI Foundry ಡಾಕ್ಯುಮೆಂಟೇಶನ್](https://learn.microsoft.com/azure/ai-foundry/how-to/create-projects) ನೋಡಿ.

## ನಿಮ್ಮ ಪರಿಸರವನ್ನು ಸಂರಚಿಸಿ

**ನೀವು ಆಪ್ಷನ್ A (`azd up`) ಬಳಸಿದರೆ**, ನಿಮ್ಮ ಸೆಟ್ಟಿಂಗ್ ಫೈಲ್ ಈಗಾಗಲೇ ಬರೆಯಲಾಗಿದೆ — ಯಾವುದೇ ಸಂರಚನೆ ಅಗತ್ಯವಿಲ್ಲ. [ನಿಮ್ಮ ಸೆಟಪ್ ಪರೀಕ್ಷಿಸಿ](#ನಿಮ್ಮ-ಸೆಟಪ್-ಪರೀಕ್ಷಿಸಿ)ಗೆ ಹೋಗಿ.

**ನೀವು ಆಪ್ಷನ್ B (ಕೈಯಿಂದ) ಬಳಸಿ**, ಉದಾಹರಣೆಯ `.env` ಫೈಲ್ ನೀವು ಕ್ರಿಯೇಟ್ ಮಾಡಿಕೊಳ್ಳಿ:

```bash
cd 02-SetupDevEnvironment/examples/basic-chat-azure
cp .env.example .env
```

`.env` ಅನ್ನು ನಿಮ್ಮ ಎಂಡ್‌ಪಾಯಿಂಟ್ (ಕೀ ಇಲ್ಲ — ಪ್ರಮಾಣೀಕರಣ ಕೀಲೆಸ್) ಜೊತೆಯಾಗಿ ಸಂಪಾದಿಸಿ:

```bash
AZURE_OPENAI_ENDPOINT=https://<your-resource>.openai.azure.com/
AZURE_OPENAI_DEPLOYMENT=gpt-5.6-luna
```

ಸಂಪನ್ಮೂಲದ Azure OpenAI ಎಂಡ್‌ಪಾಯಿಂಟ್ ಬಳಸಿ, ಪ್ರಾಜೆಕ್ಟ್ URL ಅಲ್ಲ. basic-chat ಆ್ಯಪ್ ಅದನ್ನು `/openai/v1`ಗೆ ಪರಿಹರಿಸುತ್ತದೆ ಮತ್ತು ಸ್ಪಷ್ಟ ಬೆರೆರ್-ಟೋಕನ್ ಕ್ಲೈಸ್ಕ್ಕೆ ಹೊಂದಿಸುತ್ತದೆ; API ಕೀ ಅಗತ್ಯವಿಲ್ಲ.

> **ಭದ್ರತಾ ಟಿಪ್ಪಣಿ:** ಉಳಿಸಬೇಕಾದ API ಕೀ ಇಲ್ಲ. ನೀವು Microsoft Entra ID ಮೂಲಕ `az login` (ಸ್ಥಳೀಯವಾಗಿ) ಅಥವಾ ನಿರ್ವಹಿಸಲಾದ ಐಡೆಂಟಿಟಿ (Azure ನಲ್ಲಿ) ಬಳಸಿ ಪ್ರಮಾಣೀಕರಿಸುತ್ತೀರಿ. `.env` ಫೈಲ್‌ ಒಂದೇ ಬಾರಿಗೆ ರಹಸ್ಯವಲ್ಲದ ಸೆಟ್ಟಿಂಗ್‌ಗಳನ್ನು ಹೊಂದಿದ್ದು `.gitignore`ೊಂದಿಗೆ ಸಮರ್ಪಕವಾಗಿದ್ದಾನೆ.

## ನಿಮ್ಮ ಸೆಟಪ್ ಪರೀಕ್ಷಿಸಿ

ಕೀಲೆಸ್ ಪ್ರಮಾಣೀಕರಣಕ್ಕೆ ಟೋಕನ್ ಸಿಗುವುದಕ್ಕಾಗಿ ನೀವು ಸೈನ್ ಇನ್ ಆಗಿದ್ದೀರಾ ಎಂದು ಖಚಿತಪಡಿಸಿ, ನಂತರ ಉದಾಹರಣೆಯನ್ನು ಚಲಾಯಿಸಿ:

```bash
cd 02-SetupDevEnvironment/examples/basic-chat-azure

az login          # ನೀವು ಈಗಾಗಲೇ ಪ್ರವೇಶಿಸಿರಲಿಲ್ಲದಿದ್ದರೆ
mvn clean spring-boot:run
```

ನೀವು `gpt-5.6-luna` ಮಾದರಿಯಿಂದ ಪ್ರತಿಕ್ರಿಯೆಯನ್ನು ನೋಡಬೇಕು. ಚಿಕ್ಕ ಡೀಫಾಲ್ಟ್ ಕ್ವೋಟಾ ಒಳಗೆ ಉಳಿಯಲು ಉದಾಹರಣೆಗಳನ್ನು ಕ್ರಮವಾಗಿ ಚಲಾಯಿಸಿ; HTTP 429 ಬಂದಲ್ಲಿ, ಪುನಃ ಪ್ರಯತ್ನಿಸುವ ಮುನ್ನ ರಿಟ್ರೈ ಅಂತರ ಕಾಯಿರಿ.

> **VS ಕೋಡ್ ಬಳಕೆದಾರರು:** ಚಲಾಯಿಸಲು `F5` ಒತ್ತಿ. ಆ್ಯಪ್ ನಿಮ್ಮ `.env` ಸ್ವಯಂಚಾಲಿತವಾಗಿ ಲೋಡ್ ಮಾಡುತ್ತದೆ.

> **ಪೂರ್ಣ ಉದಾಹರಣೆ:** ವಿವರಗಳು ಮತ್ತು ಸಮಸ್ಯೆ ನಿವಾರಣೆಗಾಗಿ [Azure AI Foundry ಜೊತೆಗೆ ಮೂಲ ಚಾಟ್ ಉದಾಹರಣೆ](./examples/basic-chat-azure/README.md) ನೋಡಿರಿ.

## ಮುಂದೇನಿದೆ?

ಪ್ರೊವಿಷನಿಂಗ್ ಜೊತೆ ಯಶಸ್ವಿಯಾಗಿ ಉದಾಹರಣೆಯನ್ನು ಓಡಿಸಿದ ನಂತರ, ನೀವು ಹೊಂದಿರುತ್ತೀರಿ:
- Azure AI Foundry ನಲ್ಲಿ `gpt-5.6-luna` ಮತ್ತು `text-embedding-3-small` ನಿಯೋಜಿಸಲಾಗಿದೆ
- ಕೀಲೆಸ್ ಪ್ರಮಾಣೀಕರಣ (Microsoft Entra ID) — ನಿಭಾಯಿಸಲು ಕೀಗಳು ಇಲ್ಲ
- ನಿಮ್ಮ ಎಂಡ್‌ಪಾಯಿಂಟ್ ಮತ್ತು ನಿಯೋಜನೆ ಹೆಸರುಗಳೊಂದಿಗೆ ಸ್ಥಳೀಯ `.env`
