## ಪ್ರಮುಖ ಘಟಕಗಳ ವಿವರಣೆ

### 1. ಮುಖ್ಯ ಅಪ್ಲಿಕೇಶನ್

**ಕಡತ:** `PetStoryApplication.java`

ಇದು ನಮ್ಮ ಸ್ಪ್ರಿಂಗ್ ಬೂಟ್ ಅಪ್ಲಿಕೇಶನ್‌ಗೆ ಪ್ರವೇಶ ಬಿಂದು:

```java
@SpringBootApplication
public class PetStoryApplication {
    public static void main(String[] args) {
        SpringApplication.run(PetStoryApplication.class, args);
    }
}
```

**ಇದರಿಂದ ಏನು ಆಗುತ್ತದೆ:**
- `@SpringBootApplication` ಅನೇಶನೇಶನ್ ಸ್ವಯಂ-ಸಂರಚನೆ ಮತ್ತು ಘಟಕ ಸ್ಕ್ಯಾನಿಂಗ್ ಅನ್ನು ಸಕ್ರಿಯಗೊಳಿಸುತ್ತದೆ
- 8080 ಪೋರ್ಟ್‌ನಲ್ಲಿ ಮತ್ತೊಬ್ಬ ವೆಬ್ ಸರ್ವರ್ (ಟೋಕ್ಮ್ಯಾಟ್) ಅನ್ನು ಪ್ರಾರಂಭಿಸುತ್ತದೆ
- ಎಲ್ಲಾ ಅಗತ್ಯವಾದ ಸ್ಪ್ರಿಂಗ್ ಬೀನ್‌ಗಳು ಮತ್ತು ಸೇವೆಗಳನ್ನು ಸ್ವಯಂಚಾಲಿತವಾಗಿ ಸೃಷ್ಟಿಸುತ್ತದೆ

### 2. ವೆಬ್ ನಿಯಂತ್ರಕ

**ಕಡತ:** [PetController.java](../../../../04-PracticalSamples/petstory/src/main/java/com/example/petstory/PetController.java)

| ಅಂತಿಮಬಿಂದು | ವಿನಂತಿ | ಯಶಸ್ವಿ ಪ್ರತಿಕ್ರಿಯೆ |
| --- | --- | --- |
| `GET /` | ಯಾವುದೇ ಬಾಡಿ ಇಲ್ಲ | CSRF ಟೋಕನ್‌ ಹೊಂದಿರುವ HTML ಅಪ್‌ಲೋಡ್ ಫಾರಂ |
| `POST /analyze-image` | `multipart/form-data`, ಫೈಲ್ ಕ್ಷೇತ್ರ `image` | JSON: `{"description":"ಆಡುತ್ತಿರುವ ಜಾನುವಾರು..."}` |
| `POST /generate-story` | `application/x-www-form-urlencoded`, ಕ್ಷೇತ್ರ `description` | ವರ್ಣನೆ ಮತ್ತು ರಚಿಸಿದ ಕಥೆ ಹೊಂದಿರುವ HTML ಫಲಿತಾಂಶ ಪುಟ |

ಎರಡೂ POST ಅಂತಿಮಬಿಂದುವುಗಳಿಗೆ ಸತ್ರ ಕುಕೀ ಮತ್ತು `GET /` ಯಿಂದ ಪಡೆದ CSRF ಟೋಕನ್ ಅಗತ್ಯ. ಅಪ್‌ಲೋಡ್ ಸ್ಕ್ರಿಪ್ಟು ಮರೆಗೂ `_csrf` ಮೌಲ್ಯವನ್ನು `X-CSRF-TOKEN` ಹೆಡರ್‌ನಲ್ಲಿ ಕಳುಹಿಸುತ್ತದೆ; ಕಥೆ ಸಲ್ಲಿಕೆ ಅದು `_csrf` ಫಾರಂ ಕ್ಷೇತ್ರವಾಗಿ ಕಳುಹಿಸುತ್ತದೆ. API ಕ್ಲೈಂಟ್‌ಗಳು ವಿನಂತಿಗಳ ನಡುವೆ ಕುಕೀ ಉಳಿಸಬೇಕು. ಇವು ಫಾರಂ ಅಂತಿಮಬಿಂದುಗಳು, JSON ವಿನಂತಿ ಅಂತಿಮಬಿಂದುಗಳಲ್ಲ.

ವರ್ಣನೆಗಳು ಖಾಲಿಯಾಗಿ ಇರಬಾರದು ಮತ್ತು 1000 ಅಕ್ಷರಗಳಿಗಿಂತ ಹೆಚ್ಚು ಇರಬಾರದು. ನಿಯಂತ್ರಕವು ವರ್ಣನೆಯನ್ನು ಟ್ರಿಮ್ ಮಾಡಿ `<`, `>`, ಡಬಲ್ ಕೋಟ್ಸ್, ಅಪೋಸ್ಟ್ರೋಫಿ, ಮತ್ತು `&` ಅನ್ನು ತೆಗೆಯುತ್ತದೆ, ನಂತರ ಸೇವೆಗೆ ಹಸ್ತಾಂತರಿಸುತ್ತದೆ. ಫಲಿತಾಂಶ ಟೆಂಪ್ಲೇಟೂ ಮಾದರಿಔಟ್‌ಪುಟ್ ಅನ್ನು `th:text` ಮೂಲಕ ಎಸ್ಕೇಪ್ ಮಾಡುತ್ತದೆ.

ಚಿತ್ರ ಮಾನ್ಯತೆ ವಿಫಲತೆಯು HTTP 400 ಕ್ಕೊಂದು `error` ಕ್ಷೇತ್ರವನ್ನು ಹೊರತುಪಡಿಸಿ, ಮಾದರಿ ವಿಫಲತೆಗಳು HTTP 502 ಮತ್ತು `error` ಕ್ಷೇತ್ರ ಮತ್ತು ಯಾವುದೇ `description` ಇಲ್ಲದೆ ನಿರ್ಗಮಿಸುತ್ತವೆ. ಅನಮಾನ್ಯ ಕಥಾ ವರ್ಣನೆಗಳು ಅಥವಾ ಮಾದರಿ ವಿಫಲತೆಗಳು `/` ಗೆ ಮರುನಿರ্দেশಿಸಲಾಗುತ್ತದೆ ಭೋಜನೀಯ ದೋಷದೊಂದಿಗೆ. ಅಗತ್ಯ ಕ್ಷೇತ್ರಗಳು ಇಲ್ಲದಿರುವುದು HTTP 400 ಪ್ರಮಾಣಿಕೆ; ಗೈರುಮಾನ್ಯ ಅಥವಾ ಇಲ್ಲದ CSRF ಟೋಕನ್ ಗಳಿಗೆ HTTP 403 ಅನ್ನು ನೀಡಲಾಗುತ್ತದೆ. ಯಾವುದೇ ಫಾಲ್ಬ್ಯಾಕ್ ವರ್ಣನೆಗಳು ಅಥವಾ ಕಥೆಗಳು ಯಶಸ್ವಿ AI ಫಲಿತಾಂಶಗಳಾಗಿ ಪ್ರದರ್ಶಿಸಲ್ಪಡುವುದಿಲ್ಲ.

### 3. ಕಥಾ ಸೇವೆ

**ಕಡತ:** [StoryService.java](../../../../04-PracticalSamples/petstory/src/main/java/com/example/petstory/StoryService.java)

ಅಧಿಕೃತ ಓಪನ್‌ಎಐ ಜಾವಾ SDK 4.63.1 ಅಜುರ್ ಏಐ ಫೌಂಡ್ರಿಯ OpenAI ಅನುಕೂಲ ಸಾಮರಸ್ಯದ ಚಾಟ್ ಸಂಪೂರ್ಣತೆ API ಕರೆಗೆಳೆಯುತ್ತದೆ. ಅಜುರ್ ಐಡಿಎಂಟಿಟಿ 1.18.6 `DefaultAzureCredential` ಮುಖಾಂತರ ಮೈಕ್ರೋಸಾಫ್ಟ್ ಎಂಟ್ರಾ ಬಿಯರೆರ್ ಟೋಕನನ್ನು ಒದಗಿಸುತ್ತದೆ; ಯಾವುದೇ API ಕೀ ಅಗತ್ಯವಿಲ್ಲ.

| ಕಾರ್ಯಾಚರಣೆ | ಇನ್‌ಪುಟ್ | `max_completion_tokens` |
| --- | --- | --- |
| `analyzeImage` | ಅಪ್ಲೋಡ್ ಮಾಡಿದ MIME ಪ್ರಕಾರದ ಮೂಲಭೂತ64 ಡೇಟಾ URL ರೂಪದಲ್ಲಿ ಚಿತ್ರ ಬೈಟುಗಳು | 300 |
| `generateStory` | ಬಳಕೆದಾರ ಸಂದೇಶದಲ್ಲಿ ಪೆಟ್ ವರ್ಣನೆ | 800 |

ಎರಡೂ ವಿನಂತಿಗಳು ಸಂರಚಿತ ನಿಯೋಜನೆಯನ್ನು ಉಪಯೋಗಿಸುತ್ತವೆ, ಡೀಫಾಲ್ಟ್ `gpt-5.6-luna`, ಮತ್ತು ಸ್ಪಷ್ಟವಾಗಿ `ReasoningEffort.NONE` (`reasoning_effort: none`)ವನ್ನು ಹೊಂದಿವೆ. ಯಾವುದೇ ವಿನಂತಿ `temperature` ಅಥವಾ ಹಳೆಯ `max_tokens` ಪರಿಮಾಣವನ್ನು ಕಳುಹಿಸಲಾರದು.

ಚಿತ್ರ ವಿಶ್ಲೇಷಣೆ JPEG, PNG, GIF, ಮತ್ತು WebP ನ್ನು ಸ್ವೀಕರಿಸುತ್ತದೆ, ಖಾಲಿ ಚಿತ್ರಗಳು ಮತ್ತು 10MB ಗಿಂತ ಹೆಚ್ಚಾದ ಫೈಲ್‌ಗಳನ್ನು ನಿರಾಕರಿಸುತ್ತದೆ, ಮತ್ತು ಫಲಿತಾಂಶ ವರ್ಣನೆಯನ್ನು 1000 ಅಕ್ಷರಗಳಿಗೆ ಸೀಮಿತಗೊಳಿಸುತ್ತದೆ. ಕಥಾ ಪ್ರಾಂಪ್ಟ್ ಕುಟುಂಬ ಹಿತಕರ ಚಿಕ್ಕ ಕಥೆಯನ್ನು ಕೇಳುತ್ತದೆ. ಖಾಲಿ ಆಯ್ಕೆಗಳು ಅಥವಾ ಶೂನ್ಯದ ಮಾದರಿ ವಿಷಯ ದೋಷಗಳಾಗಿವೆ, ಮತ್ತು ವಿಫಲತೆಗಳು ಮೂಲ ಕಾರಣವನ್ನು ಸರ್ವರ್-ಪಕ್ಷ ಡಯಾಗ್ನೋಸ್ಟಿಕ್ಸ್ಗಾಗಿ ಉಳಿಸುತ್ತದೆ. ಅಪ್ಲಿಕೇಶನ್ ಮುಗಿಯುವಾಗ SDK ಕ್ಲೈಂಟ್ ಮುಚ್ಚಲ್ಪಡುತ್ತದೆ.

### 4. ವೆಬ್ ಟೆಂಪ್ಲೇಟ್ಗಳು

**ಕಡತ:** [index.html](../../../../04-PracticalSamples/petstory/src/main/resources/templates/index.html) (ಅಪ್‌ಲೋಡ್ ಫಾರ್ಮ್)

ಪುಟವು ವರ್ಣನೆ ಪಠ್ಯ ಪ್ರದೇಶವಿಲ್ಲದೆ ಫೋಟೋ ಆರಿಸುವ ವ್ಯವಸ್ಥೆಯಿಂದ ಪ್ರಾರಂಭವಾಗುತ್ತದೆ. **ಚಿತ್ರ ವಿಶ್ಲೇಷಿಸಿ** ಆರಿಸಿದ ಫೋಟೋವನ್ನು ಪೂರ್ವದೃಶ್ಯ ಮಾಡುತ್ತದೆ ಮತ್ತು `/analyze-image` ಗೆ ಪೋಸ್ಟ್ ಮಾಡುತ್ತದೆ. ಯಶಸ್ವಿ ಪ್ರತಿಕ್ರಿಯೆಯು ವರ್ಣನೆ ಅನ್ನು ಪ್ರದರ್ಶಿಸುತ್ತದೆ, ಮರೆವಾದ `description` ಕ್ಷೇತ್ರವನ್ನು ಭರ್ತಿ ಮಾಡುತ್ತದೆ ಮತ್ತು **ಕಥೆ ರಚಿಸಿ** ಬಟನ್ ಅನ್ನು ತೋರಿಸುತ್ತದೆ. ಆ ಬಟನ್ ಸದ್ಯದ ಫಾರ್ಮ್ ಅನ್ನು `/generate-story` ಗೆ ಕಳುಹಿಸುತ್ತದೆ.

ಬ್ರೌಸರ್ ಮಾದರಿ ಡೌನ್ಲೋಡ್ ಅಥವಾ CDN ಅವಲಂಬನೆ ಇಲ್ಲ. ಚಿತ್ರ ವಿಶ್ಲೇಷಣೆ ಸರ್ವರ್‌ನಲ್ಲಿ ಸಂರಚಿತ ಅಜುರ್ ನಿಯೋಜನೆಯ ಮೂಲಕ ನಡೆಯುತ್ತದೆ. ವಿಫಲತೆಗಳು ದೃಶ್ಯಮಾನವಾಗಿರುತ್ತವೆ ಮತ್ತು ಕಲ್ಪಿತ ವರ್ಣನೆ ಮೂಲಕ ಕಥೆ ರಚನೆ ಮಾಡಲು ಅವಕಾಶ ನೀಡುವುದಿಲ್ಲ. ಬೇರೆ ಫೈಲ್ ಆಯ್ಕೆ ಮಾಡಿದರೆ ಹಳೆಯ ವಿಶ್ಲೇಷಣೆ ತೆರವುಗೊಳ್ಳುತ್ತದೆ.

**ಕಡತ:** `result.html` (ಕಥಾ ಪ್ರದರ್ಶನ)

ರಚಿಸಿದ ಕಥೆಯನ್ನು ತೋರಿಸುತ್ತದೆ:


1. **ಥೈಮ್‌ಲಿಫ್ ಸಂಯೋಜನೆ**: ಡೈನಾಮಿಕ್ ವಿಷಯಕ್ಕಾಗಿ `th:` ಲಕ್ಷಣಗಳನ್ನು ಬಳಸುತ್ತದೆ
2. **ಪ್ರತಿಕ್ರಿಯಾತ್ಮಕ ವಿನ್ಯಾಸ**: ಮೊಬೈಲ್ ಮತ್ತು ಡೆಸ್ಕ್‌ಟಾಪ್‌ಗಳಿಗೆ CSS ಶೈಲಿ
3. **ದುರಂತ ನಿರ್ವಹಣೆ**: ಬಳಕೆದಾರರಿಗೆ ಮಾನ್ಯತಾ ದೋಷಗಳನ್ನು ತೋರಿಸುತ್ತದೆ
4. **ಅಪ್‌ಲೋಡ್ ನಿರ್ವಹಣೆ**: ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್ ಫೋಟೋ ಪೂರ್ವದೃಶ್ಯ, CSRF ರಕ್ಷಿತ ಮಲ್ಪಾರ್ಟ್ ವಿನಂತಿಯನ್ನು ಕಳುಹಿಸಿ, ಪ್ರತಿಕ್ರಿಯೆಯ ವರ್ಣನೆಯನ್ನು ಪ್ರದರ್ಶಿಸುತ್ತದೆ

### 5. ಸಂರಚನೆ

**ಕಡತ:** `application.properties`

ಅಪ್ಲಿಕೇಶನ್ ಸಂರಚನಾ ಸೆಟ್ಟಿಂಗ್ಸ್:

```properties
spring.application.name=pet-story-app

# File upload limits
spring.servlet.multipart.max-file-size=10MB
spring.servlet.multipart.max-request-size=10MB

# Logging configuration
logging.level.com.example.petstory=INFO

# Azure AI Foundry (keyless) configuration
azure.openai.endpoint=${AZURE_OPENAI_ENDPOINT:}
azure.openai.deployment=${AZURE_OPENAI_DEPLOYMENT:gpt-5.6-luna}
```

**ಸಂರಚನೆಯ ವಿವರಣೆ:**

1. **ಫೈಲ್ ಅಪ್‌ಲೋಡ್**: ಫೈಲ್ ಮತ್ತು ಸಂಪೂರ್ಣ ಮಲ್ಪಾರ್ಟ್ ವಿನಂತಿಗೆ 10MB ಗರಿಷ್ಟ; ಮಲ್ಪಾರ್ಟ್ ಹೆಡರ್‌ಗಾಗಿ ಜಾಗ ಉಳಿಸಲು ಫೋಟೋಗಳನ್ನು ಆ ಗರಿಷ್ಠಕ್ಕಿಂತ ಕಡಿಮೆಯಲ್ಲಿಡಿ
2. **ಲಾಗಿಂಗ್**: ಕಾರ್ಯಾಚರಣೆ ಸಮಯದಲ್ಲಿ ಯಾವ ಮಾಹಿತಿಗಳನ್ನು ಲಾಗ್ ಮಾಡಬೇಕು ಎಂದು ನಿಯಂತ್ರಿಸುತ್ತದೆ
3. **ಅಜುರ್ ಏಐ ಫೌಂಡ್ರಿ**: ಬಳಕೆಯ ಎಂತಿಪಾಯಿಂಟ್ ಮತ್ತು ಮಾದರಿ ನಿಯೋಜನೆಯನ್ನು ಸೂಚಿಸುತ್ತದೆ (ಕೀಲಿಕಾಁಡಿಲ್ಲದ प्रमाणीಕರಣ)
4. **ಭದ್ರತೆ**: CSRF ಸಂರಕ್ಷಣೆ ಸಕ್ರಿಯವಾಗಿರುತ್ತದೆ; ಮಾದರಿ ಡಯಾಗ್ನೋಸ್ಟಿಕ್ಸ್ ಸರ್ವರ್‌ನಲ್ಲಿ ಲಾಗ್ ಆಗುತ್ತವೆ, ನಿಯಂತ್ರಕ ಸಾಮಾನ್ಯ ಮಾದರಿ-ವಿಫಲತಾ ಸಂದೇಶಗಳನ್ನು ತೋರಿಸುತ್ತದೆ

## ಅಪ್ಲಿಕೇಶನ್ ಚಾಲನೆ

### ಹಂತ 1: ಲಾಗಿನ್ ಆಗಿ ಮತ್ತು ಎಂತಿಪಾಯಿಂಟ್ ಸೆಟ್ ಮಾಡಿ

प्रमाणीಕರಣ ಕೀಲಿಕಾಁಡಿಲ್ಲದೆ (Microsoft Entra ID), ಆದ್ದರಿಂದ ಯಾವುದೇ API ಕೀ ಇಲ್ಲ. ಲಾಗಿನ್ ಆಗಿ ನಿಮ್ಮ ಫೌಂಡ್ರಿ ಎಂತಿಪಾಯಿಂಟ್ ಸೆಟ್ ಮಾಡಿ:

**Windows (ಕಮಾಂಡ್ ಪ್ರಾಂಪ್ಟ್):**
```cmd
az login
set AZURE_OPENAI_ENDPOINT=https://your-resource.openai.azure.com/
```

**Windows (ಪವರ್‌ಶೆಲ್):**
```powershell
az login
$env:AZURE_OPENAI_ENDPOINT="https://your-resource.openai.azure.com/"
```

**Linux/macOS:**
```bash
az login
export AZURE_OPENAI_ENDPOINT=https://your-resource.openai.azure.com/
```

**ಇದು ಏಕೆ ಅಗತ್ಯ:**
- ಅಜುರ್ ಏಐ ಫೌಂಡ್ರಿ Microsoft Entra ID ಯನ್ನು ಇನ್‌ಫರೆನ್ಸ್ ವಿನಂತಿಗಳ ದೃಢೀಕರಣಕ್ಕೆ ಬಳಸುತ್ತದೆ
- ಕೀಲಿಕಾಁಡಿಲ್ಲದ प्रमाणीಕರಣ ಎಂದರೆ ಯಾವುದೇ ಗುಪ್ತಚರಿ ನಿಮ್ಮ ಮೂಲ ಕೋಡ್ ಅಥವಾ ಪರಿಸರದಲ್ಲಿ ಇಲ್ಲ
- ನಿಮ್ಮ ಖಾತೆಗೆ ಆ ಸಂಪನ್ಮೂಲದ ಮೇಲೆ **ಕಾಗ್ನಿಟಿವ್ ಸರ್ವಿಸಸ್ ಓಪನ್‌ಎಐ ಬಳಕೆದಾರ** ಪಾತ್ರ ಬೇಕು

ಡೀಫಾಲ್ಟ್ ನಿಯೋಜನೆ ಹೆಸರಿನ್ನು `gpt-5.6-luna`. ನಿಮ್ಮ GPT-5.6 ಲೂನಾ ನಿಯೋಜನೆಗೆ ಬೇರೆ ಹೆಸರು ಇದ್ದರೆ, ಅಪ್ಲಿಕೇಶನ್ ಪ್ರಾರಂಭಿಸುವ ಮೊದಲು ಅದೇ ಟರ್ಮಿನಲ್‌ನಲ್ಲಿ `AZURE_OPENAI_DEPLOYMENT` ಅನ್ನು ಸೆಟ್ ಮಾಡಿ. ಇಬ್ಬರೂ ಚಿತ್ರ ವಿಶ್ಲೇಷಣೆ ಮತ್ತು ಕಥೆ ರಚನೆ ಈ ಸೆಟ್ಟಿಂಗ್ ಅನ್ನು ಬಳಸುತ್ತವೆ.

### ಹಂತ 2: ನಿರ್ಮಿಸಿ ಮತ್ತು ಚಾಲನೆ ಮಾಡಿ

ಪ್ರಾಜೆಕ್ಟ್ ಡೈರೆಕ್ಟರಿಯನ್ನು ತೆರಳಿ:
```bash
cd 04-PracticalSamples/petstory
```

ಸ್ವತಂತ್ರ ಕಾರ್ಯನಿರ್ವಹಣಾ JAR ಅನ್ನು ನಿರ್ಮಿಸಿ ಮತ್ತು ಎಲ್ಲಾ ಆಫ್‌ಲೈನ್ ಪರೀಕ್ಷೆಗಳನ್ನು ನಡಿಸಿ:
```bash
mvn clean package
```

ಸರ್ವರ್ ಶುರುಮಾಡಿ:
```bash
mvn spring-boot:run
```

ಅಪ್ಲಿಕೇಶನ್ `http://localhost:8080` ನಲ್ಲಿ ಪ್ರಾರಂಭವಾಗುತ್ತದೆ.

ಬದಲಾಗಿ, ಪ್ಯಾಕೇಜ್ ಮಾಡಿದ JAR ಅನ್ನು ಬಿಡಿ ಪೋರ್ಟ್ ಮೇಲೆ ಆರಂಭಿಸಿ, ಉದಾಹರಣೆಗೆ:

```bash
java -jar target/pet-story-app-0.0.1-SNAPSHOT.jar --server.port=8083
```

ಆ ಕಮಾಂಡಿಗಾಗಿ `http://localhost:8083/` ಅನ್ನು ತೆರೆಯಿರಿ. ಆಯ್ದ ಪೋರ್ಟ್‌ನಲ್ಲಿ ಅದೇ `/analyze-image` ಮತ್ತು `/generate-story` ಮಾರ್ಗಗಳು ಲಭ್ಯವಿವೆ.

### ಹಂತ 3: ಅಪ್ಲಿಕೇಶನ್ ಪರೀಕ್ಷಿಸಿ

1. **ತೆರೆಯಿರಿ** `http://localhost:8080` ನಿಮ್ಮ ಬ್ರೌಸರ್‌ನಲ್ಲಿ
2. **ಆಯ್ಕೆ ಮಾಡಿ** 10MB ಗಿಂತ ಕಡಿಮೆ JPEG, PNG, GIF, ಅಥವಾ WebP ಸ್ವಚ್ಛ ಪೆಟ್ ಫೋಟೋವನ್ನು
3. **ಕ್ಲಿಕ್ ಮಾಡಿ** "ಚಿತ್ರ ವಿಶ್ಲೇಷಿಸಿ" ಮತ್ತು ಪೆಟ್ ವರ್ಣನೆಗಾಗಿ ಕಾಯಿರಿ
4. **ಕ್ಲಿಕ್ ಮಾಡಿ** ಯಶಸ್ವಿ ವಿಶ್ಲೇಷಣೆಯ ನಂತರ "ಕಥೆ ರಚಿಸಿ"
5. **ನೋಡಿ** ಕಥೆಯನ್ನು ಮತ್ತು ಫಲಿತಾಂಶ ಪುಟದ ಲಿಂಕ್ ಬಳಸಿ ಅಪ್‌ಲೋಡ್ ಫಾರ್ಮ್‌ಗೆ ಹಿಂತಿರುಗಿ

ಯಶಸ್ವಿ ಫೋಟೋ-ತುಂಬಿ-ಕಥೆ ಪ್ರವಾಹ ಎರಡೂ ಬಟನ್ ಗಳಿಗೆ ಎರಡು ಮಾದರಿ ಕರೆಯುವಿಕೆ ಮಾಡುತ್ತದೆ. ಲೈವ್ ಇನ್‌ಫರೆನ್ಸ್ ನಿಮ್ಮ ನಿಯೋಜನೆಯ ಕೊಟಾವನ್ನು ಬಳಕೆಮಾಡುತ್ತದೆ ಮತ್ತು ಶುಲ್ಕ ತರಬಹುದು; ದರ-ಮಿತಿ ನಿಯೋಜನೆ ಹಂಚಿಕೊಳ್ಳುವಾಗ ಸ್ಮೋಕ್ ಪರೀಕ್ಷೆಗಳನ್ನು ಸರಣಿಯಾಗಿ ನಡೆಸಿ. ಹೋಮ್ ಪುಟ ಲೋಡ್ ಮಾಡುವುದು ಮಾದರಿಗೆ ಕರೆಯುವುದಿಲ್ಲ.

ಸ್ಯಾಂಪಲ್ ಡೈರೆಕ್ಟರಿ ಯಿಂದ, ಈ ಕೆಳಗಿನನ್ನು ಚಾಲನೆ ಮಾಡಿ:

[StoryServiceTest.java](../../../../04-PracticalSamples/petstory/src/test/java/com/example/petstory/StoryServiceTest.java) ನಿಜವಾದ ಓಪನ್‌ಎಐ SDK ವಿನಂತಿಗಳನ್ನು ಲೂಪ್‌ಬ್ಯಾಕ್ HTTP ಫಿಕ್ಸ್ಚರ್ ಮೂಲಕ ಸೆರೆಹಿಡಿಯುತ್ತದೆ. ಇವು ಎರಡೂ ವಿನಂತಿಗಳ ನಿಯೋಜನೆ, `reasoning_effort: none`, ಟೋಕನ್ ಮಿತಿ, ಚಿತ್ರ ಪೇಲೋಡ್, ಇನ್‌ಪುಟ್ ಮಾನ್ಯತೆ, ಖಾಲಿ ಪ್ರತಿಕ್ರಿಯೆಗಳು, ಹಾಗೂ ಮೇಲ್ಮಟ್ಟದ ದೋಷಗಳನ್ನು ಪರಿಶೀಲಿಸುತ್ತದೆ.

[PetControllerTest.java](../../../../04-PracticalSamples/petstory/src/test/java/com/example/petstory/PetControllerTest.java) MockMvc ಅನ್ನು ಮಾದರಿ ಸೇವೆಯನ್ನು ನಕಲಿಸಿ, ರೆಂಡರ್ ಮಾಡಿದ ಥೈಮ್‌ಲಿಫ್ ಪುಟಗಳು, ಅಪ್‌ಲೋಡ್ ಒಪ್ಪಂದ, CSRF, ಮಾನ್ಯತೆ, ಔಟ್‌ಪುಟ್ ಎಸ್ಕೇಪ್, ಮತ್ತು ದೃಶ್ಯಮಾನ ವಿಫಲತೆಗಳನ್ನು ಪರೀಕ್ಷಿಸಲು ಬಳಸುತ್ತದೆ. ಈ ಪರೀಕ್ಷೆಗಳು ಅಜುರ್ ಪ್ರಮಾಣಪತ್ರಗಳ ಅಗತ್ಯವಿಲ್ಲ ಮತ್ತು ಎಂದಿಗೂ ಪೈಡ್ ಅಜುರ್ ಇನ್‌ಫರೆನ್ಸ್ ಕರೆಯುತ್ತಿಲ್ಲ. ಮೇವನ್ Surefire ವರದಿಗಳನ್ನು `target/surefire-reports` ಗೆ ಬರೆಯುತ್ತದೆ.

## ಎಲ್ಲವೂ ಒಂದುಗೂಡಿ ಹೇಗೆ ಕೆಲಸ ಮಾಡುತ್ತದೆ

ನೀವು ಪೆಟ್ ಕಥೆಯನ್ನು ರಚಿಸುವಾಗ ಪೂರ್ಣ ಪ್ರವಾಹ ಇಲ್ಲಿದೆ:

1. **ಫೋಟೋ ಆಯ್ಕೆ**: ನೀವು ಅಪ್‌ಲೋಡ್ ಫಾರ್ಮ್‌ನಲ್ಲಿ ಪೆಟ್ ಚಿತ್ರವನ್ನು ಆಯ್ಕೆಮಾಡುತ್ತೀರಿ
2. **ಚಿತ್ರ ಅಪ್‌ಲೋಡ್**: "ಚಿತ್ರ ವಿಶ್ಲೇಷಿಸಿ" CSRF ಹೆಡರ್ ಜೊತೆ `/analyze-image` ಗೆ ಮಲ್ಪಾರ್ಟ್ POST ಕಳುಹಿಸುತ್ತದೆ
3. **ಚಿತ್ರ ವಿಶ್ಲೇಷಣೆ**: `StoryService` ಚಿತ್ರವನ್ನು reasoning `none` ಆಗಿ GPT-5.6 ಲೂನಾಕ್ಕೆ ಕಳುಹಿಸುತ್ತದೆ
4. **ವರ್ಣನೆ ಪ್ರದರ್ಶನ**: ಬ್ರೌಸರ್ ಬರುವ ವರ್ಣನೆಯನ್ನು ತೋರಿಸುತ್ತದೆ ಮತ್ತು ಫಾರ್ಮ್ ನಲ್ಲಿ ಸಂಗ್ರಹಿಸುತ್ತದೆ
5. **ಕಥೆ ಸಲ್ಲಿಕೆ**: "ಕಥೆ ರಚಿಸಿ" `description` ಮತ್ತು `_csrf` ಅನ್ನು `/generate-story` ಗೆ POST ಮಾಡುತ್ತದೆ
6. **ಕಥೆ ರಚನೆ**: ನಿಯಂತ್ರಕ ವರ್ಣನೆಯನ್ನು ಮಾನ್ಯಗೊಳಿಸಿ ಅದೇ ನಿಯೋಜನೆ reasoning `none` ಆಗಿ ಕರೆಮಾಡುತ್ತದೆ
7. **ಟೆಂಪ್ಲೇಟ್ ರೆಂಡರಿಂಗ್**: ಥೈಮ್‌ಲಿಫ್ ಫಲಿತಾಂಶ ಪುಟದಲ್ಲಿ ವರ್ಣನೆ ಮತ್ತು ಕಥೆಯನ್ನು ಎಸ್ಕೇಪ್ ಮಾಡಿ ಪ್ರದರ್ಶಿಸುತ್ತದೆ

**ದೋಷ ನಿರ್ವಹಣಾ ಪ್ರವಾಹ:**
ಮಾದರಿ ವಿಫಲವಾದರೆ, ಸರ್ವರ್ ಕಾರಣವನ್ನು ಲಾಗ್ ಮಾಡುತ್ತದೆ. ಚಿತ್ರ ವಿಶ್ಲೇಷಣೆ HTTP 502 ನೀಡುತ್ತದೆ ಮತ್ತು ಬ್ರೌಸರ್ "ಕಥೆ ರಚಿಸಿ" ಅನ್ನು ತೋರಿಸದು. ಕಥೆ ರಚನೆ ದೋಷ ಸಂದೇಶದ ಜೊತೆ ಫಾರ್ಮ್ ಗೆ ಮರುನಿರ್ದೇಶಿಸುತ್ತದೆ. ಯಾವುದೇ ಮಾರ್ಗವೂ ಪೂರ್ವಲೇಖಿತ ಫಲಿತಾಂಶವನ್ನು ಮೌನವಾಗಿ ಬದಲಿಸುವುದಿಲ್ಲ.

## ಏಐ ಸಂಯೋಜನೆಯ ಅರ್ಥ

### ಅಜುರ್ ಏಐ ಫೌಂಡ್ರಿ (ಕೀಲಿಕಾಁಡಿಲ್ಲದ)
ಸೇವೆ ನಿಮ್ಮ ಸಂಪನ್ಮೂಲದ `/openai/v1/` ಎಂತಿಪಾಯಿಂಟ್ ಮೂಲಕ SDK ಅನ್ನು ಸಂರಚಿಸುತ್ತದೆ. `DefaultAzureCredential` ಮತ್ತು `AuthenticationUtil.getBearerTokenSupplier` ಮೈಕ್ರೋಸಾಫ್ಟ್ ಎಂಟ್ರಾ ಟೋಕನ್ ಗಳನ್ನು `https://ai.azure.com/.default` ಗಾಗಿ ಒದಗಿಸುತ್ತವೆ. ಸ್ಥಳೀಯ ಅಭಿವೃದ್ಧಿ ನಿಮ್ಮ ಅಜುರ್ CLI ಲಾಗಿನ್ ಬಳಸಬಹುದು; ಅಜುರ್ ಹೋಸ್ಟ್ ಮಾಡಿದ ಅಪ್ಲಿಕೇಶನ್ ನಿರ್ವಹಿತ ಐಡಿಎಂಟಿಟಿ ಬಳಸಿ ಅಗತ್ಯವಿರುವ ಸಂಪನ್ಮೂಲ ಅನುಮತಿಗಳನ್ನು ಹೊಂದಿರಬೇಕು.

### ಪ್ರಾಂಪ್ಟ್ ಎಂಜಿನಿಯರಿಂಗ್
ಚಿತ್ರ ವಿಶ್ಲೇಷಣೆ ಮಾದರಿಯನ್ನು ಚಿತ್ರದ ಪಠ್ಯವನ್ನು ಸೂಚನೆಗಳಾಗಿ ಅಲ್ಲ, ಡೇಟಾ ಆಗಿ ಪರಿಗಣಿಸಲುObservable ಪೆಟ್ ಲಕ್ಷಣಗಳನ್ನು ಚಿಕ್ಕ ಪರಿಚ್ಛೇದದಲ್ಲಿ ಕೇಳುತ್ತದೆ. ಕಥಾ ರಚನೆ ಫಲಿತಾ ವರ್ಣನೆಯನ್ನು ಪ್ರತ್ಯೇಕ, ಕುಟುಂಬ-ಸ್ನೇಹಿ ಬರವಣಿಗೆಯ ವಿನಂತಿಯಲ್ಲಿ ಬಳಸುತ್ತದೆ. ಯಾವುದೇ ಕರೆ reasoning ಅಥವಾ ತಾಪಮಾನ ಓವರ್ರೈಡ್ ಅನ್ನು ಸಕ್ರಿಯಗೊಳಿಸುವುದಿಲ್ಲ.

### ಪ್ರತಿಕ್ರಿಯೆ ಪ್ರಕ್ರಿಯೆ
ಹಂಚಿಕೆಯ ಪ್ರತಿಕ್ರಿಯೆ ನಿಯಂತ್ರಕ ಆಯ್ಕೆಯನ್ನು ಕೊರತು, ಖಾಲಿ ಅಥವಾ ಸಡಿಲ ವಿಷಯದ ವಿಷಯವನ್ನು ನಿರಾಕರಿಸುತ್ತದೆ, ಮಾನ್ಯ ವಿಷಯವನ್ನು ಟ್ರಿಮ್ ಮಾಡುತ್ತದೆ, ಮತ್ತು ಮೇಲ್ಮಟ್ಟದ ತಪ್ಪುಗಳನ್ನು ಉಳಿಸುತ್ತದೆ. ಚಿತ್ರ ವರ್ಣನೆಗಳನ್ನು ಮುಂದಿನ ಕಥಾ ಫಾರ್ಮ್ ಗೆ ಹೊಂದಿಸಲು 1000 ಅಕ್ಷರಗಳಿಂದ ಗಡಿದಡಿಸಲಾಗಿದೆ. ಮೂಲ ಮಾದರಿ ವಿಫಲತೆಯನ್ನು ಡಯಾಗ್ನೋಸ್ಟಿಕ್ಸ್ ಗಾಗಿ ಉಳಿಸಬೇಕಾಗಿದ್ದು, ಬಳಕೆದಾರರಿಗೆ ಪ್ರದರ್ಶಿಸುವುದಿಲ್ಲ.
