# Azure AI Foundry க்கான மேம்பாட்டுச் சூழலை அமைத்தல்

> இந்த வழிகாட்டி இந்த படிப்பில் உள்ள ஜவா AI செயலிகளுக்கான **Azure AI Foundry** மாதிரிகள் **கீ இல்லாத** அங்கீகாரத் (Microsoft Entra ID) மூலம் அமைக்கிறது — API விசைகள் நிர்வகிக்க தேவையில்லை. கருவியுடன் புதியவரா? [மேம்பாட்டு சூழல் வழிகாட்டி](./README.md) மூலம் தொடங்கவும்.

இந்த வழிகாட்டி இந்த படிப்பின் ஜவா AI செயலிகளுக்கான **Azure AI Foundry** மாதிரிகளை அமைக்கிறது. உங்களுக்கு இரண்டு பாதைகள் உள்ளன:

- **விருப்பம் A — `azd` + Bicep கொண்டு வழங்குக (பரிந்துரைக்கப்பட்டது):** ஒரு கட்டளையால் Foundry கணக்கு மற்றும் மாதிரிகள் குறியீடாக வெளியீடு செய்யப்படும். எந்த போர்டல் கிளிக்குதலும் இல்லை.
- **விருப்பம் B — Azure AI Foundry போர்டலில் வளங்களை கையால் உருவாக்குக.**

இரு பாதைகளும் **கீ இல்லாத அங்கீகாரம்** (Microsoft Entra ID) பயன்படுத்துகிறது — API விசைகளை நகலெடுக்க அல்லது வெளியிட தேவையில்லை.

## என்ன உருவாக்கப்படுகிறது

[`infra/`](../../../02-SetupDevEnvironment/infra) உள்ள Bicep வார்ப்புருக்கள் வழங்குகிறது:

- **Azure AI Foundry** கணக்கு (`Microsoft.CognitiveServices/accounts`, வகை `AIServices`) ஒரு திட்டத்துடன்
- ஒரு **சோட்** தளவமைப்பு - GPT-5.6 Luna (`gpt-5.6-luna`), பதிப்பு `2026-07-09`, `GlobalStandard` திறன் `10` (இந்த மாதிரிக்கான 10 கோரிக்கைகள்/நிமிடம் மற்றும் 10,000 டோக்கன்கள்/நிமிடம்)
- ஒரு **embedding** தளவமைப்பு - `text-embedding-3-small`, பதிப்பு `1` (பிற அத்தியாயங்களில் பயன்படுத்தப்படும்)
- **கீ இல்லாத வேடிக்கை ஒதுக்கீடு** (`Cognitive Services OpenAI User`), அதனால் `az login` கொண்டு உள்நுழையலாம்; விசைகளை நிர்வகிக்க தேவையில்லை

## முன் நிபந்தனைகள்

- ஒரு [Azure சந்தா](https://azure.microsoft.com/free/)
- [Azure Developer CLI (`azd`)](https://aka.ms/azure-dev/install)
- [Azure CLI (`az`)](https://learn.microsoft.com/cli/azure/install-azure-cli)

## விருப்பம் A: azd + Bicep கொண்டு வழங்கல் (பரிந்துரைக்கப்பட்டது)

`02-SetupDevEnvironment` கோப்புறையிலிருந்து:

```bash
cd 02-SetupDevEnvironment

# கையொப்பமிடுக (இரு கருவிகளுக்கும்)
azd auth login
az login

# Foundry கணக்கையும் மாதிரிகளில் இடைநிறுத்தத்தையும் ஏற்பாடு செய்க
azd up
```

`azd` ஒரு **சூழல் பெயர்** (எ.கா., `genai-java`), **சந்தா**, மற்றும் **பகுதி** கேட்கிறது. உங்கள் சொந்த சந்தாவையும் `gpt-5.6-luna` மற்றும் `text-embedding-3-small` கிடைக்கக்கூடிய பகுதியையும் தேர்வு செய்யவும், உதாரணமாக `eastus2`. அந்த பகுதியில் மாதிரி மற்றும் தளவமைப்புக்கு தேவையான போத்தையை சந்தா கொண்டுள்ளதா என்பதை உறுதி செய்யவும்; கிடைக்கும் மற்றும் போத்தை சந்தா வாரியாக மாறுபடுகிறது.

வழங்கல் முடிந்தபின், azd:

1. [`infra/main.bicep`](../../../02-SetupDevEnvironment/infra/main.bicep) இல் உள்ள எல்லாவற்றையும் வெளியிடுகிறது.
2. உங்கள் தொடரமைப்பு மற்றும் தளவமைப்பு பெயர்களுடன் (ரகசியங்கள் இல்லாமல்) [`examples/basic-chat-azure/.env`](../../../02-SetupDevEnvironment/examples/basic-chat-azure) எழுதும் ஒரு postprovision ஹூக்கை இயக்குகிறது.

> **குறிப்பு:** மாற்றங்களைச் செயல்படுத்த எப்போது வேண்டுமானாலும் `azd up` ஐ மீண்டும் இயக்கவும். எல்லாவற்றையும் நீக்க `azd down` ஐ இயக்கவும், செலவுகளை நிறுத்த.

உருவாக்கப்பட்ட அமைப்புகளை பார்க்க:

```bash
azd env get-values
```

இப்போது [உங்கள் அமைப்பை சோதிக்கவும்](#உங்கள்-அமைப்பை-சோதிக்கவும்) பகுதியுக்கு தள்ளி செல்லவும்.

## விருப்பம் B: வளங்களை கையால் உருவாக்குக

போர்டலை விரும்புகிறீர்களா? வளங்களை கையால் உருவாக்க:

1. [Azure AI Foundry போர்டல்](https://ai.azure.com/) க்கு செல்லுங்கள் மற்றும் உள்நுழையுங்கள்.
2. **ஒரு திட்டத்தை உருவாக்கவும்** (இதுவும் AI Foundry வளத்தை உருவாக்கும்). அதை `GenAIJava` போன்ற பெயரிடுங்கள்.
3. உங்கள் திட்டத்தில், **Models + endpoints** → **Deploy model** → **Deploy base model** என்பதனை திறக்கவும்.
4. **GPT-5.6 Luna** (மாதிரி மற்றும் தளவமைப்பு பெயர் `gpt-5.6-luna`, பதிப்பு `2026-07-09`) `Global Standard` திறன் `10` உடன் வெளியிடவும். embedding எடுத்துக்காட்டுகளுக்கான **text-embedding-3-small**, பதிப்பு `1` க்கும் இதை மீண்டும் செய்யவும்.
5. **Overview** இல் இருந்து **endpoint** ஐ நகலெடுக்கவும் (எ.கா., `https://<resource>.openai.azure.com/`).
6. கீ இல்லாத அணுகலை நீங்களே தருங்கள்: வளத்தில், **Access control (IAM)** → **Add role assignment** → உங்கள் கணக்குக்கு **Cognitive Services OpenAI User** வேடிக்கையை ஒதுக்கவும்.

> **சிக்கல்களை தொடர்ந்தும் எதிர்கொள்கிறீர்களா?** [Azure AI Foundry ஆவணத்தை](https://learn.microsoft.com/azure/ai-foundry/how-to/create-projects) பார்க்கவும்.

## உங்கள் சூழலை கட்டமைக்கவும்

**நீங்கள் விருப்பம் A (`azd up`) பயன்படுத்தினால்,** உங்கள் அமைப்பு கோப்பு ஏற்கனவே எழுதப்பட்டுள்ளது — எதையும் கட்டமைக்க தேவையில்லை. [உங்கள் அமைப்பை சோதிக்கவும்](#உங்கள்-அமைப்பை-சோதிக்கவும்) நோக்கி தள்ளி செல்லவும்.

**நீங்கள் விருப்பம் B (கையால்) பயன்படுத்தினால்**, எடுத்துக்காட்டின் `.env` கோப்பை நீங்களேயே உருவாக்கவும்:

```bash
cd 02-SetupDevEnvironment/examples/basic-chat-azure
cp .env.example .env
```

`.env` ஐ உங்கள் endpoint இன் விவரங்களுடன் தொகுக்கவும் (கீ இல்லை — அங்கீகாரம் கீ இல்லாதது):

```bash
AZURE_OPENAI_ENDPOINT=https://<your-resource>.openai.azure.com/
AZURE_OPENAI_DEPLOYMENT=gpt-5.6-luna
```

வளத்தின் Azure OpenAI endpoint ஐப் பயன்படுத்தவும், திட்ட URL ஐ அல்ல. basic-chat செயலி அதை `/openai/v1` ஆக தீர்மானித்து ஒரு வெளிப்படையான bearer-token கிளையண்டை அமைக்கிறது; API விசை தேவையில்லை.

> **பாதுகாப்பு குறிப்பு:** சேமிக்க API விசை ஒன்றும் இல்லை. நீங்கள் Microsoft Entra ID மூலம் `az login` (உடன் உள்ளே) அல்லது நிர்வகிக்கப்பட்ட அடையாளம் (Azure இல்) கொண்டு அங்கீகரிக்கிறீர்கள். `.env` கோப்பு ரகசியமற்ற அமைப்புகளைக் கொண்டிருக்கிறது மற்றும் `.gitignore` மூலம் ஏற்கனவே சேமிக்கப்பட்டுள்ளது.

## உங்கள் அமைப்பை சோதிக்கவும்

கீ இல்லாத அங்கீகாரம் டோக்கனைப் பெற நீங்கள் உள்நுழைந்துவிட்டீர்களா என்பதை உறுதி செய்து, எடுத்துக்காட்டை இயக்கவும்:

```bash
cd 02-SetupDevEnvironment/examples/basic-chat-azure

az login          # நீங்கள் ஏற்கனவே உள்நுழையாதிருந்தால்
mvn clean spring-boot:run
```

`gpt-5.6-luna` மாதிரியிலிருந்து பதிலை நீங்கள் காணலாம். சிறிய இயல்புநிலை போத்தையில் உள்ளவரை எடுத்துக்காட்டுகளை வரிசையாக இயக்கவும்; HTTP 429 பெறினால் மீண்டும் முயற்சிக்குமுன் மறுபரிசோதனை இடவை காத்திருக்கவும்.

> **VS Code பயனர்கள்:** இயக்க `F5` அழுத்தவும். செயலி உங்கள் `.env` ஐ தானாக ஏற்றுகிறது.

> **முழு எடுத்துக்காட்டு:** விவரங்கள் மற்றும் குறைபாடுகள் தொடர்பாக [Basic Chat with Azure AI Foundry example](./examples/basic-chat-azure/README.md) பார்க்கவும்.

## அடுத்தது என்ன?

வழங்கலும் எடுத்துக்காட்டை வெற்றிகரமாக இயக்கியதும், நீங்கள் பெற்றிருப்பீர்கள்:
- `gpt-5.6-luna` மற்றும் `text-embedding-3-small` உடன் Azure AI Foundry விநியோகிக்கப்பட்டது
- கீ இல்லாத அங்கீகாரம் (Microsoft Entra ID) — விசைகள் நிர்வகிக்க தேவையில்லை
- உங்கள் endpoint மற்றும் தளவமைப்பு பெயர்களுடன் உள்ளூர் `.env`
- ஒரு ஜவா மேம்பாட்டு சூழல் தயாராக உள்ளது
