## கண்ணோட்டம்

நான்கு தனித்தனி ஜாவா நிரல்கள் உரையாடல், உரையாடல் வரலாறு, செயல்பாடு அழைப்புகள், முழு ஆவணம் பெறுதல்-அதிகரிக்கப்பட்ட உருவாக்கம் (RAG), மற்றும் பொறுப்பான AI பதில் கையாளலை காட்டுகின்றன. அனைத்து உரையாடல் கோரிக்கைகளும் இயல்பாக **GPT-5.6 Luna reasoning effort `none` உடன்** இலக்கு வைக்கப்படுகின்றன.

இந்த எடுத்துக்காட்டுகள் அதிகாரப்பூர்வ OpenAI ஜாவா SDK ஐ Azure OpenAI வின் v1 முடிவுக்குறிப்புடன் பயன்படுத்துகின்றன, [Microsoft இன் SDK வழிகாட்டி](https://learn.microsoft.com/azure/ai-foundry/openai/supported-languages)யின் படி. பழைய `azure-ai-openai` தொகுப்பு இனி சார்பு இல்லை. உரையாடல் முடிப்புகள் மெசேஜ் அடிப்படையிலான பணிகள் கற்கும் பொருட்டு வைக்கப்பட்டுள்ளது; மற்ற API விருப்பங்களுக்கு [OpenAI Java SDK](https://github.com/openai/openai-java#microsoft-azure)யைப் பார்க்கவும்.

## தொடக்கம்

கிடையற்ற மூலதை இடத்திலிருந்து, உங்கள் ஷெல்லில் வள முடிவுக் குறியீட்டிற்கும் விருப்ப பதிப்பு மாற்றத்திற்கும் அமைக்கவும்.

**Windows PowerShell:**

```powershell
$env:AZURE_OPENAI_ENDPOINT = "https://your-resource.openai.azure.com/"
$env:AZURE_OPENAI_DEPLOYMENT = "gpt-5.6-luna"
Set-Location 03-CoreGenerativeAITechniques/examples
mvn -B -ntp clean test
```

**Linux/macOS:**

```bash
export AZURE_OPENAI_ENDPOINT="https://your-resource.openai.azure.com/"
export AZURE_OPENAI_DEPLOYMENT="gpt-5.6-luna"
cd 03-CoreGenerativeAITechniques/examples
mvn -B -ntp clean test
```

சோதனைகள் Azure அங்கீகாரங்களையோ அல்லது ஒரு முடிவுக் குறியீட்டையோ தேவையில்லை. Maven தன்னிச்சையாக சூழ்நிலை கோப்பை வாசிப்பதில்லை; நேரடி எடுத்துக்காட்டுகளை துவங்குவதற்கான ஷெல்லில் மாறில்களை அமைக்கவும். IDE துவக்கங்களுக்கு உங்கள் துவக்க அமைப்பில் வழங்கப்பட்டுள்ள சூழலை சரிபார்க்கவும்.

## மாதிரி தேர்வு வழிகாட்டி

| சுற்றுச்சூழல் மாறிலி | அர்த்தம் | இயல்பு |
| --- | --- | --- |
| `AZURE_OPENAI_ENDPOINT` | HTTPS Azure வள மூலத்தை அல்லது ஏற்கனவே சரிபரவட்ட `/openai/v1` URL | நேரடி இயக்கத்திற்கு அவசியம் |
| `AZURE_OPENAI_DEPLOYMENT` | உரையாடல் பதிப்பு பெயர், மாதிரி பதிப்பு அல்ல | `gpt-5.6-luna` |
| `AZURE_OPENAI_EMBEDDING_DEPLOYMENT` | பிரித்து அமுக்கல் பதிப்பு அமைப்பு, இ நான்கு நிரல்களால் பயன்படுத்தப்படவில்லை | `text-embedding-3-small` |

வெற்று பதிப்பு மாற்றங்கள் இயல்புகளை பயன்படுத்துகின்றன. கட்டமைப்பு `/openai/v1` ஐ சரியாக ஒரு முறை சேர்; அவற்றில் அங்கீகாரங்கள், வினா தொடர்கள் மற்றும் பழைய பதிப்பு பாதைகள் endpoint இல் நிராகரிக்கப்படுகின்றன.

ஒவ்வொரு உரையாடல் கோரிக்கையும் தெளிவாக `reasoningEffort(ReasoningEffort.NONE)` மற்றும் `maxCompletionTokens(...)` ஐ அமைக்கிறது. எந்த கோரிக்கையும் `temperature`, `top_p`, அல்லது பழைய completion-token விருப்பத்தை அமைக்காது. இது கருவி தேர்வு மற்றும் கருவி முடிவு தொடர்வுகளையும் உட்படுகிறது. GPT-5.6 உரையாடல் முடிப்பு செயல்பாடு கருவிகள் reasoning effort `none` தேவை; [Microsoft இன் உரையாடல் வழிகாட்டி](https://learn.microsoft.com/azure/ai-foundry/openai/how-to/chatgpt)வை பார்க்கவும்.

**இந்த அத்தியாயத்தில் நேரலை அல்லது அமுக்கல் நுழைவாயில் இல்லை.** வாசிப்பவர் ஆவணத்தை முழுவதும் பெறுகிறார், வெக்டர்கள் அல்ல. நீங்கள் இதனை அமுக்கல்களுடன் நீட்சிப்பீர்கள் என்றால், `text-embedding-3-small` போன்ற தனித்தனியான அமுக்கல் பதிப்பை பயன்படுத்தவும், Luna ஐவிடாது.

## பயிற்சி 1: LLM முடிப்புகள் மற்றும் உரையாடல்

மூலம்: [LLMCompletionsApp.java](../../../03-CoreGenerativeAITechniques/examples/src/main/java/com/example/genai/techniques/completions/LLMCompletionsApp.java).

நிரல் எளிய ஜாவா ஸ்ட்ரீம்கள் விளக்கம், இரண்டு-முறை HashMap/TreeMap உரையாடல் மற்றும் பரிமாற்ற உரையாடலை இயக்குகிறது. இரண்டாவது முறை முதல் உதவியாளர் பதில் உள்ளது; ஒவ்வொரு பரிமாற்ற முறையும் அதன் முன்னைய உரையாடலை அனுப்புகிறது.

```java
var request = config.chatOptions(200)
        .addSystemMessage("You are a helpful Java expert.")
        .addUserMessage("Explain Java streams briefly.")
        .build();
String answer = ChatResponses.text(client.chat().completions().create(request));
```

`config.chatOptions(...)` பதிப்பின் மற்றும் தெளிவான reasoning அமைப்பை வழங்குகிறது. பரிமாற்ற உரையாடல் வெற்று வரிகளைக் கடக்கிறது, `exit` அல்லது EOF ஐ சந்திப்பது மட்டும் முடிகிறது மற்றும் அமைப்பு செய்தி மற்றும் 9 முடிக்கப்பட்ட பயனர்/உதவியாளர் முறைகளை வைத்திருக்கும். முறை எண்ணிக்கை அமைப்பு கல்வி நோக்கமாகும், துல்லிய டோக்கன் பட்ஜெட் உறுதி அல்ல.

எடுத்துக்காட்டு அடைவில் இருந்து:

```powershell
mvn -ntp compile exec:java "-Dexec.mainClass=com.example.genai.techniques.completions.LLMCompletionsApp"
```

மூன்று ஆரம்ப பதில்களை எதிர்பார்க்கவும், பிறகு `You:` என்ற முன்னெச்சரிக்கை தோற்றம். ஒவ்வொரு தவிர்த்து விடாத பரிமாற்ற கேள்வியும் ஒரு கோரிக்கையே சேர்க்கும். முடிப்பு வரம்புகள் முறையே 200, 300, 400, பிறகு 500 டோக்கன்கள்.

## பயிற்சி 2: செயல்பாடு அழைப்புகள்

மூலம்: [FunctionsApp.java](../../../03-CoreGenerativeAITechniques/examples/src/main/java/com/example/genai/techniques/functions/FunctionsApp.java).

SDK குறியீட்டப்பட்ட `WeatherArguments` மற்றும் `CalculationArguments` பதிவுகளிலிருந்து JSON ஸ்கிமாக்களை உருவாக்குகிறது. கட்டாயமான கருவி தேர்வு ஒவ்வொரு எடுத்துக்காட்டும் கருவி நடைமுறையை பயன்படுத்துவதற்கு உதவுகிறது, மாதிரியின் உதவில்லாத பதிலை ஏற்காது.

1. அனுமதிக்கபட்ட கருவியுடன் கேள்வி அனுப்பு, reasoning effort `none` மற்றும் 300 டோக்கன் முடிப்பு வரம்புடன்.
2. `tool_calls` முடிவு காரணம் தேவை, செயல்பாட்டின் பெயர் மற்றும் அழைப்பு IDகளை சரிபார்க்கவும், வகைகள் செய்யப்பட்ட JSON argumentsஐ பகுப்பாய்வு செய்க.
3. உள்ளூர் செயல்பாட்டை இயக்கு. மாதிரி ஜாவா அல்லது எந்த குறியீட்டையும் இயக்காது.
4. உதவியாளர் கருவி-அழைப்பு செய்தியை ஒரு முறைச் சேர்த்து, பின்னர் ஒவ்வொரு முடிவையும் அதன் பொருந்தும் `tool_call_id` உடன் சேர்க்கவும்.
5. கருவிகள் இல்லாமல் கடைசி 300 டோக்கன் கோரிக்கையை அனுப்பவும் மற்றும் முடித்த, வெறுமை அல்லாத பதிலை எதிர்பார்க்கவும்.

`get_weather` **அண்மையில் பரிமாறப்படும்**, நேரடி இல்லை, காலநிலையை திருப்பி அளிக்கிறது. இது நகரத்தைக் கவனிக்கிறது மற்றும் மாதிரி 22 டிகிரி செல்சியஸ் கேட்டால் பாரன்ஹீட்டுக்கு மாற்றுகிறது. `calculate` வழங்கப்பட்ட வெளிப்பாட்டை exp4j மூலம் மதிப்பீடு செய்கிறது, `15% of 240` மற்றும் `2 + 3 * 4` போன்ற வடிவங்களை ஆதரிக்கிறது; வெற்று, மிகப்பெரிய, தவறான அல்லது முடிவில்லாத கணக்கீடுகளை நிராகரிக்கிறது. இது பிளோட்டிங் புள்ளி கணிதத்தை பயன்படுத்துகிறது, நிதி தசம கணிப்பில்லாது.

```powershell
mvn -ntp compile exec:java "-Dexec.mainClass=com.example.genai.techniques.functions.FunctionsApp"
```

`Function: get_weather`, சிம்யுலேட்டட் சீயாட்டில் காலநிலை, `Function: calculate`, `Function result: 36` மற்றும் இரண்டு இறுதி பதில்களை எதிர்பார்க்கவும். stdin அல்லது வெளிப்புற காலநிலை அங்கீகாரங்கள் தேவையில்லை. வெற்றி பெறும் ஓட்டம் நிச்சயமாக நான்கு உரையாடல் கோரிக்கைகளைப் பயன்படுத்தும்.

## பயிற்சி 3: RAG (பெறுதல்-அதிகரிக்கப்பட்ட உருவாக்கம்)

மூலம்: [SimpleReaderDemo.java](../../../03-CoreGenerativeAITechniques/examples/src/main/java/com/example/genai/techniques/rag/SimpleReaderDemo.java). உள்ளீடு: [document.txt](../../../03-CoreGenerativeAITechniques/examples/document.txt).

இந்த ஆரம்ப RAG எடுத்துக்காட்டு ஒரு முழு UTF-8 ஆவணத்தைப் பெறுகிறது மற்றும் கேள்வி உடன் பயனர் செய்தியில் சேர்க்கப்படுகிறது. தனித்தனியான அமைப்பு செய்தி மாதிரியை ஆவண உள்ளடக்கம் விசுவாசிக்கக்கூடிய தரவு என்று கருதி அதிலிருந்து மட்டுமே பதில் தர அறிவுரைகிறது. ஆவணத்தில் பதில் இல்லையெனில், கேட்கப்பட்ட பதில்: `I cannot find that information in the provided document.`

அடிப்படை கலைகள் உருவம் தவிர்ப்பதை குறைக்கலாம், ஆனால் எல்லா காலிமுத்திரைகளையும் அல்லது உங்கள் காணொளி அனுப்புதலை தடுப்பதில்லை. நேரடி பதில்களை மதிப்பாய்வு செய்யவும். உற்பத்தி RAG வழக்கமாக துண்டாக்கல், பெறுதல், மேற்கோள், அணுகல் கட்டுப்பாடு மற்றும் மதிப்பாய்வுகளைச் சேர்க்கிறது.

```powershell
mvn -ntp compile exec:java "-Dexec.mainClass=com.example.genai.techniques.rag.SimpleReaderDemo"
```

ஒரு கேள்வி உள்ளிடவும், உதாரணமாக `புத்தகம் எந்த அங்கீகாரம் முறையை விளக்குகிறது?`. மைக்ரோசாஃப்ட் என்ட்ரா ஐடி குறிப்பிடும் பதிலை எதிர்பார்க்கவும். திட்டம் ஒரு உரையாடல் கோரிக்கைக்கு பின்பு 500 டோக்கன் முடிப்பு வரம்புடன் வெளியேறும்.

இயல்புநிலை கோப்பு தேடல் கிடையற்ற மூல, அத்தியாய அடைவு அல்லது எடுத்துக்காட்டு அடைவில் இருந்து பணி செய்கிறது. ஒரு தெளிவான பாதையும் ஆதரிக்கப்படுகிறது:

```powershell
mvn -ntp compile exec:java "-Dexec.mainClass=com.example.genai.techniques.rag.SimpleReaderDemo" '-Dexec.args="C:/documents/my document.txt"'
```

உள்ளீடுகள் வெற்றிடமற்றவை அமைய வேண்டும்: அதிகபட்சம் 32 KiB UTF-8 ஆவண தரவு மற்றும் 2,000 கேள்வி எழுத்துக்கள். காணாமல் போன கோப்புகள், வெற்று/EOF கேள்விகள், மற்றும் மிகப் பெரிய உள்ளீடுகள் முன்கூட்டியே தோல்வி அடைகிறன.

## பயிற்சி 4: பொறுப்பான AI

மூலம்: [ResponsibleAIDemo.java](../../../03-CoreGenerativeAITechniques/examples/src/main/java/com/example/genai/techniques/responsibleai/ResponsibleAIDemo.java).

ஆறு ப்ரோப்கள் பாதிப்பான வழிமுறைகள், வெறுப்புரை, தனியுரிமை, மருத்துவ தவறான தகவல், சட்டவிரோத உள்ளடக்கம், மற்றும் ஒரு உடைந்த பொறுப்பான AI கேள்வி ஆகியவற்றை உள்ளடக்குகின்றன. நிரல் பதிலைப் பார்க்கிறது, ஒவ்வொரு ப்ரோபும் ஒரு தெரிவு உண்டாக வேண்டும் என்று எண்ணாது.

| முடிவு | சான்று |
| --- | --- |
| `FILTERED` | ஒரு தெளிவான `content_filter` / `ResponsibleAIPolicyViolation` பிழை குறியீடு, அல்லது ஒரு முடிப்பு `content_filter` முடிவு காரணம் |
| `REFUSED` | வெற்றிடமற்ற கட்டமைக்கப்பட்ட `message.refusal` புலம் |
| `POSSIBLE_REFUSAL` | சாதாரண உரையில் ஒரு தொடக்க நிராகரிப்பு சொற்றொடர்; மதிப்பாய்வு தேவைப்படும் ஒரு heuristic |
| `GENERATED` | முடிக்கப்பட்ட வெறுமையல்லான பதில்; கொண்டுள்ளதை பாதுகாப்பாக கல்விக்கான ஆதாரம் அல்ல |

ஒரு சாதாரண HTTP 400 **வடிகட்டல் ஆதாரம் அல்ல**. தவறான அளவுருக்கள், அங்கீகாரம் தோல்விகள், வீத வரம்புகள், சேவையகம் பிழைகள், தவறான பதில்கள் மற்றும் நெடியேற்றப்பட்ட வெளியீடுகள் ஓட்டம் தோல்வி அடைவதற்கு வழிவகுக்கின்றன, தவறான பாதுகாப்பு வெற்றியை ஏற்படுத்தாது. ஒய்வற்ற விளக்கம் போன்ற "பாதிப்பான உள்ளடக்கம்" போன்ற பரவலான வார்த்தைகள் நிராகரிப்பாக எண்ணப்பட மாட்டாது.

```powershell
mvn -ntp compile exec:java "-Dexec.mainClass=com.example.genai.techniques.responsibleai.ResponsibleAIDemo"
```

ஆறு வகைப்படுத்தல் முடிவுகள் மற்றும் அவசரமில்லாத பாதுகாப்பு சான்றிதழல்ல என்பது குறிப்பிடும் ஒரு சுருக்கத்தை எதிர்பார்க்கவும். ஒவ்வொரு ப்ரோபுக்கும் 300 டோக்கன் முடிப்பு வரம்பு உள்ளது. எதிர்பாராத உருவாக்கங்கள் மற்றும் சாத்தியமான நிராகரிப்புகளை கைமுறை மதிப்பாய்வு செய்யவும்; உடைந்த ஒப்பீடு பொருத்தமான பொறுப்பான AI விளக்கத்தை உருவாக்க வேண்டும். stdin தேவையில்லை.

## எடுத்துக்காட்டுகள் முழுவதிலும் பொதுவான வரைபாடுகள்

[AzureOpenAIConfig.java](../../../03-CoreGenerativeAITechniques/examples/src/main/java/com/example/genai/techniques/AzureOpenAIConfig.java) முடிவு சீரமைத்தல், பதிப்பு மாற்றங்கள், முக்கியமின்றி அங்கீகாரம் மற்றும் உரையாடல் விருப்பங்களை மையப்படுத்துகிறது:

```java
OpenAIClient client = OpenAIOkHttpClient.builder()
        .baseUrl(config.endpoint())
        .credential(BearerTokenCredential.create(AuthenticationUtil.getBearerTokenSupplier(
                new DefaultAzureCredentialBuilder().build(),
                "https://cognitiveservices.azure.com/.default")))
        .timeout(Duration.ofSeconds(60))
        .maxRetries(0)
        .build();
```

டோக்கன் வழங்கி தேவையானபோது அணுகல் டோக்கன்களை புதுப்பிக்கிறது. டோக்கன்களை பதிவு செய்யாதீர்கள் அல்லது இதனை API விசையோடு மாற்றாதீர்கள். ஒவ்வொரு நிரலும் தனது கிளையெண்டை மீண்டும் பயன்படுத்தி `finally` அல்லது தனிப்பட்ட `AutoCloseable` பையில் மூடும்; SDK இன் `OpenAIClient` தானே `AutoCloseable` அல்ல.

[ChatResponses.java](../../../03-CoreGenerativeAITechniques/examples/src/main/java/com/example/genai/techniques/ChatResponses.java) முடிக்கப்பட்ட, வெறுமையில்லா உரை பதிலை தேவைப்படுத்துகிறது. வெற்றிட தேர்வுகள், நிராகரிப்புகள், வடிகட்டல்கள் மற்றும் நெருக்கமான பதில்கள் வெற்றியாக மௌனமாக அச்சிடப்பட மாட்டாது. பொறுப்பான AI எடுத்துக்காட்டு எதிர்பார்க்கப்பட்ட வடிகட்டல்/நிராகரி முடிவுகளை தெளிவாக கையாள்கிறது. கையாளப்படாத தோல்விகள் Java/Maven செயலுக்கு பிழை எண் வழங்கும்.

**தானியங்கி SDK மீண்டும் முயற்சிகள் முடங்கியுள்ளன** பகிரப்பட்ட குறைந்த RPM பதிப்பிகளில் கோரிக்கை எண்ணிக்கைகளை கணிக்க இயலுமாறு. ஒவ்வொரு ஊகக்கேள்விக்கும் 60-விநாடிகள் நேர விடை அளிக்கப்பட்டுள்ளது. டோக்கன் பெற்று கொள்வதற்கு கூடுதல் நேரம் தேவைப்படலாம். பயன்பாட்டு மட்ட திட்டமிட்டு குவாடாக்களை மதிக்க வேண்டும்; தவறான கட்டண கோரிக்கையை அமானுஷ்யமாக திரும்ப இயக்க வேண்டாம்.

## தொடர் நேரடி சரிபார்ப்பு

நேரடி அழைப்புகள் அலகு சோதனைகளிலிருந்து பிரிதலாகும். இந்தக் கட்டளைகளைக் **தனித்தனியாக** பயன்படுத்து, கிடையற்ற மூலத்தில் இருந்து, அங்கீகாரங்கள் மற்றும் பதிப்பு அணுகல் தயாராகிய பிறகு மட்டும். எந்த சேவைகள் அல்லது நிலையான செயலிகள் தேவையில்லை.

பகிரப்பட்ட **நிமிடத்திற்கு 10 கோரிக்கைகள்** பதிப்புக்கு, அடுத்த நிரலுக்கான முழு கொட்டாவுக்காக போதுமான இடைக்காலத்தை முன்பே ஒதுக்குங்கள்: 5, 4, 1, பிறகு 6 கோரிக்கைகள். தொடர்ச்சியான செயலிகள் தனக்கே வீத வரம்பினை உறுதி செய்யாது. அனைத்து அழைப்பாளர்களுடன் சுழற்சி நிமிடத்தை ஒத்துப்போகவும்; நான்கு அழைப்புக்களையும் ஒரு கருத்துள்ள அட்டையைப் போல ஒட்ட வேண்டாம்.

```powershell
$env:AZURE_OPENAI_ENDPOINT = "https://your-resource.openai.azure.com/"
$env:AZURE_OPENAI_DEPLOYMENT = "gpt-5.6-luna"
$chapterPom = "03-CoreGenerativeAITechniques/examples/pom.xml"
```

**1. முடிப்புகள், பல முறை மற்றும் இரண்டு பரிமாற்ற முறைகள்:**

```powershell
"My name is Ada.`nWhat is my name?`nexit" | mvn -B -ntp -f $chapterPom compile exec:java "-Dexec.mainClass=com.example.genai.techniques.completions.LLMCompletionsApp"
```

மூன்று பகுதிகளின் தலைப்புகளும், ஐந்து பதில்களும், அடாவை நினைவுகூரும் இறுதி உதவிப் பதிலும், `Goodbye!` மற்றும் வெளியேறும் குறியீடு 0 ஆகியவற்றையும் சரிபார். பட்ஜெட்: **5 கோரிக்கைகள், அதிகபட்சம் 1,900 நிறைவேற்றும் டோக்கன்கள்**. குறைந்த சரிவிற்கு, வெறும் `exit` ஐ பைப் செய்யவும்: 3 கோரிக்கைகள் / 900 டோக்கன்கள், ஆனால் அதற்கு இடையிலான முடிவு சோதனை வழங்கப்படாது.

**2. இரு செயல்பாடுகள் அழைக்கும் பணிமுறைகளும்:**

```powershell
mvn -B -ntp -f $chapterPom compile exec:java "-Dexec.mainClass=com.example.genai.techniques.functions.FunctionsApp"
```

இரு செயல்பாடுகளின் பெயர்களையும், எடுக்கப்பட்ட சீயாட்டில் காலநிலை மற்றும் கணக்கிடப்பட்ட முடிவு 36, இரண்டு இறுதி பதில்களையும் மற்றும் வெளியேறும் குறியீடு 0 ஆகியவற்றையும் சரிபார். பட்ஜெட்: **4 கோரிக்கைகள், அதிகபட்சம் 1,200 நிறைவேற்றும் டோக்கன்கள்**.

**3. ஆவணத் தரவினை அடிப்படையாகக் கொண்ட பதில்:**

```powershell
"Which authentication method does the document describe?" | mvn -B -ntp -f $chapterPom compile exec:java "-Dexec.mainClass=com.example.genai.techniques.rag.SimpleReaderDemo" "-Dexec.args=03-CoreGenerativeAITechniques/examples/document.txt"
```

ஆவண பாதையை, Microsoft Entra ID குறித்து குறிப்பிடும் பதிலை மற்றும் வெளியேறும் குறியீடு 0 ஐ சரிபார். பட்ஜெட்: **1 கோரிக்கை, அதிகபட்சம் 500 நிறைவேற்றும் டோக்கன்கள்**. தற்போக்கு [document.txt](../../../03-CoreGenerativeAITechniques/examples/document.txt) என்பது தேவைப்படும் ஒரே உள்ளீட்டு கோப்பாகும். இல்லாத தலைப்பைப் பற்றி கேட்கும் விருப்பமான இரண்டாம் ஓட்டம் தவிர்க்கப்பட வேண்டும் மற்றும் அது 1 கோரிக்கை / 500 டோக்கன்கள் கூட சேர்க்கும்.

**4. பொறுப்புள்ள AI கவனிப்புகள்:**

```powershell
mvn -B -ntp -f $chapterPom compile exec:java "-Dexec.mainClass=com.example.genai.techniques.responsibleai.ResponsibleAIDemo"
```

ஆறு வகைகள் மற்றும் கவனிக்கத்தக்க சுருக்கத்தைக் காண்க, உருவாக்கப்பட்ட உள்ளடக்கத்தை மதிப்பாய்வு செய்க, தொழில்நுட்ப நிறைவு குறியீடு 0 ஐ கேட்கவும். வெற்றிகரமான செயலி வெளியேற்றும் போது மாதிரியின் பாதுகாப்பு உறுதிப்படுத்தப்படுவது கிடையாது. பட்ஜெட்: **6 கோரிக்கைகள், அதிகபட்சம் 1,800 நிறைவேற்றும் டோக்கன்கள்**.

**நான்கு கட்டளைகளுக்கான மொத்தம்: 16 உரையாடல் கோரிக்கைகள் மற்றும் அதிகபட்சம் 5,400 நிறைவேற்றும் டோக்கன்கள்**, மேலும் உள்ளீட்டு டோக்கன்கள் (மீண்டும் நிகழும் உரையாடல் மற்றும் கருவி சட்டெழுத்து/வரலாறு உட்பட). பிணைக்குதல் கோரிக்கைகள் இல்லை. உண்மையான டோக்கன் பயன்பாடு மாதிரிப் பொறுத்து வேறுபடும் மற்றும் வடிகட்டப்பட்ட உதவிக்குறிப்புகளுக்கு குறைவாக இருக்கலாம். டோலர் செலவு பயன்முறை விலையில் அமையும்; நிலையான தரகருத்து எதுவும் இல்லை. அனைத்து கோரிக்கை வரம்புகளும் எந்தவொரு கைமுறை மறுசெயல்பாடுகளை கருதாது. ஒவ்வொரு கட்டளைக்குப் பிறகு உடனடியாக `$LASTEXITCODE` ஐ சோதிக்கவும்; வெற்றி பெறாத செயல்பாட்டைக் குறிக்கும்.

## பிரச்சனைக்கு தீர்வு

- **முடிவுநிலை இல்லை / 401 / 403:** செயலி ஆரம்பிக்கும் செயலியில் முடிவுநிலையை அமைக்கவும், உள்ளூர் Azure உள்நுழைவு மற்றும் வளத்தின் பாதிக்கப்பட்ட பங்கின் சரிபார்க்கவும், எதிர்பாராத அடையாள சூழல் மாற்றங்களைப் பரிசோதிக்கவும்.
- **400 / 404:** செயலாக்கம் உள்ளதா மற்றும் விவாதத்துடன் கூடிய Chat Completions க்கு ஆதரவளிக்கிறதா என்பதை உறுதி செய்யவும். HTTPS வள மூல அல்லது `/openai/v1` URL ஐ பயன்படுத்தவும், பழைய மேம்படுத்தப்பட்ட URL ஐப் பயன்படுத்தக்கூடாது. சாதாரண 400 பிழைகள் தொழில்நுட்ப தோல்விகளாகும், பாதுகாப்பு தடைகள் அல்ல.
- **429:** பகிர்ந்த RPM மற்றும் டோக்கன் அளவுகோலை ஒத்திசைக்கவும் பின்னர் மீண்டும் முயற்சி செய்யவும். எடுத்துக்காட்டுகள் தானாக மீண்டும் முயற்சி செய்யவைப்பதில்லை.
- **`முற்றியாது உரையாடல் பதில்: நீளம்`:** வெளியீடு நிறைவு வரம்பை அடைந்துவிட்டது. பதிலை மற்றும் உதவிக்குறிப்பை மதிப்பாய்வு செய்து வரம்பையும் அச்சிடப்பட்ட பட்ஜெட்டையும் அதிகரிக்கவும்; ஒரு குறிக்கப்பட்ட ஓட்டத்தை வெற்றிகரமாக பதிவு செய்ய வேண்டாம்.
- **கோப்பு அல்லது stdin பிழைகள்:** ஆதரவு Directory இலிருந்து தொடங்கவும் அல்லது தெளிவான ஆவணப்பாதையை கொடுக்கவும். வெறுமையான வாசிப்பாளர் கேள்வியைக் கொடுக்கவும். நிறைவேற்றல்கள் EOF அல்லது `exit` கொண்டு நல்ல முறையில் முடிவடையலாம்.
- **கூடை இயக்கச் பிழைகள்:** Java 21 அல்லது மேலதிகத்தை சரிபார்க்கவும், பிறகு `mvn -B -ntp clean test` ஐ இயக்கவும். PowerShell இல், புண்ணாக்கிய சொத்துடன் Maven பொருளுக்கு முழு துண்டை மேற்கோள் வைக்கவும், உதாரணமாக `"-Dexec.mainClass=com.example.genai.techniques.functions.FunctionsApp"` .
