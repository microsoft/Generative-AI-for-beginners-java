## അവലോകനം

നാലു സ്വതന്ത്ര ജാവ പ്രോഗ്രാമുകൾ ചാറ്റ്, സംഭാഷണ ചരിത്രം, ഫംഗ്ഷൻ കോളിംഗ്, മുഴുവൻ ഡോക്യുമെന്റ് റിട്രിവൽ-ഓഗ്മെന്റഡ് ജനറേഷൻ (RAG), ഉത്തരവാദിത്വമുള്ള AI പ്രതികരണ കൈകാര്യം എന്നിവ പ്രദർശിപ്പിക്കുന്നു. എല്ലാ ചാറ്റ് അഭ്യർത്ഥനകളും സ്വാഭാവികമായി **GPT-5.6 Luna reasoning effort `none` നു വേണ്ടി ലക്ഷ്യമിട്ട്** ആണ്.

ഈ ഉദാഹരണങ്ങൾ ഔദ്യോഗിക OpenAI ജാവ SDK Azure OpenAI ന്റെ v1 എൻഡ്‌പോയിന്റ് ഉപയോഗിച്ച് [Microsoft ന്റെ SDK മാർഗ്ഗനിർദേശങ്ങൾ](https://learn.microsoft.com/azure/ai-foundry/openai/supported-languages) പിന്തുടർന്ന് പ്രവർത്തിക്കുന്നു. പഴയ `azure-ai-openai` പാക്കേജ് ഇനി ആശ്രയം അല്ല. മെസേജ് അടിസ്ഥാനമായ പ്രവൃത്തിപദ്ധതികൾ പഠിക്കാനായി Chat Completions നിലനിർത്തുന്നു; മറ്റുള്ള API ഓപ്ഷനുകൾക്കായി [OpenAI Java SDK](https://github.com/openai/openai-java#microsoft-azure) കാണുക.

## ആരംഭിക്കുന്നത്

റിപ്പോസിറ്ററി റൂട്ട് മുതൽ, თქვენს ഷെല്ലിൽ റിസോഴ്‌സ് എൻഡ്‌പോയിന്റും ഇച്ഛാനുസൃതം ഡിപ്ലോയ്മെന്റ് ഓവർറൈഡും സജ്ജമാക്കുക.

**Windows PowerShell:**

```powershell
$env:AZURE_OPENAI_ENDPOINT = "https://your-resource.openai.azure.com/"
$env:AZURE_OPENAI_DEPLOYMENT = "gpt-5.6-luna"
Set-Location 03-CoreGenerativeAITechniques/examples
mvn -B -ntp clean test
```

**Linux/macOS:**

```bash
export AZURE_OPENAI_ENDPOINT="https://your-resource.openai.azure.com/"
export AZURE_OPENAI_DEPLOYMENT="gpt-5.6-luna"
cd 03-CoreGenerativeAITechniques/examples
mvn -B -ntp clean test
```

ടെസ്റ്റുകൾക്ക് Azure ക്രെഡൻഷ്യലുകളും എൻഡ്‌പോയിന്റും ആവശ്യമായില്ല. മേവൻ സ്വയം പരിസ്ഥിതി ഫയൽ വായിക്കാറില്ല; ലൈവ് ഉദാഹരണങ്ങൾ ആരംഭിക്കുന്നതിനായി ഉപയോഗിക്കുന്ന ഷെല്ലിൽ മാറ്ററുകൾ സജ്ജമാക്കുക. IDE ലോഞ്ചുകൾക്കായി, നിങ്ങൾക്ക് ലോഞ്ച് കോൺഫിഗറേഷൻ നൽകുന്ന പരിസ്ഥിതി പരിശോധിക്കുക.

## മോഡൽ തിരഞ്ഞെടുക്കൽ മാർഗ്ഗനിർദ്ദേശം

| പരിസ്ഥിതി മാറ്റർ | അർഥം | ഡീഫോൾട്ട് |
| --- | --- | --- |
| `AZURE_OPENAI_ENDPOINT` | HTTPS Azure റിസോഴ്സ് റൂട്ട് അല്ലെങ്കിൽ ഇതിനകം സമന്വയിച്ച `/openai/v1` URL | ലൈവ് റൺസ്‌ക്കായി ആവശ്യമാണ് |
| `AZURE_OPENAI_DEPLOYMENT` | ചാറ്റ് ഡിപ്ലോയ്മെന്റ് പേര്, മോഡൽ പതിപ്പ് അല്ല | `gpt-5.6-luna` |
| `AZURE_OPENAI_EMBEDDING_DEPLOYMENT` | വേറിട്ട എम्बെഡ്ഡിംഗ് ഡിപ്ലോയ്മെന്റ് സജ്ജീകരണം, ഈ നാല് പ്രോഗ്രാമുകളും ഉപയോഗിക്കാറില്ല | `text-embedding-3-small` |

ശൂന്യമായ ഡിപ്ലോയ്മെന്റ് ഓവർറൈഡുകൾ ഡീഫോൾട്ട് ഉപയോഗിക്കുന്നു. കോൺഫിഗറേഷൻ `/openai/v1` ഒറ്റത്തവണ മാത്രമേ ചേർക്കൂ, എൻഡ്‌പോയിന്റിൽ ക്രെഡൻഷ്യലുകൾ, ക്വറി സ്റ്റ്രിംഗുകൾ, പണ്ടത്തേതായ ഡിപ്ലോയ്മെന്റ് പാതകൾ നിരസിക്കുന്നു.

എല്ലാ ചാറ്റ് അഭ്യർത്ഥനകളും വ്യക്തമായി `reasoningEffort(ReasoningEffort.NONE)`യും `maxCompletionTokens(...)`യും സജ്ജമാക്കുന്നു. `temperature`, `top_p`, അല്ലെങ്കിൽ പണ്ടത്തെ പൂരിപ്പിക്കൽ ടോക്കൺ ഓപ്ഷൻ ഉപയോഗിക്കാറില്ല. ഇതിൽ ടൂൾ തെരഞ്ഞെടുക്കലും ഫലങ്ങൾ പിന്തുടരലും ഉൾപ്പെടുന്നു. GPT-5.6 ചാറ്റ് പൂരിപ്പിക്കൽ ഫംഗ്ഷൻ ടൂളുകൾക്ക് reasoning effort `none` ആവശ്യമാണ്; [Microsoft ന്റെ ചാറ്റ് മാർഗ്ഗനിർദേശം](https://learn.microsoft.com/azure/ai-foundry/openai/how-to/chatgpt) കാണുക.

**ഈ അധ്യായത്തിൽ സ്റ്റ്രീമിംഗ് അല്ലെങ്കിൽ എംബെഡ്ഡിംഗ് എൻട്രിപ്പോയിന്റ് ഇല്ല.** വായനക്കാർ മുഴുവൻ ഡോക്യുമെന്റ് തിരികെ തേടുകയാണ്, വക്ടറുകൾ അല്ല. നിങ്ങൾ എംബെഡിംഗുകൾ ചേർക്കുമ്പോൾ വേറിട്ട എംബെഡ്ഡിംഗ് ഡിപ്ലോയ്മെന്റ് ഉപയോഗിക്കുക, ഉദാഹരണത്തിന് `text-embedding-3-small`, ലൂന അല്ല.

## ട്യൂട്ടോറിയൽ 1: LLM പൂരിപ്പിക്കൽസ്‌യും ചാറ്റും

ഉറവിടം: [LLMCompletionsApp.java](../../../03-CoreGenerativeAITechniques/examples/src/main/java/com/example/genai/techniques/completions/LLMCompletionsApp.java).

പ്രോഗ്രാം ഒരു ലളിതമായ ജാവ സ്ട്രീംസ് വിശദീകരണം, രണ്ട് തവണയുടെ HashMap/TreeMap സംവാദം, ഇന്ററാക്ടീവ് ചാറ്റ് എന്നിവ നടപ്പിലാക്കുന്നു. രണ്ടാം തവണ ആദ്യ സഹായിയുടെ പ്രതികരണം ഉൾപ്പെടുന്നു; ഓരോ ഇന്ററാക്ടീവ് തവണയും മുൻകൂട്ടി സംസാരിച്ചത് അയയ്ക്കുന്നു.

```java
var request = config.chatOptions(200)
        .addSystemMessage("You are a helpful Java expert.")
        .addUserMessage("Explain Java streams briefly.")
        .build();
String answer = ChatResponses.text(client.chat().completions().create(request));
```

`config.chatOptions(...)` ഡിപ്ലോയ്മെന്റ് സജ്ജീകരിക്കുകയും വ്യക്തമായ reasoning സജ്ജീകരണവും നൽകുന്നു. ഇന്ററാക്ടീവ് ചാറ്റ് ശൂന്യമായ വരികൾ ഒഴിവാക്കുന്നു, `exit` അല്ലെങ്കിൽ EOF നു അവസാനിക്കുന്നു, സിസ്റ്റം മെസേജ് കൂടാതെ ഒമ്പത് പൂർത്തിയായ ഉപയോക്താവ്/സഹായി തവണകൾ സൂക്ഷിക്കുന്നു. തവണകളുടെ എണ്ണം സിഎംപിള് ഒരു വിദ്യാഭ്യാസ പരിധിയാണ്, തികച്ചും ടോക്കൺ ബഡ്ജറ്റ് ഉറപ്പ് നൽകുന്നില്ല.

ഉദാഹരണ ഫോളഡറിൽ നിന്ന്:

```powershell
mvn -ntp compile exec:java "-Dexec.mainClass=com.example.genai.techniques.completions.LLMCompletionsApp"
```

മൂന്ന് പ്രാഥമിക ഉത്തരങ്ങൾ പ്രതീക്ഷിക്കുക, തുടർന്ന് `You:` പ്രംപ്റ്റ്. ഓരോ ശൂന്യമല്ലാത്ത ഇന്ററാക്ടീവ് ചോദ്യം ഒരു അഭ്യർത്ഥന കൂടി കൂട്ടിച്ചേർക്കുന്നു. പൂരിപ്പിക്കൽ പരിധികൾ ഇന്ററാക്ടീവ് തവണകൾക്കാക്കി ക്രമം 200, 300, 400, 500 ടോക്കണുകൾ.

## ട്യൂട്ടോറിയൽ 2: ഫംഗ്ഷൻ കോളിംഗ്

ഉറവിടം: [FunctionsApp.java](../../../03-CoreGenerativeAITechniques/examples/src/main/java/com/example/genai/techniques/functions/FunctionsApp.java).

SDK രേഖകൾ `WeatherArguments` and `CalculationArguments` യിൽ നിന്നുള്ള JSON സ്കീമകൾ ഉണ്ടാക്കുന്നു. ആവശ്യമായ ഒരു ടൂൾ തിരഞ്ഞെടുപ്പിലൂടെ ഓരോ ഉദാഹരണവും ടൂൾ പ്രോട്ടോക്കോൾ ഉപയോഗിച്ച് പരീക്ഷണം നടത്തുന്നു, മോഡലിന്റെ സ്വതന്ത്ര ഉത്തരങ്ങൾ സ്വീകരിക്കുന്നില്ല.

1. അനുവദിക്കുന്ന ടൂളും reasoning effort `none`ഉം 300 ടോക്കൺ പൂർണത പരിധിയോടെ ഒരു ചോദ്യം അയയ്‌ക്കുക.
2. `tool_calls` ഫിനിഷ് കാരണം ആവശ്യപ്പെടുക, ഫംഗ്ഷൻ പേര്, കോൾ ഐഡികൾ പരിശോധിക്കുക, ടൈപ്പ് ചെയ്ത JSON വാദങ്ങൾ വിശകലനം ചെയ്യുക.
3. ലൊക്കൽ ഫംഗ്ഷൻ നിർവഹിക്കുക. മോഡൽ ജാവ അല്ലെങ്കിൽ യാതൊരു കോഡ്‌യും നിർവഹിക്കുന്നില്ല.
4. സഹായി ടൂൾ-കാൾ സന്ദേശം ഒരിക്കൽ കൂട്ടിച്ചേർക്കുക, ശേഷം ഫലം ഓരോ ടൂൾ-കാൾ ഐഡിയായി അയയ്‌ക്കുക.
5. ടൂൾ ഉപയോഗിക്കാതെ ഒരു അവസാന 300-ടോക്കൺ അഭ്യർത്ഥന അയച്ച് പൂരിപ്പിച്ച, ശൂന്യമല്ലാത്ത മറുപടി ആവശ്യപ്പെടുക.

`get_weather` **സിമുചെയിറ്റുചെയ്‌ത**, ലൈവ് അല്ല, കാലാവസ്ഥാ വിവരം നൽകുന്നു. നഗരം മാനിച്ച് 22 ഡിഗ്രി സെൽഷ്യസ് ആവശ്യമായാൽ ഫാരൻഹീറ്റിൽ മാറ്റുന്നു. `calculate` exp4j വഴി നൽകിയ വ്യഞ്ജനം വിലയിരുത്തുന്നു, `15% of 240`, `2 + 3 * 4` പോലുള്ള രൂപങ്ങൾക്കൊപ്പം, ശൂന്യമായ, വലുത്, അസാധുവായ, അല്ലെങ്കിൽ പരിമിതിയിലുള്ള ഗണനകൾ നിരസിക്കുന്നു. ഫ്ലോട്ടിങ് പോയിന്റ് അങ്കഗണിതം ഉപയോഗിക്കുന്നു, സാമ്പത്തിക ദശാംശം അല്ല.

```powershell
mvn -ntp compile exec:java "-Dexec.mainClass=com.example.genai.techniques.functions.FunctionsApp"
```

`Function: get_weather`, സിമുലേറ്റഡ് സിയാറ്റിൾ കാലാവസ്ഥ, `Function: calculate`, `Function result: 36`, மற்றும் രണ്ടുതിരഞ്ഞു മറുപടികളും പ്രതീക്ഷിക്കുക. stdin അല്ലെങ്കിൽ ബാഹ്യ കാലാവസ്ഥാ ക്രെഡൻഷ്യലുകൾ ആവശ്യമില്ല. വിജയകരമായ പ്രവർത്തനത്തിന് കൃത്യമായി നാലു ചാറ്റ് അഭ്യർത്ഥനകൾ ആവശ്യമാണ്.

## ട്യൂട്ടോറിയൽ 3: RAG (റിട്രീവൽ-ഓഗ്മെന്റഡ് ജനറേഷൻ)

ഉറവിടം: [SimpleReaderDemo.java](../../../03-CoreGenerativeAITechniques/examples/src/main/java/com/example/genai/techniques/rag/SimpleReaderDemo.java). ഇൻപുട്ട്: [document.txt](../../../03-CoreGenerativeAITechniques/examples/document.txt).

ഈ തുടങ്ങിയ RAG ഉദാഹരണം ഒരു മുഴുവൻ UTF-8 ഡോക്യുമെന്റ് തിരികെ തേടി ഉപയോഗകർത്താവിന്റെ ചോദ്യത്തോടെ അത് ഉപയോക്തൃ സന്ദേശത്തിൽ ഉൾപ്പെടുത്തുന്നു. വേറെ സിസ്റ്റം മെസേജ് മോഡലിനെ ഡോക്യുമെന്റ് ഉള്ളടക്കം വിശ്വസനീയമല്ലാത്ത ഡാറ്റയായി പരിഗണിക്കാനും ആ സന്ദർഭത്തിൽനിന്ന് മാത്രം മറുപടി നൽകാനും നിർദേശം നൽകുന്നു. ഡോക്യുമെൻറിൽ ഉത്തരം ഇല്ലെങ്കിൽ, ആവശ്യപ്പെട്ട മറുപടി: `I cannot find that information in the provided document.`

ഗ്രൗണ്ടിംഗിന് ഹല്ല്യൂസിനേഷനുകൾ കുറയ്ക്കാം, പക്ഷേ ഡെലിമിറ്ററുകളും സിസ്റ്റം നിർദ്ദേശങ്ങളും കൃത്യത ഉറപ്പാക്കാൻ അല്ലെങ്കിൽ പ്രത്യാശ ഇൻജക്ഷൻ തടയാൻ പാടില്ല. ലൈവ് ഉത്തരങ്ങൾ പരിശോധിക്കുക. പ്രൊഡക്ഷൻ RAG സാധാരണയായി ചങ്കിംഗ്, റിട്രിവൽ, ഉദ്ധരണികൾ, ആക്സസ് നിയന്ത്രണം, മൂല്യനിർണ്ണയം എന്നിവ കൂട്ടിച്ചേർക്കും.

```powershell
mvn -ntp compile exec:java "-Dexec.mainClass=com.example.genai.techniques.rag.SimpleReaderDemo"
```

ഒരു ചോദ്യം നൽകുക, ഉദാഹരണത്തിന് `Which authentication method does the document describe?`. Microsoft Entra ID പറയുന്ന ഒരു മറുപടി പ്രതീക്ഷിക്കുക. പ്രോഗ്രാം ഒരു ചാറ്റ് അഭ്യർത്ഥനയ്ക്ക് ശേഷം 500-ടോക്കൺ പൂരിപ്പിക്കൽ പരിധിയോടെ പുറത്തിറങ്ങും.

ഡീഫോൾട്ട് ഫയൽ തിരയൽ റിപ്പോസിറ്ററി റൂട്ട്, അധ്യായ ഡയറക്ടറി, അല്ലെങ്കിൽ ഉദാഹരണ ഡയറക്ടറിയിൽ നിന്ന് പ്രവർത്തിക്കുന്നു. പ്രകടമായ പാതയും പിന്തുണയ്ക്കുന്നു:

```powershell
mvn -ntp compile exec:java "-Dexec.mainClass=com.example.genai.techniques.rag.SimpleReaderDemo" '-Dexec.args="C:/documents/my document.txt"'
```

ഇൻപുട്ടുകൾ ശൂന്യമല്ലാത്തത് വേണം: പരമാവധി 32 KiB UTF-8 ഡോക്യുമെന്റ് ഡാറ്റയും 2,000 ചോദ്യ അക്ഷരങ്ങളും. കാണാത്ത ഫയലുകൾ, ശൂന്യമായ/EOF ചോദ്യങ്ങൾ, വലുതായ ഇൻപുട്ടുകൾ ഇൻഫറൻസ് മുമ്പ് വിഫലമാകും.

## ട്യൂട്ടോറിയൽ 4: ഉത്തരവാദിത്വമുള്ള AI

ഉറവിടം: [ResponsibleAIDemo.java](../../../03-CoreGenerativeAITechniques/examples/src/main/java/com/example/genai/techniques/responsibleai/ResponsibleAIDemo.java).

ആറ് പ്രോബുകൾ ഹാനികരമായ നിർദ്ദേശങ്ങൾ, ദേഷ്യം, സ്വകാര്യത, മെഡിക്കൽ തെറ്റായ വിവരങ്ങൾ, നിയമവിരുദ്ധ ഉള്ളടക്കം, ഉത്തമ ഉത്തരവാദിത്വമുള്ള AI ചോദ്യം എന്നിവ പരിശോധിക്കുന്നു. പ്രോഗ്രാം ഫിൽട്ടർ നിർബന്ധമെന്നാണെന്ന് കരുതാതെ മറുപടി നിരീക്ഷിക്കുന്നു.

| ഫലം | തെളിവ് |
| --- | --- |
| `FILTERED` | വ്യക്തമായ `content_filter` / `ResponsibleAIPolicyViolation` പിശക് കോഡ്, അല്ലെങ്കിൽ completion `content_filter` ഫിനിഷ് കാരണം |
| `REFUSED` | ശൂന്യമല്ലാത്ത ഘടനയുള്ള `message.refusal` ഫീൽഡ് |
| `POSSIBLE_REFUSAL` | സാധാരണ എഴുത്തിലുള്ള ഒരു ആരംഭ തള്ളിപ്പ് വാചകം; അവലോകനത്തിന് ആവശ്യമായ ഹ്യൂറിസ്റ്റിക് |
| `GENERATED` | പൂർത്തിയായ ശൂന്യമല്ലാത്ത മറുപടി; അതിന്റെ ഉള്ളടക്കം സുരക്ഷിതമാണ് എന്ന് തെളിവല്ല |

സാധാരണ HTTP 400 ആണ് ഫിൽട്ടറിങ് തെളിവല്ല. അസാധുവായ പാരാമീറ്ററുകൾ, പാസ്സ് വിഫലം, നിരക്ക് പരിധി, സെർവർ പിശക്, തെറ്റായ മറുപടികൾ, മുറിച്ചുവച്ച ഔട്ട്‌പുട്ടുകൾ റൺ പരാജയപ്പെടുന്നു, തെറ്റായ സുരക്ഷാ വിജയം നൽകാതെ. "ഹാനികരമായ ഉള്ളടക്കം" പോലുള്ള വ്യാപകമായ വാക്കുകൾ ഒരു നല്ല വ്യാഖ്യാനത്തിൽ തള്ളിപ്പായി കണക്കാക്കപ്പെടുകയില്ല.

```powershell
mvn -ntp compile exec:java "-Dexec.mainClass=com.example.genai.techniques.responsibleai.ResponsibleAIDemo"
```

ആറ് വിഭാഗ ഫലങ്ങളും അവലോകനങ്ങൾ സുരക്ഷാ സർട്ടിഫിക്കേഷൻ അല്ലെന്ന് പറയുന്ന ഒരു സംഗ്രഹവും പ്രതീക്ഷിക്കുക. ഓരോ പ്രോബിനും 300 ടോക്കൺ പൂരിപ്പിക്കൽ പരിധിയുണ്ട്. അനിഷ്ടജനകമായ സൃഷ്ടികളുടെ കൈകാര്യം മാനുവലായിരിക്കണം; നല്ല താരതമ്യം ഉത്തമ ഉത്തരവാദിത്വ AI വിശദീകരണം നൽകണം. stdin ആവശ്യമില്ല.

## ഉദാഹരണങ്ങൾ തമ്മിലുള്ള പൊതു പാറ്റേണുകൾ

[AzureOpenAIConfig.java](../../../03-CoreGenerativeAITechniques/examples/src/main/java/com/example/genai/techniques/AzureOpenAIConfig.java) എൻഡ്‌പോയിന്റ് സാധാരണപ്പെടുത്തൽ, ഡിപ്ലോയ്മെന്റ് ഓവർറൈഡുകൾ, കീമില്ലാ അംഗീകാരം, ചാറ്റ് ഓപ്ഷനുകൾ എന്നിവ കേന്ദ്രികൃതമാക്കുന്നു:

```java
OpenAIClient client = OpenAIOkHttpClient.builder()
        .baseUrl(config.endpoint())
        .credential(BearerTokenCredential.create(AuthenticationUtil.getBearerTokenSupplier(
                new DefaultAzureCredentialBuilder().build(),
                "https://cognitiveservices.azure.com/.default")))
        .timeout(Duration.ofSeconds(60))
        .maxRetries(0)
        .build();
```

ടോക്കൺ സപ്ലയർ ആവശ്യത്തിനു ആക്‌സസ് ടോക്കണുകൾ പുതുക്കുന്നു. ടോക്കൺസ് ലോഗ് ചെയ്യരുത് അല്ലെങ്കിൽ ഇത് API കീ ഉപയോഗിച്ച് മാറ്റരുത്. ഓരോ പ്രോഗ്രാമും അതിന്റെ ക്ലയന്റിനെ വീണ്ടും ഉപയോഗിച്ച് `finally`ൽ അടയ്ക്കുന്നു അല്ലെങ്കിൽ സ്വന്തം `AutoCloseable` റാപ്പർ വഴി; SDKയുടെ `OpenAIClient` തന്നെ `AutoCloseable` അല്ല.

[ChatResponses.java](../../../03-CoreGenerativeAITechniques/examples/src/main/java/com/example/genai/techniques/ChatResponses.java) പൂർത്തിയായ, ശൂന്യമല്ലാത്ത ടെക്സ്റ്റ് മറുപടി ആവശ്യമാണ്. ശൂന്യമായ തിരഞ്ഞെടുക്കലുകൾ, തള്ളലുകൾ, ഫിൽട്ടറുകൾ, മുറിച്ചുവച്ച മറുപടികൾ വിജയമായി മൗനമായ്മൊഴിച്ച് പ്രദർശിപ്പിക്കപെടുകയില്ല. ഉത്തരവാദിത്വമുള്ള AI ഉദാഹരണം പ്രതീക്ഷിക്കുന്ന ഫിൽട്ടർ/തള്ളൽ ഫലങ്ങൾ വ്യക്തമായി കൈകാര്യം ചെയ്യുന്നു. കൈകാര്യമില്ലാത്ത പരാജയങ്ങൾക്ക് ജാവ/മേവൻ പ്രോസസ്സ് നെഗറ്റീവ് എക്സിറ്റ് കോഡ് നൽകും.

**ഓട്ടോമാറ്റിക് SDK റീട്രൈകൾ നിഷ്ക്രിയപ്പെടുത്തിയിരിക്കുന്നു** കൊടുക്കുന്ന അഭ്യർത്ഥനകളുടെ എണ്ണം പ്രവചിക്കാൻ കഴിയുന്ന രീതിയിൽ സുതാര്യത നിലനിർത്താൻ. ഓരോ ഇൻഫറൻസ് അഭ്യർത്ഥനക്കും 60 സെക്കന്റ് ടൈംഔട്ട് ഉണ്ട്. ടോക്കൺ ലഭിക കൽ കൂടുതൽ സമയം എടുക്കാം. അപ്ലിക്കേഷൻ തല ഷെഡ്യൂളിംഗ് ക്വോട്ടകൾ പാലിക്കണം; പരാജയപ്പെട്ട പെയ്ഡ് അഭ്യർത്ഥനം അന്ധമായും പുനരാരംഭിക്കരുത്.

## ക്രമഘടിത ലൈവ് സ്ഥിരീകരണം

ലൈവ് കോൾസ് യുണിറ്റ് ടെസ്റ്റുകളിൽ നിന്നും വേർതിരിച്ചിരിക്കുന്നു. താഴെ കൊടുത്തിട്ടുള്ള കമാൻഡുകൾ **വ്യക്തിഗതമായി** റിപ്പോസിറ്ററി റൂട്ട് മുതൽ, ക്രെഡൻഷ്യലുകളും ഡിപ്ലോയ്മെന്റ് ആക്സസും തയ്യാറാകും ശേഷം മാത്രം ഉപയോഗിക്കുക. യാതൊരു സേവനങ്ങളും സ്ഥിരമായ പ്രക്രിയകളും ആവശ്യമായില്ല.

ഒരു പങ്കിട്ട **10 അഭ്യർത്ഥനകൾ/മിനിറ്റ്** ഡിപ്ലോയ്മെന്റിന്, അടുത്ത പ്രോഗ്രാമിനുമുമ്പായി മുഴുവൻ ക്വോട്ടയും സംരക്ഷിക്കുക: 5, 4, 1, 6 അഭ്യർത്ഥനകൾ അനുകമായി. ക്രമൾഡ് പ്രോസസ്സുകൾ മാത്രമല്ല നിരക്ക് പരിധി പാലനത്തിനുള്ള ഉറപ്പു നൽകുന്നത്. എല്ലാ കോൾ ചെയ്യുന്നതുമായ മിനിറ്റ് ചുറ്റും കൂട്ടുകൽ ചെയ്യുക; നാല് കോളുകൾ കൂടി ഒരു നിരക്കുന്നഘടമായി പകർത്തരുത്.

```powershell
$env:AZURE_OPENAI_ENDPOINT = "https://your-resource.openai.azure.com/"
$env:AZURE_OPENAI_DEPLOYMENT = "gpt-5.6-luna"
$chapterPom = "03-CoreGenerativeAITechniques/examples/pom.xml"
```

**1. പൂരിപ്പിക്കൽസ്‌, ബഹുതവണ, രണ്ട് ഇന്ററാക്ടീവ് തവണകൾ:**

```powershell
"My name is Ada.`nWhat is my name?`nexit" | mvn -B -ntp -f $chapterPom compile exec:java "-Dexec.mainClass=com.example.genai.techniques.completions.LLMCompletionsApp"
```

മൂന്നു വിഭാഗ തലക്കെട്ടുകളും, അഞ്ച് ഉത്തരങ്ങളും, ആദ വസ്തുത ഓർമിപ്പിക്കുന്ന അന്തിമ ഇന്ററാക്ടീവ് ഉത്തരം, `Goodbye!` എന്നും, 0 എന്ന എക്സിറ്റ് കോഡ് പരിശോധിക്കുക. ബഡ്ജറ്റ്: **5 അഭ്യർത്ഥനകൾ, പരമാവധി 1,900 സമാപന ടോക്കണുകൾ**. കുറച്ചു റൺ വേണ്ടി, മാത്രം `exit` പൈപ്പ് ചെയ്യുക: 3 അഭ്യർത്ഥനകൾ / 900 ടോക്കണുകൾ, പക്ഷേ അതിൽ ഇന്ററാക്ടീവ് ഇൻഫെറെൻസ് ചെയ്യില്ല.

**2. രണ്ട് ഫംഗ്ഷൻ-കോൾ ചെയ്യൽ വർക്ക്‌ഫ്ലോകൾ:**

```powershell
mvn -B -ntp -f $chapterPom compile exec:java "-Dexec.mainClass=com.example.genai.techniques.functions.FunctionsApp"
```

രണ്ട് ഫംഗ്ഷൻ പേരുകളും, സിമുലേറ്റഡ് സിയാറ്റിൽ കാലാവസ്ഥയും, കണക്കാക്കിയ ഫലം 36, രണ്ട് അന്തിമ ഉത്തരങ്ങളും, 0 എക്സിറ്റ് കോഡും പരിശോധിക്കുക. ബഡ്ജറ്റ്: **4 അഭ്യർത്ഥനകൾ, പരമാവധി 1,200 സമാപന ടോക്കണുകൾ**.

ആറ് വിഭാഗങ്ങളും നിരീക്ഷണസംഗ്രഹവും പരിശോധിക്കുക, സൃഷ്‌ടിച്ച ഉള്ളടക്കം അവലോകനം ചെയ്യുക, സാങ്കേതിക സമാപനത്തിന് 0 എക്സിറ്റ് കോഡ് ആവശ്യമാണ്. വിജയകരമായ പ്രക്രിയയുടെ എക്സിറ്റ് safety ഉറപ്പാക്കുന്നില്ല. ബഡ്ജറ്റ്: **6 അഭ്യർത്ഥനകൾ, പരമാവധി 1,800 സമാപന ടോക്കണുകൾ**.

**നാലു കമാൻഡുകൾക്കുള്ള മൊത്തം: 16 ചാറ്റ് അഭ്യർത്ഥനകളും പരമാവധി 5,400 സമാപന ടോക്കണുകളും**, കൂടാതെ ഇൻപുട്ട് ടോക്കണുകൾ (മറവത്കിച്ച സംഭാഷണവും ടൂൾ സ്കീമ/ചരിത്രവും ഉൾപ്പെടെ). എംബെഡ്ഡിംഗ് അഭ്യർത്ഥനകളില്ല. യഥാർത്ഥ ടോക്കൺ ഉപയോഗം മോഡൽ ആശ്രിതമാണല്ലോ, പ്രത്യേകിച്ച് ഫിൽട്ടർ ചെയ്‌ത പ്രോമ്പ്റ്റുകൾക്ക് കുറവാകും. ഡോളർ ചെലവ് ഡിപ്പ്ലോയ്മെന്റ് വിലനിർണ്ണയത്തിലാണ് ആശ്രിതം; ഉറപ്പുള്ള ധനപരിമിത സൂചികയല്ല ഇത്. എല്ലാ അഭ്യർത്ഥനപരിധികളും കൈമാറ്റങ്ങളില്ലാതെയാണ് കണക്കാക്കുന്നത്. ഓരോ കമാൻഡ് കഴിഞ്ഞ് ഉടൻ `$LASTEXITCODE` പരിശോധിക്കുക; ശൂന്യമല്ലെങ്കിൽ റൺ വിജയകരമായി പൂർത്തിയാകാത്തതാണ്.

## പ്രശ്‌നപരിഹாரம்

- **എൻഡ്‌പോയിന്റ് ഇല്ല / 401 / 403:** ലോണ്ചിംഗ് പ്രക്രിയയിൽ എൻഡ്‌പോയിന്റ് സജ്ജമാക്കുക, നിങ്ങളുടെ സ്ഥാപിത Azure സൈൻ ഇൻ, റിസോഴ്‌സ്-സ്കോപ്പ് റോളുകൾ പരിശോധിക്കുക, മനസിലാക്കാത്ത ഐഡന്റിറ്റി പരിസ്ഥിതി ഓവർറൈഡുകൾ പരിശോധിക്കുക.
- **400 / 404:** ഡിപ്പ്ലോയ്മെന്റ് നിലവിലുണ്ട്, Chat Completions 'none' റീസണിംഗ് കോൺഫിഗറേഷൻ പിന്തുണയ്ക്കുന്നുവെന്ന് സ്ഥിരീകരിക്കുക. HTTPS റിസോഴ്‌സ് റൂട്ട് അല്ലെങ്കിൽ `/openai/v1` URL ഉപയോഗിക്കുക, പഴയ (legacy) ഡിപ്പ്ലോയ്മെന്റ് URL ഉപയോഗിക്കരുത്. സാധാരണ 400 പിശകുകൾ സാങ്കേതിക പരാജയങ്ങളാണ്, സുരക്ഷാ തടസ്സങ്ങൾ അല്ല.
- **429:** പങ്കിട്ട RPMയും ടോക്കൺ ക്വോട്ടയും കോർഡിനേറ്റ് ചെയ്ത ശേഷം വീണ്ടും ശ്രമിക്കുക. ഉദാഹരണങ്ങൾ സ്വയം റീടൈ ചെയ്യുമ്പോൾ അല്ല.
- **`അസമ്പൂർണ്ണമായ ചാറ്റ് പ്രതികരണം: നീളം`:** ഔട്ട്പുട്ട് സമാപന പരിധി തൊട്ടിരിക്കുന്നു. പരിധി കൂടിക്കാൻ മുമ്പ് അഭ്യർത്ഥനയും പ്രോമ്പ്റ്റും പരിശോധിക്കുക, രേഖപ്പെടുത്തിയ ബജറ്റിനും; മുറിച്ച റൺ വിജയകരമായി കണക്കാക്കരുത്.
- **ഫയൽ അല്ലെങ്കിൽ stdin പിശകുകൾ:** പിന്തുണയുള്ള ഡയറക്ടറിയിൽ നിന്നോ വ്യക്തമായ രേഖാ പാതയോ ഉപയോഗിച്ച് തുടക്കം കുറിക്കുക. ശൂന്യമല്ലാത്ത റെഡർ ചോദ്യം നൽകുക. EOF-യിൽ അല്ലെങ്കിൽ `exit`-ൽ സാധാരണ മുറിപ്പ് അവസാനിക്കാവുന്നതാണ്.
- **കമ്പൈലേഷൻ പിശകുകൾ:** Java 21 അല്ലെങ്കിൽ അതിനുമുകളിൽ ഉറപ്പാക്കുക, തുടർന്ന് `mvn -B -ntp clean test` ഓടിക്കുക. PowerShell-ൽ, ഡോട്ടുള്ള പ്രോപ്പർട്ടി അടങ്ങിയ Maven ആർഗുമെന്റ് മുഴുവനായും ഉദ്ധരിക്കാൻ, ഉദാഹരണത്തിന് `"-Dexec.mainClass=com.example.genai.techniques.functions.FunctionsApp"`.
