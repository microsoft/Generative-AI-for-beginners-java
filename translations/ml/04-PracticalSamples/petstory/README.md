- GPT-5.6 ലൂന എന്നാണ് പേരുള്ള ഒരു അസ്യൂർ AI ഫൗണ്ടറി ഡെപ്ലോയ്മെന്റ്, അല്ലെങ്കിൽ ആ ഡെപ്ലോയ്മെന്റിലേക്ക് പോയിന്റ് ചെയ്യുന്ന `AZURE_OPENAI_DEPLOYMENT`_OVERRIDE. പ്രൊവിജനിങിനും കീ ഇല്ലാത്ത അംഗത്വത്തിനായി `az login` ഉപയോഗിച്ച് ലോഗിൻ ചെയ്യുന്നതിനും [അദ്ധ്യായം 2](../../02-SetupDevEnvironment/getting-started-azure-openai.md) നോക്കുക. ഡെപ്ലോയ്മെന്റ് ഇമേജ് ഇൻപുട്ട് പിന്തുണയ്ക്കണം, കൂടാതെ `reasoning_effort: none` ആണെന്ന് ഉറപ്പുവരുത്തണം.
- ജാവ, സ്പ്രിംഗ് ബൂട്ട്, വെബ് ഡെവലപ്പ്മെന്റ് എന്നിവയുടെ അടിസ്ഥാന മനസ്സിലാക്കൽ

## പ്രധാന ഘടകങ്ങളുടെ വിശദീകരണം

### 1. പ്രധാന അപ്ലിക്കേഷൻ

**ഫയൽ:** `PetStoryApplication.java`

ഞങ്ങളുടെ സ്പ്രിംഗ് ബൂട്ട് അപ്ലിക്കേഷന്റെ എൻട്രി പോയിന്റ് ഇതാണ്:

```java
@SpringBootApplication
public class PetStoryApplication {
    public static void main(String[] args) {
        SpringApplication.run(PetStoryApplication.class, args);
    }
}
```

**ഇത് ചെയ്യുന്നത്:**
- `@SpringBootApplication` അനോട്ടേഷൻ ഓട്ടോ-കോൺഫിഗറേഷനും ഘടക സ്കാനിംഗിനും അനുവദിക്കുന്നു
- 8080 പോർട്ടിൽ ഒരു എംബെഡഡ് വെബ് സർവർ (ടംകാറ്റ്) തുടങ്ങുന്നു
- ആവശ്യമായ എല്ലാ സ്പ്രിംഗ് ബീൻസും സർവീസും സ്വയമായിട്ട് സൃഷ്‌ടിക്കുന്നു

### 2. വെബ് കൺട്രോളർ

**ഫയൽ:** [PetController.java](../../../../04-PracticalSamples/petstory/src/main/java/com/example/petstory/PetController.java)

| എൻഡ്പോയിന്റ് | അഭ്യർത്ഥന | വിജയകരമായ പ്രതികരണം |
| --- | --- | --- |
| `GET /` | നൽകിയ ബോഡി ഇല്ല | CSRF ടോക്കൺ അടങ്ങിയ HTML അപ്‌ലോഡ് ഫോർം |
| `POST /analyze-image` | `multipart/form-data`, ഫയൽ ഫീൽഡ് `image` | JSON: `{"description":"A playful pet..."}` |
| `POST /generate-story` | `application/x-www-form-urlencoded`, ഫീൽഡ് `description` | വിവരണവും സൃഷ്‌ടിച്ച സ്റ്റോറിയും ഉള്ള HTML ഫലം പേജ് |

രണ്ടും POST എൻഡ്പോയിന്റുകൾക്ക് `GET /` നിന്നുള്ള സെഷൻ കുക്കിയും CSRF ടോക്കണും ആവശ്യമാണ്. അപ്‌ലോഡ് സ്ക്രിപ്റ്റ് മറഞ്ഞിരിക്കുന്ന `_csrf` മൂല്യം `X-CSRF-TOKEN` ഹെഡറിൽ അയയ്ക്കുന്നു; സ്റ്റോറി സമർപ്പിക്കൽ `_csrf` ഫോമ്ഫീൽഡായി അയയ്ക്കുന്നു. API ക്ലയന്റുകൾ അഭ്യർത്ഥനകളിൽ കുക്ക് സംരക്ഷിക്കണം. ഇവ ഫോമ്എൻഡ്പോയിന്റുകളാണ്, JSON അഭ്യർത്ഥന എൻഡ്പോയിന്റുകൾ അല്ല.

വിവരണങ്ങൾ ശൂന്യമാകരുത്, 1000 ക്ക് മുകളിൽ അക്ഷരങ്ങളുള്ളതായിരിക്കരുത്. കൺട്രോളർ വിവരണം മുറുക്കുന്നു കൂടാതെ `<`, `>`, ഇരട്ട ഉദ്ധരണികൾ, അപോസ്ട്രോഫ്‌സ്, `&` നീക്കം ചെയ്ത് സർവീസിന് അയയ്ക്കുന്നു. ഫലം ടെംപ്ലേറ്റ് മോഡൽ ഔട്ട്പുട്ട് `th:text` ഉപയോഗിച്ച് പിന്മാറ്റങ്ങൾ ഉണ്ടാകാതെ ആണ്.

ഇമേജ് പരിശോധന പരാജയങ്ങൾ HTTP 400 ഇലുണ്ട്, `error` ഫീൽഡോടുകൂടി; മോഡൽ പരാജയങ്ങൾ HTTP 502 ഇലുണ്ട്, `error` ഫീൽഡിലും `description` ഇല്ലാതെ. തെറ്റായ സ്റ്റോറി വിവരണങ്ങളിൽ അല്ലെങ്കിൽ മോഡൽ പരാജയങ്ങളിൽ `/` ലേക്ക് ദിശാനിർദ്ദേശം നൽകുന്നു, കാണാവുന്ന പിശക് സന്ദേശത്തോടെ. ആവശ്യമായ ഫീൽഡുകൾ ഇല്ലെങ്കിൽ HTTP 400; CSRF ടോക്കൺ ഇല്ലാതുകയാണെങ്കിൽ അല്ലെങ്കിൽ തെറ്റാണെങ്കിൽ HTTP 403. വിജയകരമായ AI ഫലമായി തിരിച്ചുവരുന്ന ഫോള്ബാക്ക് വിവരണങ്ങളും സ്റ്റോറിയും ഇല്ല.

### 3. സ്റ്റോറി സർവീസ്

**ഫയൽ:** [StoryService.java](../../../../04-PracticalSamples/petstory/src/main/java/com/example/petstory/StoryService.java)

ഔദ്യോഗിക ഓപ്പൺഎഐ ജാവ SDK 4.63.1 അസ്യൂർ AI ഫൗണ്ടറിയുടെ ഓപ്പൺഎഐ-ഒപ്പം പൊരുത്തമുള്ള ചാറ്റ് കോംപ്ലീഷൻസ് API വിളിക്കുന്നു. അസ്യൂർ ഐഡന്റിറ്റി 1.18.6 Microsoft Entra ബിയറർ ടോക്കൺ `DefaultAzureCredential` മുഖേന നൽകുന്നു; API കീ ആവശ്യമില്ല.

| ഓപ്പറേഷൻ | ഇൻപുട്ട് | `max_completion_tokens` |
| --- | --- | --- |
| `analyzeImage` | അപ്‌ലോഡ് ചെയ്ത MIME ടൈപ്പിൽ ബേസ64 ഡാറ്റ URL ആയി എൻകോഡ് ചെയ്ത ഇമേജ് ബൈറ്റുകൾ | 300 |
| `generateStory` | ഉപയോക്തൃ സന്ദേശത്തിൽ ഒരു പെടിന്റെ വിവരണം | 800 |

രണ്ടും നിർവ്വചിച്ച ഡെപ്ലോയ്മെന്റ് ഉപയോഗിക്കുന്നു, ഡീഫോൾട്ട് `gpt-5.6-luna`, വ്യക്തമായി `ReasoningEffort.NONE` (`reasoning_effort: none`) സജ്ജമാക്കിയിരിക്കുന്നു. രണ്ടും `temperature` അല്ലെങ്കിൽ പാരമ്പര്യ `max_tokens` പരാമീറ്റർ അയയ്ക്കാറില്ല.

ഇമേജ് വിശകലനം JPEG, PNG, GIF, WebP സ്വീകരിക്കുന്നു, ശൂന്യമായ ചിത്രങ്ങളും 10MBക്കു മീതെയുള്ള ഫയലുകളും തള്ളുന്നു, ഫലമായി ലഭിക്കുന്ന വിവരണം 1000 അക്ഷരങ്ങളിൽ പരിമിതപ്പെടുത്തുന്നു. സ്റ്റോറി പ്രോംപ്റ്റ് കുടുംബാനുകൂല ചെറുകഥ ചോദിക്കുന്നു. ശൂന്യമായ തിരഞ്ഞെടുപ്പുകളും മോഡൽ ഉള്ളടക്കങ്ങളില്ലായ്മയും പിശകുകൾ; പരാജയങ്ങൾ സെർവർ സൈഡിൽ വൈഫല്യകാരണമെന്ന് സൂക്ഷിക്കും. ആപ്ലിക്കേഷൻ അവസാനിക്കുന്നപ്പോൾ SDK ക്ലയന്റ് അടയ്ക്കും.

### 4. വെബ് ടെംപ്ലേറ്റുകൾ

**ഫയൽ:** [index.html](../../../../04-PracticalSamples/petstory/src/main/resources/templates/index.html) (അപ്‌ലോഡ് ഫോർം)

പേജ് ഫോട്ടോ പിക്കറോടെ തുടങ്ങുന്നു, വിവരണ ടെക്സ്റ്റ് ഏരിയയില്ല. **ഇമേജ് വിശകലനം** തിരഞ്ഞെടുത്ത ചിത്രം മുൻ‌കൂട്ടികാണിക്കുകയും `/analyze-image` ൽ പോസ്റ്റ് ചെയ്യുകയും ചെയ്യുന്നു. വിജയകരമായ പ്രതികരണം വിവരണം പ്രദർശിപ്പിക്കുകയും മറഞ്ഞിരിക്കുന്ന `description` ഫീൽഡ് പൂരിപ്പിക്കുകയും **സ്റ്റോറി സൃഷ്‌ടിക്കുക** കാണിക്കുകയും ചെയ്യും. ആ ബട്ടൺ നിലവിലുള്ള ഫോമിൽ `/generate-story`/posts‌ ചെയ്യുന്നു.

ബ്രൗസറിൽ മോഡൽ ഡൗൺലോഡിനോ CDN ആശ്രയതയോ ഇല്ല. ഇമേജ് വിശകലനം സെർവറിൽ അസ്യൂർ ഡെപ്ലോയ്മെന്റ് വഴി നടക്കുന്നു. പരാജയങ്ങൾ കാണാനും, തെറ്റായ വിവരണത്തോടെ സ്റ്റോറി സൃഷ്‌ടിക്കാനും അനുവദിക്കില്ല. മുകളിൽ തിരഞ്ഞെടുത്ത മറ്റൊരു ഫയൽ പഴയ വിശകലനം നീക്കം ചെയ്യും.

**ഫയൽ:** `result.html` (സ്റ്റോറി പ്രദർശനം)

സൃഷ്‌ടിച്ച സ്റ്റോറി കാണിക്കുന്നു:

```html
<!DOCTYPE html>
<html xmlns:th="http://www.thymeleaf.org">
```

### 5. കോൺഫിഗറേഷൻ

**ഫയൽ:** `application.properties`

അപ്ലിക്കേഷൻ കോൺഫിഗറേഷൻ സജ്ജീകരണങ്ങൾ:

```properties
spring.application.name=pet-story-app

# File upload limits
spring.servlet.multipart.max-file-size=10MB
spring.servlet.multipart.max-request-size=10MB

# Logging configuration
logging.level.com.example.petstory=INFO

# Azure AI Foundry (keyless) configuration
azure.openai.endpoint=${AZURE_OPENAI_ENDPOINT:}
azure.openai.deployment=${AZURE_OPENAI_DEPLOYMENT:gpt-5.6-luna}
```

**കോൺഫിഗറേഷൻ വിശദീകരണം:**

1. **ഫയൽ അപ്‌ലോഡ്**: ഫയൽക്കും മുഴുവൻ മൾട്ടിപാർട്ട് അഭ്യർത്ഥനയ്ക്കും 10MB പരിധിയുണ്ട്; മൾട്ടിപാർട്ട് ഹെഡറുകൾക്ക് സ്ഥലം വെക്കാൻ ഫോട്ടോകൾ ഈ പരിധിക്ക് താഴെയാകട്ടെ
2. **ലോഗിങ്**: കൃത്യവും പ്രയോഗ സമയത്തിനുള്ള വിവരങ്ങൾ ലോഗ് ചെയ്യുന്നത് നിയന്ത്രിക്കുന്നു
3. **അസ്യൂർ AI ഫൗണ്ടറി**: ഉപയോഗിക്കാൻ എൻഡ്‌പ്പോയിന്റും മോഡൽ ഡെപ്ലോയ്മെന്റും വ്യക്തമാക്കുന്നു (കീ ഇല്ലാത്ത അംഗത്വം)
4. **സുരക്ഷ**: CSRF സംരക്ഷണം സജീവമാണു; മോഡൽ ഡയഗ്നോസ്റ്റിക്സ് സെർവറിൽ ലോഗ് ചെയ്യുന്നു, കൺട്രോളർ സാധാരണ മോഡൽ പരാജയ സന്ദേശങ്ങൾ കാണിക്കുന്നു

## അപ്ലിക്കേഷൻ പ്രവർത്തിപ്പിക്കൽ

### ഘട്ടം 1: സൈൻ ഇൻ ചെയ്ത് എൻഡ്‌പോയിന്റ് സജ്ജീകരിക്കുക

അംഗത്വം കീ ഇല്ലാത്തതാണ് (Microsoft Entra ID), അതിനാൽ API കീ ഇല്ല. സൈൻ ഇൻ ചെയ്ത് ഫൗണ്ടറി എൻഡ്‌പോയിന്റ് സജ്ജീകരിക്കുക:

**Windows (കമ്മാൻഡ് പ്രോമ്പ്):**
```cmd
az login
set AZURE_OPENAI_ENDPOINT=https://your-resource.openai.azure.com/
```

**Windows (പവർഷെൽ):**
```powershell
az login
$env:AZURE_OPENAI_ENDPOINT="https://your-resource.openai.azure.com/"
```

**Linux/macOS:**
```bash
az login
export AZURE_OPENAI_ENDPOINT=https://your-resource.openai.azure.com/
```

**ഇത് വേണ്ടിയത് എന്തുകൊണ്ട്:**
- അസ്യൂർ AI ഫൗണ്ടറി Microsoft Entra ID ഉപയോഗിച്ച് ഇൻഫറൻസ് അഭ്യർത്ഥനകൾ അംഗത്വം നൽകുന്നു
- കീ ഇല്ലാത്ത അംഗത്വം എന്നത് സോഴ്‌സ് കോഡിലോ അന്തരീക്ഷത്തിലോ രഹസ്യങ്ങളും ഉണ്ടാകാതെയെന്ന് സൂചിപ്പിക്കുന്നു
- നിങ്ങളുടെ അക്കൗണ്ടിന് റിസോഴ്സിൽ **Cognitive Services OpenAI User** റോളുണ്ടാകണം

ഡീഫോൾട്ട് ഡെപ്ലോയ്മെന്റ് പേര് `gpt-5.6-luna` ആണ്. നിങ്ങളുടെ GPT-5.6 ലൂന ഡെപ്ലോയ്മെന്റിന് മറ്റൊരു പേര് ഉണ്ടെങ്കിൽ, ആ ടെർമിനലിൽ ആപ്ലിക്കേഷൻ തുടങ്ങുന്നതിനു മുമ്പായി `AZURE_OPENAI_DEPLOYMENT` സജ്ജീകരിക്കുക. ഇമേജ് വിശകലനത്തിനും സ്റ്റോറി സൃഷ്‌ടിക്കലിനും ഈ സജ്ജീകരണം ഉപയോഗിക്കുന്നു.

### ഘട്ടം 2: നിർമ്മിച്ച് പ്രവർത്തിപ്പിക്കുക

പ്രോജക്ട് ഡയറക്ടറിയിലേക്ക് പോകുക:
```bash
cd 04-PracticalSamples/petstory
```

സ്റ്റാൻഡ്എലോൺ എക്സിക്യൂട്ടബിൾ JAR നിർമ്മിച്ച് എല്ലാ ഓഫ്‌ലൈൻ ടെസ്റ്റുകളും നടത്തുക:
```bash
mvn clean package
```

സർവർ ആരംഭിക്കുക:
```bash
mvn spring-boot:run
```

ആപ്ലിക്കേഷൻ `http://localhost:8080` ൽ ആരംഭിക്കും.

അല്ലെങ്കിൽ, ഒരു ഫ്രീ പോർട്ടിൽ പാക്കേജുചെയ്ത JAR ആരംഭിക്കുക, ഉദാഹരണത്തിന്:

```bash
java -jar target/pet-story-app-0.0.1-SNAPSHOT.jar --server.port=8083
```

ആ കമാൻഡ് ഉപയോഗിച്ച്, `http://localhost:8083/` തുറക്കുക. ഒരേ `/analyze-image`-ഉം `/generate-story` റൂട്ടുകളും തെരഞ്ഞെടുക്കപ്പെട്ട പോർട്ടിൽ ലഭ്യമാണ്.

### ഘട്ടം 3: ആപ്ലിക്കേഷൻ പരീക്ഷിക്കുക

1. **തുറക്കുക** `http://localhost:8080` ബ്രൗസറിൽ
2. **തെറ്റ് ചെയ്യുക** JPEG, PNG, GIF, WebP ഫോർമാറ്റിലെ 10MB താഴെയുള്ള ഒരു വ്യക്തമായ പെടിന്റെ ഫോട്ടോ
3. **ക്ലിക്ക് ചെയ്യുക** "ഇമേജ് വിശകലനം" ബട്ടണിൽ, പെടിന്റെ വിവരണം ലഭിക്കുവാൻ കാത്തിരിക്കുക
4. **ക്ലിക്ക് ചെയ്യുക** വിജയകരമായ വിശകലനത്തിന് ശേഷം "സ്റ്റോറി സൃഷ്‌ടിക്കുക"
5. **കാണുക** ലാഭിച്ച സ്റ്റോറിയും ഫലം പേജിലെ ലിങ്ക് ഉപയോഗിച്ച് അപ്‌ലോഡ് ഫോറത്തിലേയ്ക്ക് മടങ്ങുക

വിജയകരമായ ഇമേജ് മുതൽ സ്റ്റോറിയിലേക്കുള്ള പ്രവാഹം രണ്ട് മോഡൽ കൾ ആണ്, ഓരോ ബട്ടണിലുമൊന്ന്. ലൈവ് ഇൻഫറൻസ് നിങ്ങളുടെ ഡെപ്ലോയ്മെന്റിന്റെ ക്വോട്ട ഉപയോഗിച്ച് ചാർജുകൾ ഉണ്ടാക്കാം; നിരക്ക് പരിമിതമായ ഡെപ്ലോയ്മെന്റ് പങ്കുവെക്കുമ്പോൾ സീരിയല്ലായി സ്‌മോക്ക് ടെസ്റ്റുകൾ നടത്തുക. ഹോം പേജ് ലോഡ് ചെയ്യുന്നത് മോഡൽ കോൾ ചെയ്യില്ല.

## ഓഫ്‌ലൈൻ ടെസ്റ്റുകൾ

സാമ്പിൾ ഡയറക്ടറി നിന്നു ഓടിക്കുക:

```bash
mvn test
```

[StoryServiceTest.java](../../../../04-PracticalSamples/petstory/src/test/java/com/example/petstory/StoryServiceTest.java) യഥാർത്ഥ ഓപ്പൺഎഐ SDK അഭ്യർത്ഥനകൾ ഒരു ലൂപ്ബാക്ക് HTTP ഫിക്ചർ ഉപയോഗിച്ചു പിടിക്കുന്നു. രണ്ടും ഡെപ്ലോയ്മെന്റ്, `reasoning_effort: none`, ടോക്കൺ പരിധികൾ, ഇമേജ് പേലോഡ്, ഇൻപുട്ട് സാധുത, ശൂന്യമായി തിരിച്ചുള്ള പ്രതികരണങ്ങൾ, അപ്പ്സ്ട്രീം പിശകുകൾ പരിശോധിക്കുന്നു.

[PetControllerTest.java](../../../../04-PracticalSamples/petstory/src/test/java/com/example/petstory/PetControllerTest.java) മോക്ക് മോഡൽ സർവീസ് ഉപയോഗിച്ച് MockMvc ഉപയോഗിച്ച് തൈംലീഫ് പേജുകളെ, അപ്‌ലോഡ് കരാർ, CSRF, സാധുത, ഔട്ട്പുട്ട് എസ്കേപ്പിംഗ്, കാണാവുന്ന പരാജയങ്ങൾ എന്നിവ പരീക്ഷിക്കുന്നു. ഈ ടെസ്റ്റുകൾക്ക് അസ്യൂർ ക്രെഡൻഷ്യലുകൾ ആവശ്യമില്ല, പണമടയ്ക്കുന്ന അസ്യൂർ ഇൻഫറൻസ് കോൾ ചെയ്യാറില്ല. മെവൻ `target/surefire-reports` കീഴിൽ ഷൂറ്ഫയർ റിപ്പോർട്ടുകൾ എഴുതുന്നു.

## എങ്ങനെ എല്ലാം ചേർന്ന് പ്രവർത്തിക്കുന്നു

നിങ്ങൾ ഒരു പെട് സ്റ്റോറി സൃഷ്‌ടിക്കുമ്പോൾ പൂർണ പ്രവാഹം:

1. **ഫോട്ടോ തിരഞ്ഞെടുക്കൽ**: അപ്‌ലോഡ് ഫോമിൽ ഒരു പെടിന്റെ ചിത്രം തിരഞ്ഞെടുക്കുക
2. **ചിത്രം അപ്‌ലോഡ് ചെയ്യൽ**: "ഇമേജ് വിശകലനം" CSRF ഹെഡറോടുകൂടിയ മൾട്ടിപാർട്ട് POST `/analyze-image`-ലേക്ക് അയയ്ക്കുന്നു
3. **ചിത്ര വിശകലനം**: `StoryService` ചിത്രം GPT-5.6 ലൂനയിലേക്ക് ആശയവിനിമയ ഇന്ത്യ മുതൽ `reasoning_effort: none` ആയി അയയ്ക്കുന്നു
4. **വിവരണം പ്രദർശനം**: ബ്രൗസർ തിരിച്ച് വരുന്ന വിവരണം പ്രദർശിപ്പിക്കുകയും ഫോമിൽ സൂക്ഷിക്കുകയും ചെയ്യുന്നു
5. **സ്റ്റോറി സമർപ്പിക്കൽ**: "സ്റ്റോറി സൃഷ്‌ടിക്കുക" `description`_csrf_ `/generate-story`-ലേക്ക് പോസ്റ്റ് ചെയ്യുന്നു
6. **സ്റ്റോറി സൃഷ്‌ടി**: കൺട്രോളർ വിവരണം പരിശോധന നടത്തുകയും ഡെപ്ലോയ്മെന്റിന് `reasoning_effort: none` മുൻകരുതലോടെ വിളിക്കും
7. **ടെംപ്ലേറ്റ് റെൻഡറിംഗ്**: തൈംലീഫ് വിവരണവും സ്റ്റോറിയും ഫലം പേജിൽ എസ്കേപ്പ് ചെയ്ത് പ്രദർശിപ്പിക്കുന്നു

**പിശക് കൈകാര്യം ചെയ്യൽ പ്രവാഹം:**
മോഡൽ പരാജയപ്പെട്ടാൽ, സെർവർ കാരണമൊഴിക്കുന്നു. ഇമേജ് വിശകലനം HTTP 502 തിരിച്ചുകൊടുക്കുകയും ബ്രൗസർ പിഴവ് കാണിക്കുകയും ചെയ്യുന്നു; "സ്റ്റോറി സൃഷ്‌ടി" ബട്ടൺ മറച്ച് വെക്കുന്നു. സ്റ്റോറി സൃഷ്‌ടി പിഴവോടെ ഫോറത്തിലേക്ക് റിഡയറക്ട് ചെയ്യുന്നു. ആരോ വഴി മുമ്പ് എഴുതിയ ഫലം ചേർക്കുകയില്ല.

## AI ഇന്റഗ്രേഷൻ മനസ്സിലാക്കൽ

### അസ്യൂർ AI ഫൗണ്ടറി (കീ ഇല്ലാതെ)
സർവ്വീസ് നിങ്ങളുടെ റിസോഴ്സിന്റെ `/openai/v1/` എൻഡ്പോയിന്റുമായി SDK സജ്ജീകരിക്കുന്നു. `DefaultAzureCredential` ഉം `AuthenticationUtil.getBearerTokenSupplier` ഉം Microsoft Entra ടോക്കൺ AI റെഗ്ഗ്യൂളർ അനുമതി വേണ്ടി നൽകുന്നു. ലോക്കൽ ഡെവലപ്‌മെന്റ് നിങ്ങളുടെ അസ്യൂർ CLI സൈൻ-ഇൻ ഉപയോഗിക്കാം; അസ്യൂർ ഹോസ്റ്റഡ് ആപ്പ് മാനേജ്‌ഡ് ഐഡന്റിറ്റി ഉപയോഗിച്ച് ആവശ്യമായ റിസോഴ്സ് അനുമതികൾക്ക് ഉപയോഗിക്കാം.

### പ്രോംപ്റ്റ് എൻജിനീയറിങ്
ഇമേജ് വിശകലനം സംവേദ്യമായ പെട് വിഭാഗങ്ങൾ ഒരു ചെറുകഥയിൽ ആവശ്യപ്പെടുന്നു, ടെക്സ്റ്റിനെ നിർദ്ദേശങ്ങൾ ആക്കാതെ ഡാറ്റയായി കാണാൻ മോഡൽ അറിപ്പ് നൽകുന്നു. സ്റ്റോറി സൃഷ്‌തി തിരികെ ലഭിച്ച വിവരണം ഉപയോഗിച്ച് ഒരു കുടുംബാനുകൂല രചന അഭ്യർത്ഥനയാണ്. രണ്ടും റീസണിംഗ് സജ്ജമാക്കുന്നില്ല, ടെംപറേച്ചർ ഓവർറൈഡ് ഇല്ല.

### പ്രതികരണ സംസ്‌ക്കരണം
പങ്കുവെച്ച റിലേ ഹാൻഡ്ലർ തിരഞ്ഞെടുപ്പൊന്നിനും ശൂന്യമായ അല്ലെങ്കിൽ വെളിച്ചം മാത്രം ഉള്ള ഉള്ളടക്കം തള്ളുന്നു, സാധുവായ ഉള്ളടക്കം മുറുക്കുന്നു, അപ്പ്സ്ട്രീം പരാജയങ്ങൾ സൂക്ഷിക്കുന്നു. ചിത്ര വിവരണത്തിന് 1000 അക്ഷര പരിധിയാണ് കാരണം അടുത്ത സ്റ്റോറി ഫോമിനു ചേരുവാൻ. യഥാർത്ഥ മോഡൽ പരാജയം ഡയഗ്നോസ്റ്റിക്സിന് സൂക്ഷിക്കുമ്പോൾ ഉപയോക്താവിനും കാണിക്കുന്നില്ല.
