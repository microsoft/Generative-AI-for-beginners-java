## സൃഷ്ടിക്കപ്പെടുന്നത്

[`infra/`](../../../02-SetupDevEnvironment/infra) ലെ Bicep ടെംപ്ലേറ്റുകൾ പ്രൊവിഷൻ ചെയ്യുന്നു:

- ഒരു **Azure AI Foundry** അക്കൗണ്ട് (`Microsoft.CognitiveServices/accounts`, കയിൻ `AIServices`) ഒരു പ്രോജക്ഷനോടുകൂടി
- ഒരു **ചാറ്റ്** ഡിപ്ലോയ്മെന്റ് - GPT-5.6 Luna (`gpt-5.6-luna`), പതിപ്പ് `2026-07-09`, `GlobalStandard` ശേഷി `10` (ഈ മോഡലിനായി 10 അഭ്യർത്ഥനകൾ/നിമിഷം, 10,000 ടോക്കണുകൾ/നിമിഷം)
- ഒരു **എംബെഡ്ഡിംഗ്** ഡിപ്ലോയ്മെന്റ് - `text-embedding-3-small`, പതിപ്പ് `1` (നിലവിലെ അധ്യായങ്ങളിൽ ഉപയോഗിക്കുന്നു)
- ഒരു **കീലെസ് റോളു അസൈൻമെന്റ്** (`Cognitive Services OpenAI User`), അതിനാൽ നിങ്ങൾ `az login` ഉപയോഗിച്ച് സൈൻ ഇൻ ചെയ്യും കീകൾ മാനേജ് ചെയ്യാതെ

## ഓപ്‌ഷൻ A: azd + Bicep ഉപയോഗിച്ച് പ്രൊവിഷൻ (ശിപാർശ ചെയ്യുന്നു)

`02-SetupDevEnvironment` ഫോൾഡറിൽ നിന്നു:

```bash
cd 02-SetupDevEnvironment

# സൈൻ ഇൻ ചെയ്യുക (രണ്ട് ടൂളുകളും)
azd auth login
az login

# ഫൗണ്ട്രി അക്കൗണ്ടും മോഡൽ ഡിപ്ലോയ്മെന്റുകളും ഒരുക്കുക
azd up
```

`azd` നിങ്ങൾക്ക് **പരിസ്ഥിതി പേര്** (ഉദാഹരണത്തിന് `genai-java`), **സബ്സ്ക്രിപ്ഷൻ**, **പ്രദേശം** എന്നിവ ചോദിക്കും. `gpt-5.6-luna` ഉം `text-embedding-3-small` ഉം ലഭ്യമായ നിങ്ങളുടെ സബ്സ്ക്രിപ്ഷനും പ്രദേശവും തിരഞ്ഞെടുക്കുക, ഉദാഹരണത്തിന് `eastus2`. ആ പ്രദേശം മോഡലിനും ഡിപ്ലോയ്മെന്റ് തരംക്കും രോഗക്ഷമതാ പരിധി സംശോധനം ചെയ്യുക; ലഭ്യതയും പരിധിയും സബ്സ്ക്രിപ്ഷൻ അനുസരിച്ചാണ് വ്യത്യാസപ്പെടുന്നത്.

പ്രൊവിഷൻ പൂർത്തിയായപ്പോൾ, azd:

1. [`infra/main.bicep`](../../../02-SetupDevEnvironment/infra/main.bicep) യിൽ നിർവ്വചിച്ച എല്ലാ ഘടകങ്ങളും ഡിപ്ലോയ്മെന്റ് ചെയ്യുന്നു.
2. ഒരു പോസ്റ്റ്‌പ്രൊവിഷൻ ഹുക്ക് പ്രവർത്തിപ്പിച്ച്, നിങ്ങളുടെ എൻഡ്‌പോയിന്റ്, ഡിപ്ലോയ്മെന്റ് പേര് എന്നിവ അടങ്ങിയ [`examples/basic-chat-azure/.env`](../../../02-SetupDevEnvironment/examples/basic-chat-azure) എഴുതുന്നു (സീക്രെറ്റുകൾ ഇല്ല).

> **ടിപ്പ്:** മാറ്റങ്ങൾ പ്രയോഗിക്കാൻ വരുന്നപ്പോൾ `azd up` വീണ്ടും ഓടിക്കുക. മുഴുവൻ ഡിൽറ്റുചെയ്യാനും ചെലവ് അവസാനിപ്പിക്കാനും `azd down` ഓടിക്കുക.

സജ്ജീകരണങ്ങൾ കാണാൻ:

```bash
azd env get-values
```

ഇപ്പോൾ [സജ്ജീകരണം പരീക്ഷിക്കുക](#സജ്ജീകരണം-പരീക്ഷിക്കുക) എന്നിങ്ങനെ പോവുക.

## ഓപ്‌ഷൻ B: മാനുവൽ ആയി വിഭവങ്ങൾ സൃഷ്ടിക്കുക

പോർട്ടൽ ഉപയോഗിക്കാൻ ഇഷ്ടം ആണെങ്കിൽ, കൈയോടെ വിഭവങ്ങൾ സൃഷ്ടിക്കുക:

1. [Azure AI Foundry പോർട്ടൽ](https://ai.azure.com/) വെബ്‌സൈറ്റിലെങ്കി പോകുകയും സൈൻ ഇൻ ചെയ്യുക.
2. **ഒരു പ്രോജക്ട് സൃഷ്ടിക്കുക** (ഇതിലൂടെ ഫൗണ്ട്രി വിഭവവും സൃഷ്ടിക്കും). `GenAIJava` പോലൊരു പേര് നൽകുക.
3. നിങ്ങളുടെ പ്രോജക്ടിൽ **Models + endpoints** → **Deploy model** → **Deploy base model** തുറക്കുക.
4. **GPT-5.6 Luna** ഡിപ്ലോയ്മെന്റ് (മോഡൽ, ഡിപ്ലോയ്മെന്റ് പേര് `gpt-5.6-luna`, പതിപ്പ് `2026-07-09`) **Global Standard** ശേഷി `10` ഉപയോഗിച്ച് ഡിപ്ലോയ്മെന്റ് ചെയ്യുക. എംബെഡ്ഡിംഗ് ഉദാഹരണങ്ങൾക്കായി **text-embedding-3-small**, പതിപ്പ് `1` - ആവശ്യമുണ്ടെങ്കിൽ ഫലം ആവർത്തിക്കുക.
5. **Overview** നിന്ന് **എൻഡ്‌പോയിന്റ്** (ഉദാഹരണത്തിന് `https://<resource>.openai.azure.com/`) കോപ്പി ചെയ്യുക.
6. കീലെസ് പ്രവേശനം ഉറപ്പാക്കുക: വിഭവത്തിൽ **Access control (IAM)** → **Add role assignment** → നിങ്ങളുടെ അക്കൗണ്ടിലേക്ക് **Cognitive Services OpenAI User** റോളു അസൈൻ ചെയ്യുക.

> **കൂടെ ബുദ്ധിമുട്ടുണ്ടോ?** [Azure AI Foundry വൃത്താന്തം](https://learn.microsoft.com/azure/ai-foundry/how-to/create-projects) കാണുക.

## നിങ്ങളുടെ പരിസ്ഥിതി ക്രമീകരിക്കുക

**ഓപ്‌ഷൻ A (`azd up`) ഉപയോഗിച്ചാൽ**, നിങ്ങളുടെ സജ്ജീകരണ ഫയൽ ഇതിനകം തന്നെ എഴുതപ്പെട്ടിരിക്കുന്നു — ക്രമീകരിക്കാനുള്ള എന്തുമില്ല. [സജ്ജീകരണം പരീക്ഷിക്കുക](#സജ്ജീകരണം-പരീക്ഷിക്കുക) ഇതിലേക്ക് നേരിട്ട് പോകൂ.

**ഓപ്‌ഷൻ B (മാനുവൽ)** ഉപയോഗിച്ചാൽ, ഉദാഹരണത്തിന്റെ `.env` ഫയൽ താങ്കൾ തന്നെയാണ് ക്രമീകരിക്കേണ്ടത്:

```bash
cd 02-SetupDevEnvironment/examples/basic-chat-azure
cp .env.example .env
```

`.env` ഫയൽ നിങ്ങളുടെ എൻഡ്‌പോയിന്റുമായി എഡിറ്റ് ചെയ്യുക (കീ ആവശ്യമില്ല — പ്രാമാണികത കീലെസ് ആണ്):

```bash
AZURE_OPENAI_ENDPOINT=https://<your-resource>.openai.azure.com/
AZURE_OPENAI_DEPLOYMENT=gpt-5.6-luna
```

പ്രോജക്ട് URL അല്ലാതെ വിഭവത്തിന്റെ Azure OpenAI എൻഡ്‌പോയിന്റ് ഉപയോഗിക്കുക. basic-chat ആപ്പ് അത് `/openai/v1` ആക്കി പരിഹരിച്ച് ഒരു വ്യക്തമായ ബിയർർ-ടോക്കൺ ക്ലയന്റ് ക്രമീകരിക്കുന്നു; API കീ ആവശ്യമില്ല.

> **സുരക്ഷാ കുറിപ്പ്:** സംരക്ഷിക്കാനുള്ള API കീ ഒന്നുമില്ല. നിങ്ങൾ Microsoft Entra ID ഉപയോഗിച്ച് `az login` (പ്രാദേശികമായി) അല്ലെങ്കിൽ മാനേജ്‌ ചെയ്‌ത ഐഡന്റിറ്റി (Azure-യിൽ) വഴി പ്രാമാണികപ്പെടുത്തുന്നു. `.env` ഫയൽ രഹസ്യമല്ലാത്ത സജ്ജീകരണങ്ങൾ മാത്രം ഉൾക്കൊള്ളുന്നു, അത് `.gitignore` വഴി മുൻകരുതലായി സജ്ജീകരിച്ചിട്ടുണ്ട്.

## സജ്ജീകരണം പരീക്ഷിക്കുക

കീലെസ് പ്രാമാണികത ടോക്കൺ ലഭിക്കുന്നത് ഉറപ്പാക്കാൻ സൈൻ ഇൻ ചെയ്തിട്ടുണ്ടെന്ന് ഉറപ്പാക്കി, ഉദാഹരണം ഓടിക്കുക:

```bash
cd 02-SetupDevEnvironment/examples/basic-chat-azure

az login          # നിങ്ങൾ ഇതിനകം സൈൻ ഇൻ ചെയ്തിട്ടില്ലെങ്കിൽ
mvn clean spring-boot:run
```

നിങ്ങൾക്ക് `gpt-5.6-luna` മോഡലിൽ നിന്നുള്ള പ്രതികരണമുണ്ടാകും. ചെറിയ ഡീഫോൾട്ട് പരിധി പാലിക്കാൻ ഉദാഹരണങ്ങൾ ക്രമത്തിൽ ഓടിക്കുക; HTTP 429 കിട്ടിയാൽ വീണ്ടും ശ്രമിക്കുന്നതിന് മുമ്പ് വീണ്ടും ശ്രമിക്കുക.

> **VS കോഡ് ഉപയോക്താക്കൾ:** ഓടിക്കാൻ `F5` അമർത്തുക. ആപ്പ് നിങ്ങളുടെ `.env` സ്വയം ലോഡ് ചെയ്യും.

> **പൂർണ്ണ ഉദാഹരണം:** [Azure AI Foundry ഉപയോഗിച്ചുള്ള അടിസ്ഥാന ചാറ്റ് ഉദാഹരണം](./examples/basic-chat-azure/README.md) കാണുക വിശദീകരണങ്ങൾക്ക്.

- Azure AI Foundry നഗരത്തിൽ `gpt-5.6-luna` ഉം `text-embedding-3-small` ഉം ഡിപ്ലോയ്മെന്റ് ചെയ്തത്
- കീലെസ് പ്രാമാണികത (Microsoft Entra ID) — കീകൾ മാനേജുമാകേണ്ടതാണ് ഇല്ല
- നിങ്ങളുടെ എൻഡ്‌പോയിന്റും ഡിപ്ലോയ്മെന്റ് പേരുകളും ഉൾപ്പെടുത്തുന്ന ഒരു പ്രാദേശിക `.env` ഫയൽ
- ഒരു ജാവ ഡെവലപ്മെന്റ് പരിസ്ഥിതി ആരംഭിക്കാൻ സജ്ജീകരിച്ചിരിക്കുന്നു
