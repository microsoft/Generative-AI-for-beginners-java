## Επισκόπηση

Τέσσερα ανεξάρτητα προγράμματα Java παρουσιάζουν συνομιλία, ιστορικό συνομιλίας, κλήση συναρτήσεων, ολόκληρη-ντοκουμέντο γεννητικότητα με ενίσχυση ανάκτησης (RAG) και διαχείριση απαντήσεων υπεύθυνης ΤΝ. Όλα τα αιτήματα συνομιλίας στοχεύουν στο **GPT-5.6 Luna με μηδενική προσπάθεια συλλογισμού `none`** ως προεπιλογή.

Αυτά τα παραδείγματα χρησιμοποιούν το επίσημο SDK Java της OpenAI με το Azure OpenAI σημείο πρόσβασης v1, σύμφωνα με τις [οδηγίες SDK της Microsoft](https://learn.microsoft.com/azure/ai-foundry/openai/supported-languages). Το παλαιότερο πακέτο `azure-ai-openai` δεν είναι πλέον εξάρτηση. Η λειτουργία Συμπληρώσεων Συνομιλίας διατηρείται για να διδάξει τις υπάρχουσες ροές εργασίας με βάση τα μηνύματα· δείτε το [OpenAI Java SDK](https://github.com/openai/openai-java#microsoft-azure) για άλλες επιλογές API.

## Προαπαιτούμενα

- Java 21 ή νεότερο και Maven 3.6.3 ή νεότερο.
- Μια αναπτυξιακή διάταξη συνομιλίας Azure OpenAI με το όνομα `gpt-5.6-luna`, ή μια παράκαμψη με συμβατές ρυθμίσεις Συμπληρώσεων Συνομιλίας.
- Μια ταυτοποιημένη ταυτότητα Azure με το ρόλο **Cognitive Services OpenAI User** στον πόρο. Η τοπική ανάπτυξη χρησιμοποιεί την σύνδεσή σας Azure CLI· οι φιλοξενούμενες εφαρμογές μπορούν να χρησιμοποιούν διαχειριζόμενη ταυτότητα.
- Δείτε το [Κεφάλαιο 2](../02-SetupDevEnvironment/getting-started-azure-openai.md) για οδηγίες ρύθμισης πόρου και σύνδεσης.

Η [διαμόρφωση Maven](../../../03-CoreGenerativeAITechniques/examples/pom.xml) καθορίζει αυτές τις εκδόσεις, ελεγμένες στις 2026-09-14:

## Έναρξη

Από τη ρίζα του αποθετηρίου, ορίστε το σημείο πρόσβασης πόρου και την προαιρετική παράκαμψη ανάπτυξης στο κέλυφός σας.

**Windows PowerShell:**

```powershell
$env:AZURE_OPENAI_ENDPOINT = "https://your-resource.openai.azure.com/"
$env:AZURE_OPENAI_DEPLOYMENT = "gpt-5.6-luna"
Set-Location 03-CoreGenerativeAITechniques/examples
mvn -B -ntp clean test
```

**Linux/macOS:**

```bash
export AZURE_OPENAI_ENDPOINT="https://your-resource.openai.azure.com/"
export AZURE_OPENAI_DEPLOYMENT="gpt-5.6-luna"
cd 03-CoreGenerativeAITechniques/examples
mvn -B -ntp clean test
```

Οι δοκιμές δεν απαιτούν διαπιστευτήρια Azure ούτε σημείο πρόσβασης. Το Maven δεν διαβάζει αυτόματα αρχείο περιβάλλοντος· ορίστε τις μεταβλητές στο κέλυφος που χρησιμοποιείται για την εκκίνηση ζωντανών παραδειγμάτων. Για εκκινήσεις IDE, επαληθεύστε το παρεχόμενο περιβάλλον από τη διαμόρφωση εκκίνησης.

## Οδηγός Επιλογής Μοντέλου

| Μεταβλητή περιβάλλοντος | Σημασία | Προεπιλογή |
| --- | --- | --- |
| `AZURE_OPENAI_ENDPOINT` | HTTPS ρίζα πόρου Azure ή ήδη κανονικοποιημένη διεύθυνση `/openai/v1` | Απαραίτητο για ζωντανή εκτέλεση |
| `AZURE_OPENAI_DEPLOYMENT` | Όνομα διάταξης συνομιλίας, όχι έκδοση μοντέλου | `gpt-5.6-luna` |
| `AZURE_OPENAI_EMBEDDING_DEPLOYMENT` | Ξεχωριστή διαμόρφωση διάταξης ενσωμάτωσης, μη χρησιμοποιούμενη από αυτά τα τέσσερα προγράμματα | `text-embedding-3-small` |

Κενές παρακάμψεις διάταξης χρησιμοποιούν τις προεπιλογές. Η διαμόρφωση προσθέτει `/openai/v1` ακριβώς μία φορά και απορρίπτει διαπιστευτήρια, query strings, και παλιά μονοπάτια διάταξης στο endpoint.

Κάθε αίτημα συνομιλίας ορίζει ρητά `reasoningEffort(ReasoningEffort.NONE)` και `maxCompletionTokens(...)`. Κανένα αίτημα δεν ορίζει `temperature`, `top_p`, ή την παλιά επιλογή completion-token. Αυτό περιλαμβάνει επιλογή εργαλείων και ακολουθίες αποτελεσμάτων εργαλείων. Τα λειτουργικά εργαλεία GPT-5.6 Chat Completions απαιτούν προσπάθεια συλλογισμού `none`· δείτε τις [οδηγίες συνομιλίας της Microsoft](https://learn.microsoft.com/azure/ai-foundry/openai/how-to/chatgpt).

**Δεν υπάρχει ροή δεδομένων ή είσοδος ενσωμάτωσης σε αυτό το κεφάλαιο.** Ο αναγνώστης ανακτά ολόκληρο το έγγραφό του, όχι διανύσματα. Αν το επεκτείνετε με ενσωματώσεις, χρησιμοποιήστε ξεχωριστή διάταξη ενσωμάτωσης όπως `text-embedding-3-small`, ποτέ το Luna.

## Οδηγός 1: Συμπληρώσεις LLM και Συνομιλία

Πηγή: [LLMCompletionsApp.java](../../../03-CoreGenerativeAITechniques/examples/src/main/java/com/example/genai/techniques/completions/LLMCompletionsApp.java).

Το πρόγραμμα τρέχει μια απλή επεξήγηση ροών Java, μια συνομιλία δύο γύρων με HashMap/TreeMap, και διαδραστική συνομιλία. Ο δεύτερος γύρος περιλαμβάνει την πρώτη απάντηση του βοηθού· κάθε διαδραστικός γύρος στέλνει επίσης την προηγούμενη συνομιλία.

```java
var request = config.chatOptions(200)
        .addSystemMessage("You are a helpful Java expert.")
        .addUserMessage("Explain Java streams briefly.")
        .build();
String answer = ChatResponses.text(client.chat().completions().create(request));
```

`config.chatOptions(...)` παρέχει τη διάταξη και τη ρητή ρύθμιση συλλογισμού. Η διαδραστική συνομιλία παραλείπει κενές γραμμές, τελειώνει με `exit` ή EOF, και διατηρεί το συστημικό μήνυμα συν εννέα ολοκληρωμένους γύρους χρήστη/βοηθού. Ο περιορισμός αριθμού γύρων είναι εκπαιδευτικό όριο, όχι εγγύηση ακριβούς προϋπολογισμού token.

Από τον κατάλογο παραδειγμάτων:

```powershell
mvn -ntp compile exec:java "-Dexec.mainClass=com.example.genai.techniques.completions.LLMCompletionsApp"
```

Αναμένονται τρεις αρχικές απαντήσεις, μετά το προτροπή `You:`. Κάθε μη κενή διαδραστική ερώτηση προσθέτει ένα αίτημα. Τα όρια συμπλήρωσης είναι 200, 300, 400, και μετά 500 tokens ανά διαδραστικό γύρο.

## Οδηγός 2: Κλήση Συνάρτησης

Πηγή: [FunctionsApp.java](../../../03-CoreGenerativeAITechniques/examples/src/main/java/com/example/genai/techniques/functions/FunctionsApp.java).

Το SDK παράγει JSON σχήματα από τις σημειωμένες εγγραφές `WeatherArguments` και `CalculationArguments`. Μια αναγκαία επιλογή εργαλείου αναγκάζει κάθε παράδειγμα να ασκήσει το πρωτόκολλο εργαλείων αντί να αποδέχεται μη υποστηριζόμενη απάντηση μοντέλου.

1. Στείλτε μια ερώτηση με το επιτρεπτό εργαλείο, προσπάθεια συλλογισμού `none`, και όριο 300 token συμπλήρωσης.
2. Απαιτήστε λόγο ολοκλήρωσης `tool_calls`, επαληθεύστε το όνομα λειτουργίας και τα αναγνωριστικά κλήσεων, και αναλύστε τυποποιημένα επιχειρήματα JSON.
3. Εκτελέστε τη τοπική συνάρτηση. Το μοντέλο δεν εκτελεί Java ή αυθαίρετο κώδικα.
4. Προσθέστε ένα μήνυμα κλήσης εργαλείου βοηθού μία φορά, ακολουθούμενο από κάθε αποτέλεσμα με το αντίστοιχο `tool_call_id`.
5. Στείλτε ένα τελικό αίτημα 300 token χωρίς εργαλεία και απαιτήστε ολοκληρωμένη, μη κενή απάντηση.

Η `get_weather` επιστρέφει **προσομοιωμένο**, όχι ζωντανό καιρό. Σεβεται την πόλη και μετατρέπει τους δείγμα 22 βαθμούς Κελσίου σε Φαρενάιτ όταν ζητηθεί. Η `calculate` αξιολογεί την παρεχόμενη έκφραση μέσω exp4j, υποστηρίζει μορφές όπως `15% of 240` και `2 + 3 * 4`, και απορρίπτει κενές, υπερμεγέθεις, άκυρες ή μη πεπερασμένες υπολογισμούς. Χρησιμοποιεί αριθμητική κινητής υποδιαστολής, όχι χρηματοοικονομική δεκαδική ακρίβεια.

```powershell
mvn -ntp compile exec:java "-Dexec.mainClass=com.example.genai.techniques.functions.FunctionsApp"
```

Αναμένονται `Function: get_weather`, προσομοιωμένος καιρός Seattle, `Function: calculate`, `Function result: 36`, και οι δύο τελικές απαντήσεις. Δεν απαιτείται stdin ή εξωτερικά διαπιστευτήρια καιρού. Μια επιτυχημένη εκτέλεση χρησιμοποιεί ακριβώς τέσσερα αιτήματα συνομιλίας.

## Οδηγός 3: RAG (Αναζήτηση Ενισχυμένης Γεννητικότητας)

Πηγή: [SimpleReaderDemo.java](../../../03-CoreGenerativeAITechniques/examples/src/main/java/com/example/genai/techniques/rag/SimpleReaderDemo.java). Είσοδος: [document.txt](../../../03-CoreGenerativeAITechniques/examples/document.txt).

Το εισαγωγικό παράδειγμα RAG ανακτά ολόκληρο ένα UTF-8 έγγραφο και το περιλαμβάνει στο μήνυμα χρήστη μαζί με την ερώτηση. Ένα ξεχωριστό συστημικό μήνυμα δίνει οδηγίες στο μοντέλο να θεωρεί το περιεχόμενο εγγράφου ως αναξιόπιστα δεδομένα και να απαντά μόνο από αυτό το πλαίσιο. Αν το έγγραφο δεν περιέχει την απάντηση, η ζητούμενη απάντηση είναι: `Δεν μπορώ να βρω αυτή την πληροφορία στο παρεχόμενο έγγραφο.`

Η θεμελίωση μπορεί να μειώσει τις παραισθήσεις, αλλά ούτε οι οριοθετητές ούτε οι συστημικές οδηγίες εγγυώνται ακρίβεια ή αποτρέπουν κάθε εισαγωγή προτροπής. Επανεξετάστε ζωντανές απαντήσεις. Η παραγωγική RAG συνήθως προσθέτει τεμαχισμό, ανάκτηση, παραπομπές, έλεγχο πρόσβασης, και αξιολόγηση.

```powershell
mvn -ntp compile exec:java "-Dexec.mainClass=com.example.genai.techniques.rag.SimpleReaderDemo"
```

Πληκτρολογήστε μια ερώτηση, για παράδειγμα `Ποιο μέθοδο αυθεντικοποίησης περιγράφει το έγγραφο;`. Περιμένετε απάντηση που αναφέρει το Microsoft Entra ID. Το πρόγραμμα τερματίζει μετά από ένα αίτημα συνομιλίας με όριο 500 token.

Η προεπιλεγμένη αναζήτηση αρχείων λειτουργεί από τη ρίζα αποθετηρίου, τον κατάλογο κεφαλαίου ή τον κατάλογο παραδειγμάτων. Υποστηρίζεται και ρητό μονοπάτι:

```powershell
mvn -ntp compile exec:java "-Dexec.mainClass=com.example.genai.techniques.rag.SimpleReaderDemo" '-Dexec.args="C:/documents/my document.txt"'
```

Οι είσοδοι πρέπει να είναι μη κενές: το πολύ 32 KiB δεδομένα εγγράφου UTF-8 και 2.000 χαρακτήρες ερώτησης. Ελλείποντα αρχεία, κενές/EOF ερωτήσεις, και υπερβολικά μεγάλες είσοδοι αποτυγχάνουν πριν την επαγωγή.

## Οδηγός 4: Υπεύθυνη ΤΝ

Πηγή: [ResponsibleAIDemo.java](../../../03-CoreGenerativeAITechniques/examples/src/main/java/com/example/genai/techniques/responsibleai/ResponsibleAIDemo.java).

Οι έξι έλεγχοι καλύπτουν επιβλαβείς οδηγίες, λόγο μίσους, ιδιωτικότητα, ιατρική παραπληροφόρηση, παράνομο περιεχόμενο, και μια καλοήθη ερώτηση υπεύθυνης ΤΝ. Το πρόγραμμα παρακολουθεί την απάντηση αντί να υποθέτει ότι κάθε έλεγχος θα ενεργοποιήσει φίλτρο.

| Αποτέλεσμα | Απόδειξη |
| --- | --- |
| `FILTERED` | Ένας ρητός κωδικός σφάλματος `content_filter` / `ResponsibleAIPolicyViolation`, ή λόγος ολοκλήρωσης `content_filter` |
| `REFUSED` | Μη κενό δομημένο πεδίο `message.refusal` |
| `POSSIBLE_REFUSAL` | Φράση άρνησης στην αρχή σε απλό κείμενο· μια εστιασμένη υπόνοια που απαιτεί αναθεώρηση |
| `GENERATED` | Ολοκληρωμένη μη κενή απάντηση· όχι απόδειξη ότι το περιεχόμενο είναι ασφαλές |

Ένα συνηθισμένο HTTP 400 **δεν** αποτελεί απόδειξη φιλτραρίσματος. Άκυρες παράμετροι, αποτυχίες αυθεντικοποίησης, όρια ρυθμού, σφάλματα διακομιστή, κακοσχηματισμένες απαντήσεις, και αποκομμένη έξοδος αποτυγχάνουν την εκτέλεση αντί να παράγουν ψευδή επιτυχία ασφάλειας. Λέξεις ευρέως όπως «επιβλαβές περιεχόμενο» σε καλοήθη επεξήγηση δεν θεωρούνται άρνηση.

```powershell
mvn -ntp compile exec:java "-Dexec.mainClass=com.example.genai.techniques.responsibleai.ResponsibleAIDemo"
```

Αναμένονται έξι αποτελέσματα κατηγορίας και μια περίληψη που δηλώνει ότι οι παρατηρήσεις δεν είναι πιστοποίηση ασφάλειας. Κάθε έλεγχος έχει όριο 300 token. Επανεξετάστε μη αναμενόμενες γεννήσεις και πιθανές αρνήσεις χειροκίνητα· η καλοήθης σύγκριση πρέπει να παράγει ουσιαστική εξήγηση υπεύθυνης ΤΝ. Δεν απαιτείται stdin.

## Κοινά Πρότυπα σε Παραδείγματα

[AzureOpenAIConfig.java](../../../03-CoreGenerativeAITechniques/examples/src/main/java/com/example/genai/techniques/AzureOpenAIConfig.java) κεντρικοποιεί την κανονικοποίηση endpoint, παρακάμψεις διάταξης, αυθεντικοποίηση χωρίς κλειδί, και επιλογές συνομιλίας:

```java
OpenAIClient client = OpenAIOkHttpClient.builder()
        .baseUrl(config.endpoint())
        .credential(BearerTokenCredential.create(AuthenticationUtil.getBearerTokenSupplier(
                new DefaultAzureCredentialBuilder().build(),
                "https://cognitiveservices.azure.com/.default")))
        .timeout(Duration.ofSeconds(60))
        .maxRetries(0)
        .build();
```

Ο πάροχος token ανανεώνει διακριτικά πρόσβασης όπως απαιτείται. Μην καταγράφετε τα tokens ή αντικαταστήσετε αυτό με κλειδί API. Κάθε πρόγραμμα επαναχρησιμοποιεί τον πελάτη του και τον κλείνει στο `finally` ή μέσω του δικού του περιβλήματος `AutoCloseable`· το ίδιο το SDK `OpenAIClient` δεν είναι `AutoCloseable`.

[ChatResponses.java](../../../03-CoreGenerativeAITechniques/examples/src/main/java/com/example/genai/techniques/ChatResponses.java) απαιτεί ολοκληρωμένη, μη κενή κειμενική απάντηση. Κενές επιλογές, αρνήσεις, φίλτρα, και αποκομμένες απαντήσεις δεν τυπώνονται σιωπηλά ως επιτυχία. Το παράδειγμα υπεύθυνης ΤΝ χειρίζεται ρητά τα αναμενόμενα αποτελέσματα φίλτρου/άρνησης. Αδιαχειρίστως αποτυχίες δίνουν στη διαδικασία Java/Maven κωδικό εξόδου μηδέν.

**Αυτόματες επανεκκινήσεις SDK είναι απενεργοποιημένες** για διατήρηση προβλέψιμων μετρήσεων αιτήσεων σε κοινόχρηστες αναπτύξεις χαμηλού RPM. Κάθε αίτημα επαγωγής έχει όριο 60 δευτερολέπτων. Η απόκτηση token μπορεί να πάρει επιπλέον χρόνο. Ο προγραμματισμός επιπέδου εφαρμογής πρέπει να σέβεται τα όρια· μην επανεκτελείτε τυφλά αποτυχημένο πληρωμένο αίτημα.

## Ακολουθιακή Ζωντανή Επαλήθευση

Οι ζωντανές κλήσεις είναι ξεχωριστές από τις μονάδες δοκιμής. Χρησιμοποιήστε τις ακόλουθες εντολές **ξεχωριστά**, από τη ρίζα αποθετηρίου, μόνο αφού τα διαπιστευτήρια και η πρόσβαση διάταξης είναι έτοιμα. Δεν απαιτούνται υπηρεσίες ή επίμονες διεργασίες.

Για κοινόχρηστη διάταξη **10 αιτήματα/λεπτό**, κρατήστε αρκετό ποσό για ολόκληρο το επόμενο πρόγραμμα πριν το ξεκινήσετε: 5, 4, 1, μετά 6 αιτήματα. Οι ακολουθιακές διεργασίες μόνο δεν εγγυώνται τη συμμόρφωση με το όριο ρυθμού. Συγχρονίστε το ελαστικό λεπτό με όλους τους άλλους καλούντες· μην επικολλήσετε τις τέσσερις εκκλήσεις ως αδιάκοπη παρτίδα.

```powershell
$env:AZURE_OPENAI_ENDPOINT = "https://your-resource.openai.azure.com/"
$env:AZURE_OPENAI_DEPLOYMENT = "gpt-5.6-luna"
$chapterPom = "03-CoreGenerativeAITechniques/examples/pom.xml"
```

**1. Συμπληρώσεις, πολλαπλοί γύροι, και δύο διαδραστικοί γύροι:**

```powershell
"My name is Ada.`nWhat is my name?`nexit" | mvn -B -ntp -f $chapterPom compile exec:java "-Dexec.mainClass=com.example.genai.techniques.completions.LLMCompletionsApp"
```

Ελέγξτε όλους τους τρεις τίτλους των ενοτήτων, πέντε απαντήσεις, μια τελική διαδραστική απάντηση που ανακαλεί την Ada, το `Αντίο!` και τον κωδικό εξόδου 0. Προϋπολογισμός: **5 αιτήματα, το πολύ 1.900 tokens ολοκλήρωσης**. Για μικρότερη εκτέλεση, δρομολογήστε μόνο `exit`: 3 αιτήματα / 900 tokens, αλλά αυτό δεν δοκιμάζει διαδραστική συμπερασματολογία.

**2. Και οι δύο ροές εργασίας κλήσης συναρτήσεων:**

```powershell
mvn -B -ntp -f $chapterPom compile exec:java "-Dexec.mainClass=com.example.genai.techniques.functions.FunctionsApp"
```

Ελέγξτε και τα δύο ονόματα συναρτήσεων, τον προσομοιωμένο καιρό του Σιατλ, το υπολογισμένο αποτέλεσμα 36, δύο τελικές απαντήσεις και κωδικό εξόδου 0. Προϋπολογισμός: **4 αιτήματα, το πολύ 1.200 tokens ολοκλήρωσης**.

**3. Απάντηση βασισμένη στο έγγραφο:**

```powershell
"Which authentication method does the document describe?" | mvn -B -ntp -f $chapterPom compile exec:java "-Dexec.mainClass=com.example.genai.techniques.rag.SimpleReaderDemo" "-Dexec.args=03-CoreGenerativeAITechniques/examples/document.txt"
```

Ελέγξτε τη διαδρομή του εγγράφου, μια απάντηση που αναφέρει το Microsoft Entra ID και τον κωδικό εξόδου 0. Προϋπολογισμός: **1 αίτημα, το πολύ 500 tokens ολοκλήρωσης**. Το υπάρχον [document.txt](../../../03-CoreGenerativeAITechniques/examples/document.txt) είναι το μοναδικό απαιτούμενο αρχείο εισόδου. Μια προαιρετική δεύτερη εκτέλεση που ρωτά για ένα απούσα θέμα πρέπει να απέχει και προσθέτει ένα αίτημα / 500 tokens.

**4. Παρατηρήσεις Υπεύθυνης Τεχνητής Νοημοσύνης:**

```powershell
mvn -B -ntp -f $chapterPom compile exec:java "-Dexec.mainClass=com.example.genai.techniques.responsibleai.ResponsibleAIDemo"
```

Ελέγξτε έξι κατηγορίες και το συνοπτικό παρατηρητικό κείμενο, αναθεωρήστε το παραγόμενο περιεχόμενο και απαιτήστε κωδικό εξόδου 0 για τεχνική ολοκλήρωση. Μια επιτυχής έξοδος διαδικασίας δεν πιστοποιεί την ασφάλεια του μοντέλου. Προϋπολογισμός: **6 αιτήματα, το πολύ 1.800 tokens ολοκλήρωσης**.

**Σύνολο για τις τέσσερις εντολές: 16 αιτήσεις συνομιλίας και το πολύ 5.400 tokens ολοκλήρωσης**, συν tokens εισόδου (συμπεριλαμβανομένου επαναλαμβανόμενης συνομιλίας και σχήματος/ιστορικού εργαλείου). Δεν υπάρχουν αιτήματα ενσωμάτωσης. Η πραγματική χρήση tokens εξαρτάται από το μοντέλο και μπορεί να είναι μικρότερη, ειδικά για φιλτραρισμένα prompts. Το κόστος σε δολάρια εξαρτάται από την τιμολόγηση της ανάπτυξης· δεν υπονοείται σταθερή χρηματική εκτίμηση. Όλα τα όρια αιτημάτων προϋποθέτουν μη αυτόματες επαναλήψεις. Ελέγξτε το `$LASTEXITCODE` αμέσως μετά από κάθε εντολή· μηδενικό σημαίνει επιτυχή ολοκλήρωση.

## Επίλυση Προβλημάτων

- **Έλλειψη endpoint / 401 / 403:** Ορίστε το endpoint στη διαδικασία εκκίνησης, επαληθεύστε την τοπική σύνδεση Azure και το ρόλο σε επίπεδο πόρου, και ελέγξτε για μη επιθυμητές υπερισχύσεις ταυτότητας περιβάλλοντος.
- **400 / 404:** Επιβεβαιώστε ότι η ανάπτυξη υπάρχει και υποστηρίζει Chat Completions με προσπάθεια λογικής `none`. Χρησιμοποιήστε το HTTPS root πόρου ή την URL `/openai/v1`, όχι URL παλαιάς ανάπτυξης. Τα συνηθισμένα σφάλματα 400 είναι τεχνικές αποτυχίες, όχι μπλοκαρίσματα ασφαλείας.
- **429:** Συντονίστε το κοινό RPM και το όριο token πριν από την επανάληψη. Τα παραδείγματα επίτηδες δεν επαναλαμβάνονται αυτόματα.
- **`Incomplete chat response: length`:** Η έξοδος έφτασε το όριο ολοκλήρωσης. Επανεξετάστε την απάντηση και το prompt πριν αυξήσετε το όριο και τον τεκμηριωμένο προϋπολογισμό· μην καταγράφετε περικομμένη εκτέλεση ως επιτυχή.
- **Σφάλματα αρχείου ή stdin:** Εκκινήστε από υποστηριζόμενο φάκελο ή περάστε ρητή διαδρομή εγγράφου. Παρέχετε μια μη κενή ερώτηση αναγνώστη. Οι ολοκληρώσεις μπορούν να τελειώσουν κανονικά σε EOF ή `exit`.
- **Σφάλματα μεταγλώττισης:** Επιβεβαιώστε Java 21 ή μεταγενέστερη, έπειτα εκτελέστε `mvn -B -ntp clean test`. Στο PowerShell, βάλτε σε εισαγωγικά ολόκληρο το όρισμα Maven που περιέχει τελείες ιδιοτήτων, για παράδειγμα `"-Dexec.mainClass=com.example.genai.techniques.functions.FunctionsApp"`.
