## Τι θα Μάθετε

Αυτός ο οδηγός εξηγεί πώς να δημιουργήσετε μια υπηρεσία υπολογιστή χρησιμοποιώντας το Πρωτόκολλο Πλαισίου Μοντέλου (MCP). Θα κατανοήσετε:

- Πώς να δημιουργήσετε μια υπηρεσία που η Τεχνητή Νοημοσύνη μπορεί να χρησιμοποιεί ως εργαλείο
- Πώς να ρυθμίσετε άμεση επικοινωνία με υπηρεσίες MCP
- Πώς τα μοντέλα AI μπορούν αυτόματα να επιλέγουν ποια εργαλεία να χρησιμοποιήσουν
- Τη διαφορά μεταξύ άμεσων κλήσεων πρωτοκόλλου και αλληλεπιδράσεων με βοήθεια AI

## Προαπαιτούμενα

Πριν ξεκινήσετε, βεβαιωθείτε ότι έχετε:
- Εγκατεστημένο Java 21 ή νεότερη έκδοση
- Το Maven για διαχείριση εξαρτήσεων
- Θεμελιώδη κατανόηση Java και Spring Boot

Μόνο οι πελάτες AI απαιτούν μια ανάπτυξη Azure OpenAI και επαληθευμένη `DefaultAzureCredential`,
όπως μια υπάρχουσα τοπική σύνδεση Azure CLI ή μια διαχειριζόμενη ταυτότητα στο Azure. Η ταυτότητα χρειάζεται
το ρόλο Cognitive Services OpenAI User στον πόρο. Δείτε [Κεφάλαιο 2](../../02-SetupDevEnvironment/getting-started-azure-openai.md).
Ο διακομιστής, ο άμεσος πελάτης SDK, και όλες οι αυτοματοποιημένες δοκιμές δεν χρειάζονται λογαριασμό Azure ή πρόσβαση σε μοντέλο.

## Επεξήγηση Κύριων Συνιστωσών

### 1. Κύρια Εφαρμογή

**Αρχείο:** `McpServerApplication.java`

Αυτό είναι το σημείο εισόδου της υπηρεσίας υπολογιστή μας. Είναι μια τυπική εφαρμογή Spring Boot με μια ειδική προσθήκη:

```java
@SpringBootApplication
public class McpServerApplication {

    public static void main(String[] args) {
        SpringApplication.run(McpServerApplication.class, args);
    }
    
    @Bean
    public ToolCallbackProvider calculatorTools(CalculatorService calculator) {
        return MethodToolCallbackProvider.builder().toolObjects(calculator).build();
    }
}
```

**Τι κάνει αυτό:**
- Εκκινεί έναν web διακομιστή Spring Boot στην θύρα 8080
- Δημιουργεί έναν `ToolCallbackProvider` που καθιστά τις μεθόδους του υπολογιστή διαθέσιμες ως εργαλεία MCP
- Η επισήμανση `@Bean` λέει στο Spring να το διαχειριστεί ως συνιστώσα που μπορούν να χρησιμοποιήσουν άλλα μέρη

### 2. Υπηρεσία Υπολογιστή

**Αρχείο:** `CalculatorService.java`

Εδώ γίνεται όλος ο μαθηματικός υπολογισμός. Κάθε μέθοδος φέρει `@Tool` για να είναι διαθέσιμη μέσω MCP:

```java
@Service
public class CalculatorService {

    @Tool(description = "Add two numbers together")
    public String add(double a, double b) {
        double result = a + b;
        return formatResult(a, "+", b, result);
    }

    @Tool(description = "Subtract the second number from the first number")
    public String subtract(double a, double b) {
        double result = a - b;
        return formatResult(a, "-", b, result);
    }
    
    // Περισσότερες λειτουργίες αριθμομηχανής...
    
    private String formatResult(double a, String operator, double b, double result) {
        return String.format(java.util.Locale.ROOT, "%.2f %s %.2f = %.2f", a, operator, b, result);
    }
}
```

**Βασικά χαρακτηριστικά:**

1. **Επισήμανση `@Tool`**: Αυτή λέει στο MCP ότι αυτή η μέθοδος μπορεί να κληθεί από εξωτερικούς πελάτες
2. **Καθαρές Περιγραφές**: Κάθε εργαλείο έχει περιγραφή που βοηθά τα μοντέλα AI να καταλάβουν πότε να το χρησιμοποιήσουν
3. **Συνεπής μορφή επιστροφής**: Όλες οι λειτουργίες επιστρέφουν ανθρώπινα αναγνώσιμες συμβολοσειρές όπως "5.00 + 3.00 = 8.00"
4. **Διαχείριση σφαλμάτων**: Ο διαχωρισμός με μηδέν και τα αρνητικά τετραγωνικά ρίζα επιστρέφουν μηνύματα σφάλματος

**Διαθέσιμες λειτουργίες:**
- `add(a, b)` - Προσθέτει δύο αριθμούς
- `subtract(a, b)` - Αφαιρεί τον δεύτερο από τον πρώτο
- `multiply(a, b)` - Πολλαπλασιάζει δύο αριθμούς
- `divide(a, b)` - Διαιρεί τον πρώτο με τον δεύτερο (με έλεγχο μηδενός)
- `power(base, exponent)` - Υψώνει τη βάση στη δύναμη του εκθέτη
- `squareRoot(number)` - Υπολογίζει τετραγωνική ρίζα (με έλεγχο αρνητικού)
- `modulus(a, b)` - Επιστρέφει το υπόλοιπο της διαίρεσης
- `absolute(number)` - Επιστρέφει την απόλυτη τιμή
- `help()` - Επιστρέφει πληροφορίες για όλες τις λειτουργίες

### 3. Άμεσος Πελάτης MCP

Δείτε [SDKClient.java](../../../../04-PracticalSamples/calculator/src/test/java/com/microsoft/mcp/sample/client/SDKClient.java).

Αυτός ο πελάτης χρησιμοποιεί `HttpClientStreamableHttpTransport` στο `/mcp`, αρχικοποιεί τη σύνδεση,
επικοινωνεί με τον διακομιστή, και ακολουθεί σελιδοποίηση λίστας εργαλείων. Ελέγχει ότι τα εννέα αναμενόμενα εργαλεία
υπάρχουν και καλεί το καθένα, συμπεριλαμβανομένων των `modulus` και `help`, χωρίς μοντέλο AI.

Ο τρέχων δημιουργός αιτήσεων μοιάζει ως εξής:

```java
var request = CallToolRequest.builder("add")
    .arguments(Map.of("a", 5.0, "b", 3.0))
    .build();
var result = client.callTool(request);
```

Σφάλματα πρωτοκόλλου αποτυγχάνουν τον πελάτη αντί να εμφανίζουν παραπλανητική επιτυχία. Ο πελάτης MCP
κλείνει με try-with-resources, συμπεριλαμβανομένης της αποτυχίας ανακάλυψης ή κλήσης εργαλείου.

### 4. Πελάτης με Τεχνητή Νοημοσύνη

Δείτε [LangChain4jClient.java](../../../../04-PracticalSamples/calculator/src/test/java/com/microsoft/mcp/sample/client/LangChain4jClient.java)
και [Bot.java](../../../../04-PracticalSamples/calculator/src/test/java/com/microsoft/mcp/sample/client/Bot.java).

Το `OpenAiOfficialChatModel` υλοποιεί το τρέχον API `ChatModel` του LangChain4j.
Το `StreamableHttpMcpTransport` το συνδέει με το ίδιο σημείο `/mcp` όπως ο πελάτης SDK.
Το `AiServices` ανακαλύπτει τα εργαλεία και διαχειρίζεται τη συνομιλία κλήσης/αποτελέσματος εργαλείου.

Η προεπιλεγμένη ανάπτυξη είναι **GPT-5.6 Luna**, με την επεξεργασία λογικής ρητά απενεργοποιημένη:

```java
var parameters = OpenAiOfficialChatRequestParameters.builder()
    .modelName("gpt-5.6-luna")
    .reasoningEffort("none")
    .maxCompletionTokens(1024)
    .parallelToolCalls(false)
    .build();
```

Αυτές οι προεπιλογές εφαρμόζονται σε κάθε ολοκλήρωση, συμπεριλαμβανομένων των συνεχειών μετά την εκτέλεση εργαλείου.
Ο πελάτης χρησιμοποιεί μια ανανεώσιμη `BearerTokenCredential` με την υποστήριξη του `DefaultAzureCredential`
και το πεδίο εφαρμογής `https://ai.azure.com/.default`, όχι ένα μονομερές διακριτικό που περνά ως API key.
Τα URL πόρων και τα URL που ήδη τελειώνουν σε `/openai/v1` γίνονται και τα δύο αποδεκτά.

Το bot διατηρεί ένα περιορισμένο ιστορικό συνομιλίας, εμφανίζει `Tool executed: ...` με το πραγματικό
αποτέλεσμα MCP, και αποτυγχάνει αν μια απάντηση παραλείψει εργαλεία. Οι βρόγχοι εργαλείων περιορίζονται σε τέσσερις γύρους.
Τα σφάλματα αυθεντικοποίησης, μοντέλου, MCP, και εργαλείου μεταφέρονται· οι αυτόματες δοκιμές μοντέλου είναι απενεργοποιημένες.
Τόσο η μεταφορά/πελάτης MCP όσο και ο επίσημος πελάτης OpenAI κλείνουν σε επιτυχία ή αποτυχία.

## Εκτέλεση Παραδειγμάτων

### Βήμα 1: Εκκίνηση του Διακομιστή Υπολογιστή

Δεν απαιτείται διαμόρφωση Azure για τον διακομιστή. Οι παρακάτω εντολές εκτελούνται από τον κατάλογο αυτού του δείγματος.
Το παράδειγμα χρησιμοποιεί τη θύρα **18081** για να αποφύγει διενέξεις με άλλο δείγμα· η προεπιλογή παραμένει 8080.

```powershell
cd 04-PracticalSamples/calculator
mvn spring-boot:run "-Dspring-boot.run.arguments=--server.port=18081"
```

Το σημείο πρόσβασης MCP είναι `http://localhost:18081/mcp`. Πληροφορίες υγείας και ανακάλυψης βρίσκονται στα
`http://localhost:18081/health` και `http://localhost:18081/info`.
Η ροή HTTP αντικαθιστά την παλιά μεταφορά μόνο SSE· τα `/sse` και `/v1/tools` δεν είναι σημεία πρόσβασης.

### Βήμα 2: Δοκιμή με Άμεσο Πελάτη

Σε άλλο τερματικό PowerShell:

```powershell
cd 04-PracticalSamples/calculator
$env:MCP_SERVER_URL = "http://localhost:18081"
mvn test-compile exec:java "-Dexec.mainClass=com.microsoft.mcp.sample.client.SDKClient" "-Dexec.classpathScope=test"
```

Δεν απαιτείται είσοδος. Όλα τα εννέα εργαλεία δοκιμάζονται. Αναμενόμενα αριθμητικά αποτελέσματα περιλαμβάνουν
8, 6, 42, 5, 256, 4, 2, και 5.5, ακολουθούμενα από το κείμενο βοήθειας.

### Βήμα 3: Δοκιμή με Πελάτη AI

Μετά την αυθεντικοποίηση όπως περιγράφεται στα προαπαιτούμενα, ρυθμίστε τον πελάτη AI στο ίδιο τερματικό:

```powershell
$env:AZURE_OPENAI_ENDPOINT = "https://your-resource.openai.azure.com/"
$env:AZURE_OPENAI_DEPLOYMENT = "gpt-5.6-luna"
mvn test-compile exec:java "-Dexec.mainClass=com.microsoft.mcp.sample.client.LangChain4jClient" "-Dexec.classpathScope=test" "-Dexec.args=--prompt 'Calculate the sum of 24.5 and 17.3 using the calculator service'"
```

Αναμένεται μια γραμμή `Tool executed: add` με `41.80`, ακολουθούμενη από την απάντηση του μοντέλου.
Η λειτουργία μεμονωμένου προτροπής εξέρχεται χωρίς αναμονή εισόδου. Για να τρέξετε το αρχικό demo τεσσάρων προτροπών:

```powershell
mvn test-compile exec:java "-Dexec.mainClass=com.microsoft.mcp.sample.client.LangChain4jClient" "-Dexec.classpathScope=test" "-Dexec.args=--demo"
```

Το demo καλεί τις λειτουργίες `add`, `squareRoot`, `help`, και την αλυσιδωτή `power` και μετά `divide`.
Αναμενόμενες αριθμητικές απαντήσεις είναι 41.8, 12, και 64. Η παράλειψη ορισμάτων τρέχει επίσης αυτό το demo.

### Βήμα 4: Εκτέλεση Διαδραστικού Bot

```powershell
mvn test-compile exec:java "-Dexec.mainClass=com.microsoft.mcp.sample.client.Bot" "-Dexec.classpathScope=test"
```

Πληκτρολογήστε `Multiply 6 by 7 using the calculator service`, κατόπιν `exit` ή `quit`.
Περιμένετε το πραγματικό αποτέλεσμα εργαλείου `multiply` 42. Οι κενές γραμμές αγνοούνται· EOF επίσης τερματίζει τη συνεδρία.
Για μη διαδραστική δοκιμή καπνού αυτού του σημείου εισόδου:

```powershell
mvn test-compile exec:java "-Dexec.mainClass=com.microsoft.mcp.sample.client.Bot" "-Dexec.classpathScope=test" "-Dexec.args=--prompt 'Multiply 6 by 7 using the calculator service'"
```

Και οι δύο είσοδοι AI δέχονται `--prompt "question"`, `--demo`, και `--interactive`.
Εσφαλμένες επιλογές αποτυγχάνουν πριν ανοίξουν σύνδεση. Κάθε όρισμα Maven `-D...` είναι πλήρως παρατιθέμενο
για PowerShell. Σε Bash, χρησιμοποιήστε `export NAME=value` αντί για `$env:NAME = "value"`.

**Πόρος:** Εκτελέστε τα δείγματα AI διαδοχικά. Μια απλή προτροπή χρειάζεται συνήθως δύο αιτήσεις μοντέλου;
το πλήρες demo χρειάζεται συνήθως εννέα, συμπεριλαμβανομένων των συνεχίσεων μετά από αποτελέσματα εργαλείων. Με κοινό ρυθμό 10 RPM
ανάπτυξης, επιτρέψτε ένα νέο παράθυρο πόρου πριν την επόμενη εκτέλεση AI. Ένα 429 αποτυγχάνει εμφανώς χωρίς
αυτόματες δοκιμές; ακολουθήστε τις οδηγίες retry-after της υπηρεσίας. Ο πραγματικός αριθμός αιτημάτων εξαρτάται από το μοντέλο.
Οι εκτός σύνδεσης δοκιμές δεν καταναλώνουν πόρο και δεν καθορίζουν ζωντανή διαθεσιμότητα ή ποιότητα απάντησης Luna.

### Διαμόρφωση και Τερματισμός

| Ρύθμιση | Προεπιλογή / συμπεριφορά |
| --- | --- |
| `MCP_SERVER_URL` | `http://localhost:8080`; βασικό URL, χωρίς `/mcp` |
| `-Dmcp.server.url=...` | Υπερισχύει του `MCP_SERVER_URL` για όλους τους πελάτες |
| `AZURE_OPENAI_ENDPOINT` | Απαιτείται μόνο για πελάτες AI; URL πόρου ή `/openai/v1` URL |
| `AZURE_OPENAI_DEPLOYMENT` | `gpt-5.6-luna`; όνομα ανάπτυξης Azure |
| `AZURE_OPENAI_MAX_COMPLETION_TOKENS` | `1024`; θετικός ακέραιος |
| Υπόδειξη λογικής | Πάντα `none`, συμπεριλαμβανομένων συνεχίσεων εργαλείου |

Μια υπερισχύουσα ανάπτυξη πρέπει να υποστηρίζει `reasoning_effort=none` και `max_completion_tokens`.
Οι πελάτες δεν διαβάζουν αυτόματα αρχείο `.env`. Σταματήστε τον διακομιστή με `Ctrl+C` μετά τις δοκιμές.
Οι πελάτες επιστρέφουν ομαλά χωρίς `System.exit` ή καθυστερήσεις τερματισμού.

## Εκτός Σύνδεσης Δοκιμές

```powershell
mvn -B -ntp clean verify
```

Όλες οι δοκιμές είναι εκτός σύνδεσης σε σχέση με το Azure: το πρωτόκολλο ξεκινά έναν διακομιστή Spring και
έναν OpenAI-συμβατό στέλεχο σε τυχαίες θύρες loopback και μετά τους κλείνει. Το Maven μπορεί να χρειαστεί ακόμα
να κατεβάσει εξαρτήσεις. Δεν χρησιμοποιούνται διαπιστευτήρια, ζωντανή ανάπτυξη ή προϋπάρχων διακομιστής MCP.

- Οι μονάδες δοκιμές υπολογιστή περιλαμβάνουν όλες τις αριθμητικές λειτουργίες, δεκαδικά αποτελέσματα, βοήθεια, και σφάλματα τομέα.
- Οι δοκιμές MCP καλύπτουν την αρχικοποίηση, ανακάλυψη, όλες τις εννέα κλήσεις εργαλείων, αποτυχίες εργαλείων, και υγεία/πληροφορίες.
- Οι δοκιμές πρωτοκόλλου AI εκτελούν το πλήρες demo και το διαδραστικό Bot με τον πραγματικό υπολογιστή,
  επαληθεύοντας ότι τα αποτελέσματα εργαλείων τροφοδοτούν την επόμενη ολοκλήρωση, και ελέγχουν κάθε HTTP σώμα για Luna,
  `reasoning_effort: "none"`, και `max_completion_tokens` χωρίς παλαιό `max_tokens`.
- Οι δοκιμές διαμόρφωσης/εισόδου καλύπτουν υπερκαλύψεις ανάπτυξης και σημείων πρόσβασης, κενές γραμμές, EOF, έξοδο/τερματισμό,
  λειτουργία μίας προτροπής, μη έγκυρες επιλογές, και διάδοση σφαλμάτων. Οι δοκιμές πόρων αποδεικνύουν ότι το 429 δεν δοκιμάζεται.

## Πώς Λειτουργεί Όλο Μαζί

Ακολουθεί η πλήρης ροή όταν ρωτάτε την AI "Πόσο κάνει 5 + 3;":

1. **Εσείς** ρωτάτε την AI σε φυσική γλώσσα
2. **Η AI** αναλύει το αίτημά σας και καταλαβαίνει ότι θέλετε πρόσθεση
3. **Η AI** καλεί τον διακομιστή MCP: `add(5.0, 3.0)`
4. **Η Υπηρεσία Υπολογιστή** υπολογίζει: `5.0 + 3.0 = 8.0`
5. **Η Υπηρεσία Υπολογιστή** επιστρέφει: `"5.00 + 3.00 = 8.00"`
6. **Η AI** λαμβάνει το αποτέλεσμα και μορφοποιεί μια φυσική απάντηση
7. **Εσείς** παίρνετε: "Το άθροισμα του 5 και του 3 είναι 8"
