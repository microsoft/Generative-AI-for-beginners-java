# Azure AI Foundry కోసం అభివృద్ధి వాతావరణాన్ని సెట్ చేయడం

> ఈ గైడ్ ఈ కోర్సులోని జావా AI యాప్స్ కోసం **Azure AI Foundry** నమూనాలను కీలేని* ప్రమాణీకరణ (Microsoft Entra ID) ఉపయోగించి సెట్ చేస్తుంది — నిర్వహించాల్సిన API కీలు అవసరం లేదు. టూలింగ్ కొత్తవా? [అభివృద్ధి వాతావరణ గైడ్](./README.md)తో ప్రారంభించండి.

ఈ గైడ్ ఈ కోర్సులోని జావా AI యాప్స్ కోసం **Azure AI Foundry** నమూనాలను సెట్ చేస్తుంది. మీకు రెండు మార్గాలు ఉన్నాయి:

- **ఎంపిక A — `azd` + Bicep తో ప్రొవిజన్ చేయండి (శిఫారసు చేయబడింది):** ఒకే ఆజ్ఞ ద్వారా Foundry ఖాతా మరియు నమూనాలను కోడ్‌గా మోపండి. పోర్టల్‌పై క్లిక్ చేయాల్సిన అవసరం లేదు.
- **ఎంపిక B — Azure AI Foundry పోర్టల్‌లో మానవీయంగా వనరులను సృష్టించండి.**

రెండూ **కీలేని ప్రమాణీకరణ** (Microsoft Entra ID) ఉపయోగిస్తాయి — కాపీ చేయాల్సిన లేదా లీక్ చేయాల్సిన API కీలు ఉండవు.

## ఏమి సృష్టించబడుతుంది

[`infra/`](../../../02-SetupDevEnvironment/infra) లోని Bicep టెంప్లేట్లు ఈ క్రింది వాటిని ప్రొవిజన్ చేస్తాయి:

- ఒక **Azure AI Foundry** ఖాతా (`Microsoft.CognitiveServices/accounts`, `AIServices` రకం) ఒక ప్రాజెక్టుతో
- ఒక **చాట్** డిప్లాయ్‌మెంట్ - GPT-5.6 Luna (`gpt-5.6-luna`), వెర్షన్ `2026-07-09`, `GlobalStandard` సామర్థ్యం `10` (ఈ నమూనా కోసం ప్రతి నిమిషానికి 10 అభ్యర్థనలు మరియు 10,000 టోకెన్లు)
- ఒక **ఎంబెడింగ్** డిప్లాయ్‌మెంట్ - `text-embedding-3-small`, వెర్షన్ `1` (తరవాత అధ్యాయాల్లో ఉపయోగిస్తారు)
- ఒక **కీలేని పాత్ర నియామకం** (`Cognitive Services OpenAI User`) కాబట్టి మీరు కీలు నిర్వహించకుండా `az login` తో సైన్ ఇన్ అవుతారు

## ముందస్తు అవసరాలు

- ఒక [Azure సబ్‌స్క్రిప్షన్](https://azure.microsoft.com/free/)
- [Azure Developer CLI (`azd`)](https://aka.ms/azure-dev/install)
- [Azure CLI (`az`)](https://learn.microsoft.com/cli/azure/install-azure-cli)
- [Java 21+](https://learn.microsoft.com/java/openjdk/download) మరియు [Maven 3.9+](https://maven.apache.org/download.cgi)

## ఎంపిక A: `azd` + Bicep తో ప్రొవిజన్ చేయండి (శిఫారసు చేయబడింది)

`02-SetupDevEnvironment` ఫోల్డర్ నుండి:

```bash
cd 02-SetupDevEnvironment

# సైన్ ఇన్ చేయండి (రెండు టూల్స్)
azd auth login
az login

# ఫౌన్రీ ఖాతా + మోడల్ డిప్లాయ్‌మెంట్లను సిద్ధం చేయండి
azd up
```

`azd` మీకు **వాతావరణం పేరును** (ఉదాహరణకు `genai-java`), **సబ్‌స్క్రిప్షన్**, మరియు **ప్రాంతం** అడుగుతుంది. మీ సొంత సబ్‌స్క్రిప్షన్ మరియు `gpt-5.6-luna` మరియు `text-embedding-3-small` అందుబాటులో ఉన్న ప్రాంతాన్ని ఎంచుకోండి, ఉదాహరణకు `eastus2`. ఆ ప్రాంతంలో నమూనా మరియు డిప్లాయ్‌మెంట్ రకం కోసం సబ్‌స్క్రిప్షన్‌కు తగిన క్వోటా ఉందో నిర్ధారించండి; అందుబాటు మరియు క్వోటా సబ్‌స్క్రిప్షన్‌ ప్రకారం మారవచ్చు.

ప్రొవిజనింగ్ పూర్తయినప్పుడు, azd:

1. [`infra/main.bicep`](../../../02-SetupDevEnvironment/infra/main.bicep)లో నిర్వచించిన అన్ని విషయం మోపుతుంది.
2. మీ ఎండ్‌పాయింట్ మరియు డిప్లాయ్‌మెంట్ పేర్లతో (రహస్యాలు కాదు) [`examples/basic-chat-azure/.env`](../../../02-SetupDevEnvironment/examples/basic-chat-azure) రాయడానికి పోస్ట్‌ప్రొవిజన్ హుక్‌ను నడుపుతుంది.

> **సూచన:** మార్పులు చేయాలనుకుంటే ఏ సమయంలోనైనా `azd up` మళ్ళీ నడపండి. అన్ని چیزలను తొలగించి ఖర్చును నిలిపివేయడానికి `azd down` నడపండి.

సృష్టించిన సెట్టింగులను చూడటానికి:

```bash
azd env get-values
```

ఇప్పుడు [మీ సెటప్‌ను పరీక్షించండి](#మీ-సెటప్‌ను-పరీక్షించండి) కి దూకండి.

## ఎంపిక B: వనరులను మానవీయంగా సృష్టించండి

పోర్టల్ మాకు ఇష్టమైతే? వనరులను చేతితో సృష్టించండి:

1. [Azure AI Foundry పోర్టల్](https://ai.azure.com/)కు వెళ్ళి సైన్ ఇన్ అవ్వండి.
2. **ప్రాజెక్ట్ సృష్టించండి** (ఇది AI Foundry వనరు కూడా సృష్టిస్తుంది). దానికి `GenAIJava` వంటి పేరు అందించండి.
3. మీ ప్రాజెక్టులో, **నమూనాలు + ఎండ్‌పాయింట్లు** → **మోడల్‌ను డిప్లాయ్ చేయండి** → **బేస్ మోడల్‌ను డిప్లాయ్ చేయండి** తెరవండి.
4. **GPT-5.6 Luna** (మోడల్ మరియు డిప్లాయ్‌మెంట్ పేరు `gpt-5.6-luna`, వెర్షన్ `2026-07-09`) ని **Global Standard** సామర్థ్యం `10` తో డిప్లాయ్ చేయండి. ఎంబెడింగ్ ఉదాహరణలు కావాలంటే **text-embedding-3-small**, వెర్షన్ `1` కూడా మళ్లీ చేయండి.
5. **సామాన్య అవలోకనం** నుండి **ఎండ్‌పాయింట్** (ఉదాహరణకు `https://<resource>.openai.azure.com/`) ను కాపీ చేసుకోండి.
6. మీకు కీలేని యాక్సెస్ ఇవ్వండి: వనరుపై, **యాక్సెస్ నియంత్రణ (IAM)** → **పాత్రను నియమించండి** తెరవండి → మీ ఖాతాకు **Cognitive Services OpenAI User** ని నియమించండి.

> **ఇంకా సమస్యలున్నా?** [Azure AI Foundry డాక్యుమెంటేషన్](https://learn.microsoft.com/azure/ai-foundry/how-to/create-projects) చూడండి.

## మీ వాతావరణాన్ని విధేయపరచండి

**మీరు ఎంపిక A (`azd up`) ఉపయోగించినట్లయితే**, మీ సెట్టింగులు ఇప్పటికే రాయబడ్డాయి — ఏదీ ఏర్పాటు చేయాల్సిన అవసరం లేదు. [మీ సెటప్‌ను పరీక్షించండి](#మీ-సెటప్‌ను-పరీక్షించండి) కి దూకండి.

**మీరు ఎంపిక B (మానవీయంగా) ఉపయోగించినట్లయితే**, ఉదాహరణ `.env` ఫైల్‌ను మీరు చేద్దాం:

```bash
cd 02-SetupDevEnvironment/examples/basic-chat-azure
cp .env.example .env
```

`.env` లో మీ ఎండ్‌పాయింట్‌తో ఎడిట్ చేయండి (కీ అవసరం లేదు — ప్రమాణీకరణ కీలేని):

```bash
AZURE_OPENAI_ENDPOINT=https://<your-resource>.openai.azure.com/
AZURE_OPENAI_DEPLOYMENT=gpt-5.6-luna
```

ప్రాజెక్ట్ URL కాదు, వనరుని Azure OpenAI ఎండ్‌పాయింట్‌ను ఉపయోగించండి. basic-chat యాప్ దానిని `/openai/v1` కి పరిష్కరిస్తుంది మరియు స్పష్టమైన బేరర్-టోకెన్ క్లయింట్‌ని డిఫైన్ చేస్తుంది; API కీ అవసరం లేదు.

> **భద్రత సూచన:** నిల్వ చేయవలసిన API కీ లేదు. మీరు `az login` (స్థానికంగా) లేదా మేనేజ్ చేసిన ఐడెంటిటీ (Azureలో) ద్వారా Microsoft Entra ID తో సైన్ ఇన్ అవుతారు. `.env` ఫైల్‌లో రహస్యాలు లేని సెట్టింగులు మాత్రమే ఉంటాయి మరియు `.gitignore` ద్వారా కప్పబడ్డది.

## మీ సెటప్‌ను పరీక్షించండి

మీరు సైన్ ఇన్ అయినట్లు నిర్ధారించుకోండి, తద్వారా కీ లేని ప్రమాణీకరణ టోకెన్ పొందగలదు, తరువాత ఉదాహరణను నడపండి:

```bash
cd 02-SetupDevEnvironment/examples/basic-chat-azure

az login          # మీరు ఇప్పటికే సైన్ ఇన్ కాకపోతే
mvn clean spring-boot:run
```

మీరు `gpt-5.6-luna` నమూనా నుండి ప్రతిస్పందన కనుగొనాలి. చిన్న డిఫాల్ట్ క్వోటాలో ఉండేందుకు ఉదాహరణలను వరుసగా నడపండి; మీరు HTTP 429 పొందితే, మళ్ళీ ప్రయత్నించే ముందు రీట్రై ఇంటర్వల్ కోసం వేచిచూడండి.

> **VS Code వినియోగదారులు:** నడపడానికి `F5` నొక్కండి. యాప్ మీ `.env` ను స్వయంచాలకంగా లోడ్ చేస్తుంది.

> **పూర్తి ఉదాహరణ:** వివరాలు మరియు సమస్యల పరిష్కారం కోసం [Basic Chat with Azure AI Foundry example](./examples/basic-chat-azure/README.md) చూడండి.

## తరువాత ఏమై ఉంటుంది?

ప్రొవిజనింగ్ మరియు ఉదాహరణ విజయవంతంగా నడిపిన తర్వాత, మీ వద్ద:
- `gpt-5.6-luna` మరియు `text-embedding-3-small` తో Azure AI Foundry డిప్లాయ్ చేయబడింది
- కీలు నిర్వహించాల్సిన అవసరం లేని ప్రమాణీకరణ (Microsoft Entra ID)
- మీ ఎండ్‌పాయింట్ మరియు డిప్లాయ్‌మెంట్ పేర్లతో స్థానిక `.env`
- సన్నద్ధమైన జావా అభివృద్ధి వాతావరణం
